## Процесс запроса на включение

### 1. Форк и клон

```bash
git clone https://github.com/YOUR_USERNAME/claude-code-ultimate-guide.git
cd claude-code-ultimate-guide
```

### 2. Создать ветку

```bash
git checkout -b fix/typo-in-section-3
# or
git checkout -b feature/add-debugging-guide
```

### 2.5. Установите хуки предварительной фиксации

В этом репозитории используются перехватчики предварительной фиксации для обеспечения контроля качества (уценка, проверка YAML, согласованность версий и т. д.). Настройте их один раз:

```bash
# macOS/Linux
pip install pre-commit
pre-commit install

# Windows (PowerShell)
pip install pre-commit
pre-commit install
```

Предварительная фиксация теперь будет выполняться автоматически на `git commit`. Вы также можете запустить вручную:

```bash
pre-commit run --all-files
```

**Что проверяют хуки:**
- ✓ Согласованность форматирования Markdown
- ✓ Валидность синтаксиса YAML
- ✓ Согласованность файлов ВЕРСИИ во всем репозитории
- ✓ Никаких неработающих символических ссылок или конфиденциальных файлов.

### 3. Внесите изменения

Следуйте инструкциям по содержанию [](#content-guidelines) ниже.

### 4. Проверьте свои изменения

- Предварительный рендеринг уценки
- Тестируйте фрагменты кода на вашей платформе
- Убедитесь, что все ссылки работают

### 5. Разместите пиар

Include:
- Четкое описание изменений
- Почему нужны перемены
- Что вы тестировали

## <a name="content-guidelines"></a>Рекомендации по содержанию

### Стиль письма

- **Краткая информация**: пункты списка > длинные абзацы
- **Practical**: включите примеры для каждой концепции.
- **Кроссплатформенность**: Поддержка macOS/Linux И Windows
- **Accurate**: проверьте весь код перед отправкой.

### Структура документации

```markdown
## Section Title

Brief intro (1-2 sentences).

### Subsection

| Column 1 | Column 2 |
|----------|----------|
| Data     | Data     |

**Example:**
```bash
code example here
```
```

### Platform-specific code

Always provide both when commands differ:

```bash
# macOS/Linux
~/.claude/settings.json

# Windows
%USERPROFILE%\.claude\settings.json
```

## Контрольный список качества

Перед отправкой:

- [ ] Markdown отображается правильно (предварительный просмотр на GitHub)
- [ ] Все ссылки рабочие
- [ ] Фрагменты кода, протестированные на вашей платформе.
- [ ] Предоставлены эквиваленты Windows (если применимо)
- [ ] Spell-checked
- [ ] Следует существующему стилю

## Вклад Windows (особенно приветствуется!)

Мейнтейнер работает над macOS. Если вы пользователь Windows:

- Тестируйте скрипты PowerShell на PS 5.1+
- Проверка обработки пути
- Сообщайте о проблемах, связанных с Windows
- Если возможно, добавьте альтернативы пакетному файлу.

**Ваш вклад особенно ценен!**

## Что мы не принимаем

- Маркетинговый язык или рекламный контент
- Непроверенные или спекулятивные утверждения
- Крупные структурные изменения без предварительного обсуждения
- Критические изменения в существующих примерах
