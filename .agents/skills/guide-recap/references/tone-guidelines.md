# Рекомендации по тону

Правила для социального контента, созданного на основе записей CHANGELOG. Центральный принцип: **Вовлечение через ценность, а не рекламу**.

## Контрольный список ДЕЛАТЬ/НЕ

### ДЕЛАТЬ

- Используйте конкретные цифры из CHANGELOG (`227 -> 257`, `+522 lines`, `4 new diagrams`).
- Укажите, что теперь может делать пользователь (`Test your knowledge`, `New visual guide for...`)
- Задавайте искренние вопросы (`Visual learner?`, `How do you review PRs?`)
- Кредитные именованные источники (`Based on Pat Cullen's workflow`, `From Addy Osmani's research`)
- Используйте точные глаголы действия (`added`, `integrated`, `documented`, `evaluated`)
- Ссылайтесь на конкретные шаблоны по имени (`Permutation Frameworks`, `Split-Role Agents`)

### НЕ

- Используйте рекламные слова: `game-changer`, `revolutionary`, `incredible`, `amazing`, `must-have`.
- Используйте FOMO: `You're missing out`, `Don't fall behind`, `Everyone is using this`.
- Используйте ложную срочность: `Act now`, `Limited time`, `Before it's too late`.
- Используйте хуки для кликбейта: `This ONE trick`, `You won't believe`, `Hidden feature`.
- Придумайте метрики: `10x faster`, `saves hours`, `boosts productivity by 300%`.
- Используйте более 3–4 смайлов в сообщении LinkedIn и по 2 в твите.
- Чрезмерное обещание: `The only guide you'll ever need`, `Complete mastery`

## Языковые правила

### Французский (FR)

| Формат | Зарегистрироваться | Пример |
|--------|----------|---------|
| LinkedIn | Вызов | `Vous utilisez Claude Code au quotidien ?` |
| Информационный бюллетень | Вызов | `Vous trouverez dans cette version...` |
| Twitter/X | Обучение | `Tu connais les Permutation Frameworks ?` |
| Слабый | Обучение | `Nouvelle version dispo, check ca` |

### английский (EN)

- Прямой адрес (`you`) во всех форматах
- Орфография американского английского (`optimize`, `analyze`, а не `optimise`, `analyse`)
- Никаких британских идиом или написаний.

## Эмодзи Бюджет

| Формат | Макс Эмодзи | Размещение |
|--------|-----------|-----------|
| LinkedIn | 3-4 | Хук (0-1), пули (по 1, максимум 3), CTA (0-1) |
| Твиттер | 2 | Хук (1), ключевая точка (1) |
| Информационный бюллетень | 2-3 | Только заголовки разделов |
| Слабый | 4-6 | Маркеры статуса, акцент |

Разрешенные смайлы: `+`, `->`, технические символы предпочтительнее декоративных.
Избегайте: огня, ракеты, взрыва, 100, сумасшедшего (маркетинговые клише).

## Правила призыва к действию

| Формат | Стиль призыва к действию | Цель ссылки |
|--------|-----------|-------------|
| LinkedIn | Мягкий вопрос или ценностное утверждение | URL целевого сайта |
| Твиттер | Короткое действие или ссылка | репозиторий GitHub |
| Информационный бюллетень | Явная связь с контекстом | URL целевого сайта |
| Слабый | Прямая ссылка | репозиторий GitHub |

Никаких паттернов `Click here`, `Check this out`, `Link in bio`.

## Контрольный список качества (предварительный результат)

Прежде чем выводить какой-либо социальный контент, проверьте:

1. [ ] Каждое число взято из фактической записи CHANGELOG.
2. [ ] Никаких рекламных слов (grep против НЕ перечислять)
3. [ ] Количество эмодзи в рамках бюджета
4. [ ] Регистр FR соответствует формату (vous/tu)
5. [ ] EN использует американское правописание
6. [ ] Призыв к действию ссылается на правильную цель
7. [ ] Названные источники указаны при использовании
8. [ ] Никаких придуманных показателей или процентов
