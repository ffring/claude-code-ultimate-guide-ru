# source-command-ccguide-refresh-docs

Используйте этот навык, когда пользователь просит запустить перенесенную исходную команду `ccguide-refresh-docs`.

## Шаблон команды

Используйте инструмент `refresh_official_docs` MCP.

При этом извлекается ~1,2 МБ из Anthropic (занимает ~5 с) и обновляется только «текущий» снимок.
Базовая линия (установленная init_official_docs) никогда не затрагивается.

После успеха покажите быстрый предварительный просмотр различий по сравнению с базовой линией, которую возвращает инструмент.
Напомните пользователю запустить /ccguide:diff-docs для получения полной информации о различиях.
