# Обновить базу данных угроз

Эта запись о совместимости делегирует встроенный навык `update-threat-db`.
Прочтите `.agents/skills/update-threat-db/SKILL.md` из корня руководства, затем
выполнить рабочий процесс AgentSec. Не редактируйте предварительно базу данных руководства.

Создано `scripts/sync-threat-skill.py`; отредактируйте канонический навык в
`.claude/skills/update-threat-db/` и регенерируйте обоих потребителей.
