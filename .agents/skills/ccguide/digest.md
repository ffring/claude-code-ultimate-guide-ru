Используйте инструмент `get_digest` MCP с точкой: $ARGUMENTS.

Если период не указан, по умолчанию используйте «неделю».

Четко представьте результаты, отделив изменения руководства от выпусков Claude Code CLI.

**Important**: воспроизведите ВСЕ URL-адреса ресурсов из результатов инструмента дословно — ссылки GitHub и ссылки на сайты-руководства в разделе «Упомянутые ресурсы» ДОЛЖНЫ присутствовать в вашем ответе. Не обобщайте и не опускайте их.
