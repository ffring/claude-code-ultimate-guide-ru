Выполните эту последовательность действий по порядку. Представьте результаты в виде одного консолидированного отчета.

## Шаг 1. Обновите официальные документы.

Вызовите инструмент `refresh_official_docs` MCP, чтобы получить последние документы Anthropic и обновить текущий снимок.

Если это не удалось (нет базового уровня), попросите пользователя сначала запустить /ccguide:init-docs один раз, а затем остановиться.

## Шаг 2 — Официальная документация по различиям

Вызовите инструмент `diff_official_docs` MCP, чтобы сравнить базовый уровень и обновленный ток.

## Шаг 3. Руководство + дайджест выпусков CC

Вызовите инструмент `get_digest` MCP с периодом: «день».

---

## Выходной формат

Представьте все как единый ежедневный брифинг:

```
# Daily Claude Code Update — {today's date}

## Official Anthropic Docs
{diff results — added/removed/modified sections, or "No changes"}

## Guide + CC CLI
{digest results — guide CHANGELOG entries + CC releases from last 24h, or "No changes"}

---
Docs snapshot: {baseline date} → {current date}
```

Rules:
- Если нигде нет изменений: скажите так четко, в одну строку, без отступов.
- Воспроизведите ВСЕ URL-адреса дословно (URL-адреса источников, ссылки GitHub)
- Если официальные документы не изменились И нет обновлений guide/CC: «За последние 24 часа ничего не изменилось».
- Будьте плотнее — это ежедневный брифинг, а не отчет.
