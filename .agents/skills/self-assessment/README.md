# Навык самооценки

Интерактивный инструмент оценки навыков, который оценивает ваше мастерство Claude Code и создает персонализированные пути обучения.

## Обзор

Этот навык обеспечивает два режима оценки:

- **Quick** (5 минут): 10 вопросов, по одному на тему, быстрая проверка навыков.
- **Comprehensive** (20 минут): 20 вопросов, по два на тему, глубокий анализ усвоения знаний.

После оценки получите:
- ✓ Ваш профиль мастерства (Beginner/Intermediate/Advanced)
- ✓ Разбивка баллов по темам
- ✓ Выявленные пробелы, ранжированные по важности
- ✓ Персонализированный путь обучения (с учетом зависимостей)
- ✓ 3 практических проекта, соответствующих вашему уровню

## Использование

### Быстрая оценка
```bash
/self-assessment quick
```
Быстрая оценка по всем темам. Показывает общий уровень + 2-3 верхних пробела.

### Комплексная оценка
```bash
/self-assessment comprehensive
```
Глубокое погружение в каждую тему. Показывает подробные оценки по темам + полный курс обучения + практические проекты.

### Варианты
```bash
/self-assessment quick --verbose        # Show detailed explanations
/self-assessment comprehensive --save   # Save results to assessment-results.json
```

## <a name="how-it-works"></a>Как это работает

### Поток взаимодействия

1. **Выберите режим:** Быстрый или Комплексный
2. **Ответить на вопросы:** 4 варианта с множественным выбором (AD)
3. **См. отзывы:** Объяснение + ссылка для каждого ответа.
4. **Получить профиль:** Оценка мастерства по всем темам
5. **Получить путь обучения:** Персонализированная последовательность с учетом зависимостей
6. **Выберите действие:** Изучите, попрактикуйтесь, повторите попытку или углубитесь в конкретную тему.

### Подсчет очков

**Быстрый режим:**
- Всего 10 баллов (по 1 за тему)
- Уровни: 0–3 (начинающий), 4–7 (средний), 8–10 (продвинутый).

**Комплексный режим:**
- Всего 20 баллов (по 2 за тему)
- Уровни: 0–6 (начинающий), 7–13 (средний), 14–20 (продвинутый).

### Затронутые темы

1. Быстрый старт — установка и основной рабочий процесс
2. Основные понятия — цикл взаимодействия, контекст, сеансы.
3. Память и настройки — конфигурация CLAUDE.md
4. Агенты — Создание и использование специализированных агентов.
5. Навыки — Создание возможностей многократного использования
6. Команды — слэш-команды и автоматизация.
7. Хуки — триггеры и проверка, управляемые событиями.
8. Серверы MCP — интеграция и настройка протоколов
9. Расширенные шаблоны — многоагентная оркестровка, композиция
10. Безопасность и производство — усиление защиты, управление, масштабирование

## Путь обучения

После комплексной оценки получите:

### Этапы структурированного обучения
- **Фаза 1:** Сначала заполните критические пробелы (соблюдая зависимости)
- **Фаза 2:** Приобретение промежуточных навыков
- **Фаза 3:** Освоение передовых моделей и производства
- **Бонус:** Глубокое погружение в конкретные слабые темы

Каждый этап включает в себя:
- 📖 Задания по чтению (ссылки на конкретные разделы руководства)
- 🔨 Практическая практика (шаблоны из примеров/)
- 📝 Проверка знаний (/lesson-quiz [тема])

### 3 практических проекта
Получите реальные сценарии, соответствующие вашему уровню:

1. **Проект 1:** Объедините 2–3 темы, в которых вы слабы (2–3 часа)
2. **Проект 2:** Реальный рабочий процесс (3 часа)
3. **Проект 3:** Настройка производства или конфигурация команды (3 часа)

Каждый проект включает в себя:
- Четкие критерии успеха
- Пошаговые инструкции
- Ожидаемые результаты

## Интеграция с системой обучения

Этот навык работает с `/lesson-quiz` для более глубокого обучения:

```bash
# After comprehensive assessment, drill down:
/lesson-quiz 05-skills          # 5 questions on Skills topic
/lesson-quiz 07-hooks           # 5 questions on Hooks topic
/lesson-quiz 09-advanced        # 5 questions on Advanced Patterns
```

## Файлы в этом навыке

- **SKILL.md** — определение и документация основного навыка.
- **quick-assessment-prompt.txt** — Вопросы для быстрого режима (10 вопросов)
- **comprehensive-assessment-prompt.txt** — Вопросы для комплексного режима (20 вопросов)
- **README.md** — Этот файл

## Советы для достижения наилучших результатов

1. **Ответьте честно** — Не угадывайте; пропустите, если не уверены (влияет на качество обучения)
2. **Пояснения к обзору** — В каждом ответе указано «почему» + ссылка на руководство.
3. **Пересдайте после изучения** — ваш профиль улучшается с каждой освоенной темой
4. **Поделиться результатами** — Используйте профиль для согласования командных тренировок
5. **Соответствуйте своей цели** — Быстрый для скорости, Комплексный для глубины

## Распределение очков

### Быстрый режим (10 вопросов, по 1 на тему)
- Наилучший результат: 10/10 (100%) — уровень Мастера.
- Продвинутый: 8-10/10 (80-100%)
- Средний уровень: 4-7/10 (40-70%)
- Новичок: 0-3/10 (0-30%)

### Комплексный режим (20 вопросов, по 2 на тему)
- Наилучший результат: 20/20 (100%) — Экспертный уровень.
- Продвинутый: 14-20/20 (70-100%)
- Средний уровень: 7-13/20 (35-65%)
- Новичок: 0-6/20 (0-30%)

Мастерство по темам:
- 0/2 (0%) — Нет мастерства, сначала сосредоточьтесь здесь
- 1/2 (50%) — Базовое понимание, нужна практика
- 2/2 (100%) — опытный, готовый к продвинутым

