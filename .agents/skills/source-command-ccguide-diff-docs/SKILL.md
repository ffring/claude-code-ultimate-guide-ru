# source-command-ccguide-diff-docs

Используйте этот навык, когда пользователь просит запустить перенесенную исходную команду `ccguide-diff-docs`.

## Шаблон команды

Используйте инструмент `diff_official_docs` MCP.

Без сетевого вызова — читает только локальные индексные файлы (~50 КБ каждый). Мгновенный.

Четко представьте результаты:
- Добавлены разделы (новые страницы в официальной документации)
- Удаленные разделы
- Измененные секции с дельтой линии и первой измененной линией.
- Неизменное количество

Если базовый уровень не существует, попросите пользователя сначала запустить /ccguide:init-docs.
Если текущий снимок не существует, попросите пользователя сначала запустить /ccguide:refresh-docs.
Если изменений нет, убедитесь, что все синхронизировано, и предложите запустить /ccguide:refresh-docs для обновления.
