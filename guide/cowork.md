## Краткий обзор

**Cowork** — это агентная функция рабочего стола Claude, которая расширяет возможности автономного искусственного интеллекта для нетехнических пользователей через приложение Claude Desktop. Вместо команд терминала Cowork напрямую обращается к локальным папкам и файлам.

### Ключевые факты

| Аспект | Подробности |
|--------|---------|
| **Статус** | Предварительный просмотр исследования (январь 2026 г.) |
| **Доступ** | Подписка Pro ($20/mo) или Max ($100-200/mo), только macOS |
| **Фокус** | Манипулирование файлами, создание документов, организация |
| **Отличие от Кода** | Никакого выполнения кода, только файлы |

---

## Три инструмента Claude: какой из них подойдет вам?

Три инструмента, одна подписка ($20/mo Pro). Они дополняют друг друга, а не конкурируют.

| | Claude ИИ | Claude Code | Коворкинг |
|---|-----------|-------------|--------|
| **Интерфейс** | Веб/мобильный | Терминал (CLI) | Настольное приложение |
| **Слоган** | Пишешь, думаешь, ищешь | Вы кодируете в масштабе | Вы автоматизируете без кода |
| **Определение** | Универсальный разговорный помощник | Автономный агент для полных кодовых баз | Агентские рабочие процессы с файлами для пользователей, не являющихся разработчиками |
| **Основные варианты использования** | Написание, мозговой штурм, исследование | Отладка, рефакторинг, тестирование | Организация файлов, извлечение PDF-файлов, рабочие процессы между приложениями |
| **Выполняет код** | Нет | Да | Нет |
| **Доступ к файловой системе** | Только загрузить | Полный | Папка-песочница |
| **Требуется настройка** | Никто | npm install -g @anthropic-ai/claude-code | Установка приложения macOS |
| **Зрелость** | Производство | Производство | Предварительный просмотр исследования |
| **Идеальный профиль** | Писатель · Консультант · Студент | Разработчик · Инженер · Технический руководитель | Оперативный отдел · Ассистент · Нетехнический специалист по малому и среднему бизнесу |
| **Основной компромисс** | Нет доступа к системе | Стоимость токенов на тяжелых проектах | Только macOS, ограниченная конфигурация |

→ [Полное сравнение Cowork и Code](https://cowork.bruniaux.com/guide/reference/comparison/)

### Руководство по принятию решений

- **Пишете документ или проводите исследование?** → Claude AI
- **Кодирование: рефакторинг, отладка, тесты?** → Claude Code (вы по адресу)
- **Организация файлов, извлечение PDF-файлов без кода?** → Cowork

## Сводка по безопасности

Официальной документации по безопасности пока не существует. Основные практики:

1. **Выделенное рабочее пространство**: никогда не предоставлять доступ к Documents/Desktop.
2. **Просмотр планов**: проверяйте каждое действие перед утверждением.
3. **Нет учетных данных**: храните конфиденциальные данные вне рабочего пространства.
4. **Сначала создайте резервную копию**: перед разрушительными операциями

→ [Полное руководство по безопасности](https://cowork.bruniaux.com/guide/03-security/)
