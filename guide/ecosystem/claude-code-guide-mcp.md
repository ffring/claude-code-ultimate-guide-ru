## <a name="tldr"></a>ТЛ;ДР

Используйте сервер MCP, если вы хотите, чтобы клиент кодирования выполнял поиск в руководстве, открывал точный раздел исходного кода, получал рабочий шаблон или проверял выпуски Claude Code без загрузки полного руководства в контекст.

Сервер работает локально через stdio. Версия `1.3.7` не имеет собственной телеметрии. Некоторые инструменты могут связываться с GitHub или Anthropic при вызове и записывать файлы локального кэша. Загрузки не являются пользователями, активными установками, сеансами или выполнениями.

Установите опубликованный в данный момент пакет:

```bash
claude mcp add --scope user claude-code-guide -- npx -y claude-code-ultimate-guide-mcp@1.3.7
codex mcp add claude-code-guide -- npx -y claude-code-ultimate-guide-mcp@1.3.7
```

## Что решает сервер

Руководство слишком велико, чтобы вводить его полностью по каждому вопросу. Сервер MCP обеспечивает меньший цикл обнаружения и извлечения:

1. выполнить поиск по структурированному указателю справочника;
2. возвращать совпадающие пути и привязки;
3. читать только соответствующий раздел источника;
4. при необходимости получить определенный шаблон или выпустить запись.

Это уменьшает нерелевантный контекст. Это не гарантирует, что ответ правильный, актуальный или подходящий для конкретного репозитория. Клиенту все равно придется проверять полученный источник и проверять срочные заявления.

## Первый полезный запрос

Спросите клиента:

> Вызовите search_guide с query="перехватчиками области сеанса" и limit=20. Найдите записьooks_session_scoped, откройте возвращенный путь и строку с read_section и укажите исходный путь и точный заголовок.

Ожидаемая последовательность инструментов:

```text
search_guide({ query: "session-scoped hooks", limit: 20 })
// Use the path and offset returned for hooks_session_scoped.
// The 2026-10-28 check returned the following values:
read_section({ path: "guide/ultimate-guide.md", offset: 10108, limit: 80 })
```

Проверенный ответ прочитал строки 10108-10120 под `Session-Scoped Hooks`. При проверке 5 октября 2026 г. ограничение поиска по умолчанию, равное 10, не включало именно эту запись; используйте 20 и проверьте результат сопоставления. Номера строк могут меняться, поэтому повторно используйте возвращенное смещение, а не предполагайте, что 10108 остается текущим.

Начиная с версии 1.3.6, границы глав создаются на основе заголовков справочников, а не устаревших статических диапазонов. При проверке публичной версии 1.3.7 28 октября 2026 г. перехватчики поиска и чтения в области сеанса вернули правильную ссылку на главу `Guide`, `07-hooks`. Используйте возвращенный путь и смещение, проверьте заголовок и укажите источник [GitHub](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/guide/ultimate-guide.md#L10108) или раздел [Hooks](https://cc.bruniaux.com/guide/ultimate-guide/07-hooks/#session-scoped-hooks). Основной GitHub является изменяемым.

Историческое ограничение: общедоступная версия 1.3.5 возвращала `08-mcp` для этой же записи перехватчиков, поскольку ее статические диапазоны глав были устаревшими. Этот дефект маршрутизации исправлен в версии 1.3.6; предыдущая проверка не закрепила SHA содержимого GitHub.

Для шаблона начните с `search_examples`, затем вызовите `get_example` с возвращенным именем. Для внесения изменений в официальную документацию запустите `init_official_docs` один раз, затем `refresh_official_docs` и `diff_official_docs`, когда вам понадобится новое сравнение.

## Архитектура и поток данных

```text
MCP client
  -> local stdio process started through npx
     -> bundled indexes and datasets
     -> optional GitHub fetch for guide content and templates
     -> optional Anthropic fetch for official documentation snapshots
     -> local cache under ~/.cache/claude-code-guide/
```

Протокол MCP проходит через стандартный ввод и стандартный вывод дочернего процесса. В этой архитектуре нет размещенной конечной точки руководства MCP. Клиент контролирует, когда запускается локальный процесс и какие инструменты он вызывает.

## Связанный контент, выборка GitHub и кеш

Пакет включает в себя структурированный справочник, историю выпусков, руководство по навигации и другие наборы данных заявленных ресурсов. Инициализация, операции со списками и поиск по руководству используют связанные данные.

Эти инструменты могут извлекать контент из GitHub, когда локальная проверка или доступная запись в кэше недоступны:

- `read_section`
- `get_example`
- `get_cheatsheet`
- `get_changelog`
- `get_digest`
- `get_threat`
- `list_threats`

Успешные ответы GitHub могут быть кэшированы под `~/.cache/claude-code-guide/<version>/` на 24 часа. Когда `GUIDE_ROOT` указывает на оформление локального руководства, инструменты содержания вместо этого считывают данные из этого оформления.

`init_official_docs` и `refresh_official_docs` извлекают документацию Anthropic и сохраняют отдельные локальные снимки. `diff_official_docs` и `search_official_docs` читают эти снимки, не отправляя сетевой запрос.

## Граница сети и конфиденциальности

Версия `1.3.7` не имеет сторонней телеметрии, конечной точки аналитики, идентификатора устройства или загрузки событий. Запросы и ответы MCP автору проекта не отправляются.

Доступ к сети зависит от инструмента:

| Операция | Сеть | Локальная запись |
| --- | --- | --- |
| Список возможностей и поиск в связанном индексе | Нет | Нет |
| Чтение некэшированного содержимого руководства или шаблонов | GitHub, когда необходимо | 24-часовой кэш |
| Инициализируйте или обновите официальные документы | Anthropic | Локальные снимки |
| Сравните или найдите существующие снимки официальных документов. | Нет | Нет |

Клиент MCP, npm, `npx`, GitHub, Anthropic и оператор машины могут иметь свои собственные журналы или политики. Эти системы находятся за пределами основной границы телеметрии этого сервера.

### Решение телеметрии для 1.3.7

Централизованная телеметрия продукта намеренно не реализована в `1.3.7`. Количество загрузок не оправдывает добавление конечной точки отслеживания и не может свидетельствовать об активном использовании.

Любое будущее предложение требует рассмотрения решения о конфиденциальности до появления кода. Минимальные критерии приемки:

- отключено по умолчанию и включено явным действием пользователя;
- нет текста запроса, аргументов, путей к файлам, возвращаемого содержимого, идентификатора репозитория, имени хоста или идентификатора учетной записи;
- локально сгенерированный случайный идентификатор, который пользователь может сбросить;
- только версия пакета, имя инструмента, успех или неудача и приблизительная задержка;
- документированная конечная точка, период хранения, процесс удаления и точная схема полезной нагрузки;
- механизм немедленного отключения и общедоступный способ проверки исходящих событий.

Пока эти условия не будут одобрены и реализованы, точным утверждением является отсутствие телеметрии первой стороны.

## Офлайн-поведение

Сервер частично отключен, но не полностью отключен.

- список возможностей, список тем, данные о выпуске, ресурсы и поиск по индексу на основе связанного контента;
- содержимое кэшированного руководства можно читать, пока кэш остается пригодным для использования;
- для некэшированных разделов и шаблонов Markdown может потребоваться GitHub;
- Для поиска и сравнения официальных документов требуются снимки, ранее созданные при доступе к сети;
- первое выполнение `npx` может потребовать доступа к реестру npm, если пакет еще не кэширован или не установлен.

Для разработки или контролируемого автономного использования заранее установите зависимости, соберите пакет и запустите `dist/index.js` из локальной проверки с установленным `GUIDE_ROOT`.

## <a name="limitations"></a>Ограничения

- Полное руководство по Markdown не входит в комплект поставки.
- Версия `1.3.7` наследует рукопожатие MCP от `package.json` и проверяет его.
- Официальный идентификатор реестра чувствителен к регистру: `io.github.FlorianBruniaux/claude-code-guide`.
- Командные файлы Companion `/ccguide:*` находятся в репозитории и не устанавливаются пакетом npm.
- Поиск находит разделы-кандидаты; он не заменяет проверку источника или проверку свежести.
- Ни одна метрика в этом репозитории не измеряет активных пользователей.

Эти более старые исходные состояния не являются новой октябрьской проверкой доступа и не обозначаются как нулевые.

Ранее завершенный снимок UTC за июль 2026 года зафиксировал 1459 загрузок npm. Держите этот исторический месяц отдельно от сентября и от завершающего 30-дневного окна, указанного выше.

Ежемесячный рабочий процесс использует фильтры точного URL-адреса страницы или пути, публикует только совокупные показатели страниц и пакетов и четко указывает недостающие источники. Загрузки npm могут включать установки, запуски CI, промахи в кеше, ботов и повторные загрузки. Они не идентифицируют уникальных или активных людей.
