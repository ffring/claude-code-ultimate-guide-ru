# Справочник по настройкам Claude Code

> Полный справочник по конфигурации `settings.json` и переменным среды. Охватывает подтвержденные настройки Claude Code v2.1.310 (последняя проверка 27 октября 2026 г.). Официальная ссылка на настройки [](https://code.claude.com/docs/en/settings-reference) остается авторитетной.

**Источники:** [Официальная документация по настройкам](https://code.claude.com/docs/en/settings) · [Официальная документация по env-vars](https://code.claude.com/docs/en/env-vars) · [JSON Schema](https://json.schemastore.org/claude-code-settings.json)

**Legend:**
- Нет значка = подтверждено в официальной документации.
- `📋 Schema only` = присутствует в схеме JSON, но отсутствует на официальной странице настроек (все еще действует)
- `⚠️ Unverified` = не подтверждено в официальных источниках

## Область применения и приоритет

Claude Code использует четыре области настроек, применяемые от самого высокого до самого низкого приоритета:

| Приоритет | Область применения | Расположение | Поделились? | Цель |
|----------|-------|----------|---------|---------|
| 1 | **Управляемый** | Сервер, профиль MDM, реестр или система `managed-settings.json` | Да (развернуто в ИТ-отделе) | Политики всей организации, которые нельзя переопределить. |
| 2 | **Командная строка** | Флаги `--` при запуске | Нет | Временные переопределения сеанса |
| 3 | **Локальный** | `.claude/settings.local.json` | Нет (gitignored) | Персональный проект |
| 4 | **Проект** | `.claude/settings.json` | Да (обязано) | Общие настройки команды |
| 5 | **Пользователь** | `~/.claude/settings.json` | Нет | Глобальные персональные настройки по умолчанию |

**Array merging:** Параметры, такие как `permissions.allow`, `sandbox.filesystem.allowWrite` и `allowedHttpHookUrls`, объединяются и дедуплицируются в разных областях, а не заменяются.

**Запретить приоритет: правила** `permissions.deny` всегда вступают в силу независимо от правил allow/ask в любой области действия.

**Способы доставки управляемых настроек:**
- Управляется сервером (консоль администратора Claude.ai)
- macOS MDM: список `com.anthropic.claudecode`
- Реестр Windows: `HKLM\SOFTWARE\Policies\ClaudeCode`
- Файл: `managed-settings.json` в `/Library/Application Support/ClaudeCode/` (macOS), `/etc/claude-code/` (Linux/WSL), `C:\Program Files\ClaudeCode\` (Windows)
- Каталог вставных файлов: `managed-settings.d/*.json` рядом с `managed-settings.json`, объединены в алфавитном порядке.

**Другая конфигурация:** `~/.claude.json` хранит сеанс OAuth, конфигурации сервера MCP, состояние доверия для каждого проекта и настройки, такие как `editorMode`. Не помещайте ключи `~/.claude.json` в `settings.json`: это вызовет ошибки проверки схемы.

## Клавиши настроек

### Базовая конфигурация

#### `$schema`
**Type:** строка
**Scope:** все
**По умолчанию:** нет

URL-адрес схемы JSON для проверки и автозаполнения IDE. Добавьте `"https://json.schemastore.org/claude-code-settings.json"`, чтобы включить встроенную проверку в VS Code, Cursor и других редакторах.

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json"
}
```

#### `model`
**Type:** строка
**Scope:** все
**По умолчанию:** `"default"`

Переопределить модель по умолчанию для всех сеансов. Принимает псевдонимы (`"sonnet"`, `"opus"`, `"haiku"`, `"opusplan"`) или полные идентификаторы моделей, например `"claude-sonnet-4-6"`. Переменная среды `ANTHROPIC_MODEL` имеет приоритет.

```json
{ "model": "opus" }
```

#### `agent`
**Type:** строка
**Scope:** все
**По умолчанию:** нет

Запустите основной поток как именованный субагент. Применяет системное приглашение этого агента, ограничения инструмента и модель. Значение должно соответствовать агенту, определенному в `.claude/agents/`. Также доступно через флаг `--agent` CLI.

```json
{ "agent": "code-reviewer" }
```

#### `language`
**Type:** строка
**Scope:** все
**По умолчанию:** `"english"`

Предпочитаемый язык ответа Claude. Также устанавливает язык голосовой диктовки. Примеры: `"japanese"`, `"spanish"`, `"french"`.

#### `cleanupPeriodDays`
**Тип:** номер
**Scope:** все
**По умолчанию:** `30`

Сеансы, неактивные дольше указанного количества дней, удаляются при запуске. Установка `0` удаляет все существующие расшифровки при запуске и полностью отключает сохранение сеанса: файлы `.jsonl` не записываются, `/resume` не отображает диалоги, а перехватчики получают пустой `transcript_path`.

#### `autoUpdatesChannel`
**Type:** строка
**Scope:** все
**По умолчанию:** `"latest"`
**Значения:** `"latest"` | `"stable"`

Освободите канал, чтобы подписаться. `"stable"` обычно отстает от `"latest"` примерно на неделю и пропускает версии со значительными регрессиями.

#### `alwaysThinkingEnabled`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Включите расширенное мышление по умолчанию для всех сеансов. Обычно настраивается через `/config`, а не редактируется напрямую.

#### `includeGitInstructions`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `true`

Включите в системную подсказку встроенные инструкции по фиксации и PR, а также снимок состояния git. Установите значение `false` при использовании специального навыка рабочего процесса git. Переменная окружения `CLAUDE_CODE_DISABLE_GIT_INSTRUCTIONS` имеет приоритет.

#### `voiceEnabled`
**Тип:** логическое значение
**Scope:Пользователь**
**По умолчанию:** нет

Включите голосовую диктовку «нажми и говори». Пишется автоматически при запуске `/voice`. Требуется учетная запись Claude.ai.

#### `companyAnnouncements`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет

Объявления, отображаемые пользователям при запуске. Несколько объявлений чередуются в случайном порядке.

```json
{
  "companyAnnouncements": [
    "Welcome to Acme Corp! Review code guidelines at docs.acme.com",
    "All PRs require code review before merge"
  ]
}
```

#### `availableModels`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет

Ограничьте, какие модели пользователи могут выбирать с помощью `/model`, `--model`, инструмента Config или `ANTHROPIC_MODEL`. Не влияет на параметр «По умолчанию», если не включен `enforceAvailableModels`.

```json
{ "availableModels": ["sonnet", "haiku"] }
```

#### `fastModePerSessionOptIn`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

При `true` быстрый режим не сохраняется между сеансами. Каждый сеанс начинается с выключенного быстрого режима, поэтому пользователям необходимо включить его с помощью `/fast`. Предпочтения пользователя по-прежнему сохраняются.

#### `teammateMode`
**Type:** строка
**Scope:** все
**По умолчанию:** `"auto"`
**Значения:** `"auto"` | `"in-process"` | `"tmux"`

Как отображаются товарищи по команде агентов. `"auto"` использует разделенные панели в tmux или iTerm2, в противном случае — в процессе.

#### `showClearContextOnPlanAccept`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Покажите опцию «Очистить контекст» на экране принятия плана. Установите значение `true`, чтобы восстановить опцию, которая была скрыта по умолчанию, начиная с версии 2.1.81.

#### `feedbackSurveyRate`
**Тип:** номер
**Scope:** все
**По умолчанию:** нет

Вероятность (0–1) того, что опрос о качестве сеанса появится, если он соответствует критериям. Установите значение `0` для полного подавления. Полезно при использовании Bedrock, Vertex или Foundry.

#### `disableAutoMode`
**Type:** строка
**Scope:** все
**По умолчанию:** нет
**Значения:** `"disable"`

Установите значение `"disable"`, чтобы предотвратить активацию автоматического режима. Удаляет `auto` из цикла `Shift+Tab` и отклоняет `--permission-mode auto` при запуске.

#### `useAutoModeDuringPlan`
**Тип:** логическое значение
**Scope:** пользователь/локальный
**По умолчанию:** `true`

Использует ли режим планирования семантику автоматического режима, когда автоматический режим доступен. Не читается из общих настроек проекта.

#### `autoMode`
**Type:** объект
**Scope:** пользователь/локальный
**По умолчанию:** нет

Настройте классификатор автоматического режима. Содержит массивы прозаических правил `environment`, `allow` и `soft_deny`. Не читается из общих настроек проекта.

#### `defaultShell`
**Type:** строка
**Scope:** все
**По умолчанию:** `"bash"`
**Значения:** `"bash"` | `"powershell"`

Оболочка по умолчанию для команд поля ввода `!`. `"powershell"` требует `CLAUDE_CODE_USE_POWERSHELL_TOOL=1`.

#### `skipWebFetchPreflight` `📋 Schema only`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Пропустите проверку черного списка WebFetch перед получением URL-адресов.

#### `env`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Переменные среды применяются к каждому сеансу. Используйте это вместо сценариев-оболочек для установки переменных. См. раздел [Environment Variables](#environment-variables) для всех поддерживаемых ключей.

```json
{
  "env": {
    "NODE_ENV": "development",
    "CLAUDE_CODE_EFFORT_LEVEL": "medium"
  }
}
```

### Планы и память

#### `plansDirectory`
**Type:** строка
**Scope:** все
**По умолчанию:** `"~/.claude/plans"`

Каталог, в котором хранятся выходные данные `/plan`. Путь указывается относительно корня проекта.

#### `autoMemoryEnabled`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `true`

Включите или отключите функцию автоматического запоминания, которая автоматически сохраняет контекст между сеансами.

#### `autoMemoryDirectory`
**Type:** строка
**Scope:** пользователь/локальный/управляемый
**По умолчанию:** нет

Пользовательский каталог для хранения в автоматической памяти. Принимает пути, расширенные `~/`. Не принято в настройках проекта (`.claude/settings.json`), чтобы запретить общим репозиториям перенаправлять записи в память в конфиденциальные места.

### Разрешения

Контролируйте, какие инструменты и операции может выполнять Claude.

#### `permissions.allow`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Правила разрешений, которые позволяют использовать инструмент без запроса. Массивы объединяются в разных областях. См. синтаксис правила [Permission](#permission-rule-syntax) ниже.

#### `permissions.ask`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Правила разрешений, требующие подтверждения пользователя перед использованием инструмента.

#### `permissions.deny`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Правила разрешений, блокирующие использование инструмента. Высший приоритет безопасности, не может быть отменен правилами allow/ask ни в какой области.

#### `permissions.additionalDirectories`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Дополнительные рабочие каталоги, к которым имеет доступ Claude, помимо текущего корня проекта.

```json
{ "permissions": { "additionalDirectories": ["../shared-libs/"] } }
```

#### `permissions.defaultMode`
**Type:** строка
**Scope:** все
**По умолчанию:** не установлено (встроенный режим запуска для поверхности: `auto` в интерактивном терминале и сеансах VS Code, начиная с версии 2.1.283)
**Значения:** `"default"` (псевдоним `"manual"`) | `"acceptEdits"` | `"plan"` | `"auto"` | `"dontAsk"` | `"bypassPermissions"`

Режим разрешений по умолчанию при открытии Claude Code. `auto` и `bypassPermissions` вступают в силу только из пользовательских или управляемых настроек (или `--permission-mode`), а не из настроек проекта или локальных настроек. В удаленных средах учитываются только `"acceptEdits"` и `"plan"`.

#### `permissions.disableBypassPermissionsMode`
**Type:** строка
**Scope:** все
**По умолчанию:** нет
**Значения:** `"disable"`

Установите значение `"disable"`, чтобы предотвратить активацию режима `bypassPermissions`. Отключает флаг `--dangerously-skip-permissions`. Наиболее полезно в управляемых настройках.

#### `allowManagedPermissionRulesOnly`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

При использовании `true` правила пользователя и проекта `allow`, `ask` и `deny` игнорируются. Применяются только правила управляемых разрешений.

### <a name="permission-rule-syntax"></a>Синтаксис правила разрешения

Правила имеют формат `Tool` или `Tool(specifier)`. Порядок оценки: сначала запретить, затем спросить, затем разрешить. Первое совпадающее правило побеждает.

| Инструмент | Шаблон | Пример |
|------|---------|---------|
| `Bash` | Шаблон команды с подстановочными знаками | `Bash(npm run *)`, `Bash(git *)` |
| `Read` | Шаблон пути к файлу | `Read(.env)`, `Read(./secrets/**)` |
| `Edit` | Шаблон пути к файлу | `Edit(src/**)`, `Edit(*.ts)` |
| `Write` | Шаблон пути к файлу | `Write(*.md)` |
| `WebFetch` | `domain:hostname` | `WebFetch(domain:example.com)` |
| `WebSearch` | Нет спецификатора | `WebSearch` |
| `Task` | Имя агента | `Task(Explore)` |
| `Agent` | Имя агента | `Agent(researcher)` |
| `MCP` | `mcp__server__tool` или `MCP(server:tool)` | `mcp__memory__*` |

**Префиксы пути для правил Read/Edit:**

| Префикс | Значение |
|--------|---------|
| `//` | Абсолютный путь от корня файловой системы |
| `~/` | Относительно домашнего каталога |
| `/` | Относительно корня проекта |
| `./` или нет | Относительный путь (текущий каталог) |

Примечания по подстановочным знакам **Bash:** `*` соответствует в любой позиции. `Bash(ls *)` (пробел перед `*`) соответствует `ls -la`, но НЕ `lsof`. `Bash(*)` эквивалентен `Bash` (соответствует всем командам). Устаревший суффикс `:*` (например, `Bash(npm:*)`) устарел.

```json
{
  "permissions": {
    "allow": ["Edit(*)", "Bash(npm run *)", "Bash(git *)"],
    "ask": ["Bash(git push *)"],
    "deny": ["Read(.env)", "Read(./secrets/**)"],
    "defaultMode": "acceptEdits"
  }
}
```

### <a name="hooks"></a>Хуки

#### `hooks`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Настройте пользовательские команды для запуска при событиях жизненного цикла. См. документацию [hooks](https://code.claude.com/docs/en/hooks) и [§7.1 руководства](../ultimate-guide.md#71-the-event-system) для получения полного набора из 33 событий перехвата, кодов выхода и переменных среды.

#### `disableAllHooks`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Отключите все перехватчики и любую пользовательскую строку состояния.

#### `allowManagedHooksOnly`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

При `true` загружаются только управляемые перехватчики и перехватчики SDK. Перехватчики пользователей, проектов и плагинов заблокированы.

#### `allowedHttpHookUrls`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет (без ограничений)

Разрешенный список шаблонов URL-адресов, на которые могут ориентироваться перехватчики HTTP. Поддерживает `*` в качестве подстановочного знака. Если они определены, перехватчики с несовпадающими URL-адресами автоматически блокируются. Пустой массив блокирует все перехватчики HTTP. Массивы объединяются между источниками настроек.

```json
{ "allowedHttpHookUrls": ["https://hooks.example.com/*"] }
```

#### `httpHookAllowedEnvVars`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет (без ограничений)

Список разрешенных имен переменных среды, которые перехватчики HTTP могут интерполировать в значения заголовка. Эффективный `allowedEnvVars` каждого хука является пересечением с этим списком. Массивы объединяются между источниками настроек.

### <a name="mcp-servers"></a>Серверы MCP

#### `enableAllProjectMcpServers`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Автоматически утверждать все серверы MCP, определенные в файлах проекта `.mcp.json`. Избегает запросов подтверждения для каждого сервера.

#### `enabledMcpjsonServers`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет

Разрешенный список определенных имен серверов из файлов `.mcp.json` для утверждения.

#### `disabledMcpjsonServers`
**Type:** массив строк
**Scope:** все
**По умолчанию:** нет

Черный список определенных имен серверов из файлов `.mcp.json`, которые следует отклонить.

#### `allowedMcpServers`
**Type:** массив
**Scope:** только управляемый
**По умолчанию:** нет (без ограничений)

Белый список серверов MCP, которые могут настроить пользователи. Каждая запись соответствует `serverName`, `serverCommand` или `serverUrl`. Не определено = нет ограничений, пустой массив = блокировка.

```json
{
  "allowedMcpServers": [
    { "serverName": "github" },
    { "serverCommand": "npx @modelcontextprotocol/*" },
    { "serverUrl": "https://mcp.company.com/*" }
  ]
}
```

#### `deniedMcpServers`
**Type:** массив
**Scope:** только управляемый
**По умолчанию:** нет

Черный список серверов MCP, которые явно заблокированы. Применяется ко всем областям, включая управляемые серверы. Имеет приоритет над `allowedMcpServers`.

#### `allowManagedMcpServersOnly`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

При `true` учитывается только `allowedMcpServers` из управляемых настроек. Пользователи по-прежнему могут добавлять серверы MCP, но можно использовать только серверы, определенные администратором. `deniedMcpServers` по-прежнему сливается из всех источников.

#### `channelsEnabled`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

Разрешить каналы для пользователей claude.ai Team и Enterprise. Если параметр не установлен или `false`, доставка сообщений канала блокируется независимо от того, какие данные пользователи передают в `--channels`. Вместо этого при развертывании ключа консоли API используются настройки консоли по умолчанию и управляемые элементы управления; не делайте выводов об их политике из этой настройки Team/Enterprise-only.

#### `allowedChannelPlugins`
**Type:** массив
**Scope:** только управляемый
**Default:** нет (используется список разрешений Anthropic по умолчанию)

Белый список плагинов канала, которые могут отправлять сообщения. Заменяет белый список Anthropic по умолчанию, если он установлен. Требуется `channelsEnabled: true`. Пустой массив блокирует все плагины канала.

> **Граница безопасности**: этот список разрешений определяет, какие плагины канала могут доставлять сообщения. Он не предоставляет доставленному сообщению, его отправителю или плагину никаких разрешений Bash, файловой системы, GitHub или другого инструмента. Запретите отправителям и рассматривайте содержимое канала как ненадежные входные данные, в том числе в тех случаях, когда плагин может ретранслировать запрос на разрешение.

### Песочница

Настройте изолированную программную среду команд bash для обеспечения безопасности. Доступно на macOS, Linux и WSL2.

#### `sandbox.enabled`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Включите песочницу bash. Изолирует команды bash от вашей файловой системы и сети.

#### `sandbox.failIfUnavailable`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Выйти с ошибкой при запуске, если `sandbox.enabled` — это `true`, но песочница не запускается (отсутствуют зависимости, неподдерживаемая платформа). При `false` отображается предупреждение и команды выполняются без изолированной программной среды. Полезно в управляемых развертываниях, которые требуют изолированной программной среды в качестве жесткого шлюза.

#### `sandbox.autoAllowBashIfSandboxed`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `true`

Автоматическое одобрение команд bash в песочнице. Когда песочница активна, команды bash, которые обычно требуют подтверждения, автоматически одобряются.

#### `sandbox.excludedCommands`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Команды, которые обходят песочницу и выполняются непосредственно в вашей среде.

> **Используйте форму glob, а не простое имя.** Простая запись, такая как `"git"`, соответствует только строке без аргументов `git`, поэтому она никогда не срабатывает при реальном вызове, и команда остается в изолированной программной среде. Вместо этого напишите `"git *"`. Голая форма — это то, что предлагает опубликованная схема JSON, поэтому здесь легко ошибиться: вы настраиваете что-то, что ничего не делает, замечаете, что команда все еще находится в песочнице, и только затем находите glob-форму ([anthropics/claude-code#10524](https://github.com/anthropics/claude-code/issues/10524)). Проверено на 2.1.220: `"git"` не дало эффекта, `"git *"` сработал сразу.

> **Каждая команда в вызове должна соответствовать (v2.1.277+).** Claude Code проверяет записи по всей отправляемой командной строке. `npm ci && docker compose build` остается в изолированной программной среде, если только другая запись не охватывает `npm ci`, а перенаправление на файл, `cd`, цикл или подстановка `$(...)` сохраняет весь вызов в изолированной программной среде. До версии 2.1.277 одна соответствующая команда выводила из песочницы весь вызов, включая команды, которые выполнялись до него ([anthropics/claude-code#81157](https://github.com/anthropics/claude-code/issues/81157)). Записи соответствуют тексту вызова: `git -C <path> push`, `/usr/local/bin/docker` и скрипт, который вызывает инструмент внутренне, не совпадают.
>
> Исключенная команда выполняется без ограничений файловой системы и прокси-сервера, поэтому она может достичь любого хоста, а не только `allowedDomains`. Ограничьте записи подкомандами, которым действительно необходимо покинуть песочницу, а не весь двоичный файл. Git через SSH на macOS является распространенным случаем (на Linux и WSL2 он работает в изолированной программной среде, если хост разрешен): исключения нужны только для сетевых операций, поэтому перечислите их и оставьте локальный git.
>
> Если песочница требуется администратору (`allowUnsandboxedCommands: false` из управляемых настроек или `--settings` или управляемый `allowManagedDomainsOnly`), записи в репозитории `.claude/settings.json` и `.claude/settings.local.json` игнорируются (v2.1.282+).
>
> ```json
> "excludedCommands": [
>   "git push *", "git pull *", "git fetch *",
>   "git clone *", "git ls-remote *", "git remote *", "git submodule *"
> ]
> ```
>
> При этом `git status`, `git diff`, `git log`, `git add` и `git commit` остаются внутри песочницы.

#### `sandbox.allowUnsandboxedCommands`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `true`

Разрешите командам отказываться от использования песочницы с помощью параметра `dangerouslyDisableSandbox`. Установите значение `false` для строгой песочницы, где все команды должны выполняться внутри песочницы или находиться в `excludedCommands`. На вкладке «Переопределения `/sandbox`» `false` отображается как **Strict Sandbox Mode**.

Начиная с версии 2.1.285, `false` в настройках пользователя, `--settings` или управляемых настройках сохраняется, даже если проект устанавливает `true` (ранее `true` проекта побеждал). `false` из управляемых настроек или `--settings` также делает песочницу обязательной для администратора: Claude Code тогда игнорирует настройки репозитория, которые могут ослабить ее, включая `excludedCommands`. См. [: песочница, необходимая администратору,](../security/sandbox-native.md#admin-required-sandbox).

#### `sandbox.enableWeakerNestedSandbox`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Включите более слабую песочницу для непривилегированных сред Docker (только Linux и WSL2). Снижает безопасность.

#### `sandbox.enableWeakerNetworkIsolation`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

(Только для macOS) Разрешить доступ к системной службе доверия TLS (`com.apple.trustd.agent`). Требуется для инструментов на основе Go, таких как `gh`, `gcloud` и `terraform`, при использовании `httpProxyPort` с прокси-сервером MITM и пользовательским центром сертификации. Снижает безопасность.

#### `sandbox.network.allowUnixSockets`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Определенные пути сокетов Unix, доступные в песочнице на macOS (для агентов SSH, локальных баз данных и т. д.). Игнорируется в Linux и WSL2, где фильтр seccomp не может проверять пути сокетов; используйте `allowAllUnixSockets` только после принятия его более широких границ. Случай входящих сообщений [для нескольких сеансов](../security/sandbox-native.md#cross-session-inbox-sockets) не требует этого исключения для обычных вызовов `SendMessage`.

#### `sandbox.network.allowAllUnixSockets`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Разрешите все соединения сокетов Unix в песочнице. Переопределяет `allowUnixSockets`. В Linux и WSL2 это единственный способ разрешить сокеты Unix, поскольку он пропускает фильтр seccomp, который в противном случае блокирует вызовы `socket(AF_UNIX, ...)`.

#### `sandbox.network.allowLocalBinding`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `false`

Разрешить привязку к портам локального хоста (только macOS). Команды песочницы могут затем прослушивать сетевые порты и подключаться к любому порту на локальном хосте, включая все остальные службы, прослушивающие его; затем неаутентифицированная локальная служба, такая как отладчик, может выполнять команду за пределами изолированной программной среды. В Linux и WSL2 `localhost` изолированной команды является личным для него, и этот ключ не имеет никакого эффекта.

#### `sandbox.network.allowedDomains`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Домены, разрешенные для исходящего сетевого трафика. Поддерживает подстановочные знаки, такие как `*.example.com`.

#### `sandbox.network.allowManagedDomainsOnly`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

При использовании `true` соблюдаются только `allowedDomains` и `WebFetch(domain:...)`, разрешающие правила из управляемых настроек. Неразрешенные домены блокируются без запроса. Запрещенные домены по-прежнему пользуются уважением из всех источников.

#### `sandbox.network.httpProxyPort`
**Тип:** номер
**Scope:** все
**По умолчанию:** нет

HTTP прокси-порт для пользовательского прокси (1–65535). Если не указано, Claude запускает собственный прокси.

#### `sandbox.network.socksProxyPort`
**Тип:** номер
**Scope:** все
**По умолчанию:** нет

Порт прокси-сервера SOCKS5 для пользовательского прокси (1–65535).

#### `sandbox.network.deniedDomains`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Команды изолированной программной среды доменов никогда не смогут достичь, даже если более широкий подстановочный знак `allowedDomains` позволит это сделать. Запрещенному хосту отказывают во всех режимах разрешений, а список `allowed_domains` для каждой команды в автоматическом режиме не может его открыть. Установленный в управляемых настройках или `--settings`, он также не позволяет репозиторию устанавливать прокси-порты (v2.1.285+). Адреса IPv6 используют форму в квадратных скобках: `"[::1]"` или `"[::1]:443"` (v2.1.229+).

#### `sandbox.filesystem.allowWrite`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Дополнительные пути, по которым могут писать изолированные команды. Объединены все области настроек. Также объединены с путями из `Edit(...)`, разрешающими правила разрешений.

Соглашения о префиксах **Path:** `/` = абсолютный, `~/` = домашний относительной, `./` или без префикса = относительный к проекту в настройках проекта / `~/.claude` относительной в настройках пользователя.

#### `sandbox.filesystem.denyWrite`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Пути, по которым команды песочницы не могут писать. Объединены с правилами запрета `Edit(...)`.

#### `sandbox.filesystem.denyRead`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Пути, по которым изолированные команды не могут читаться. Объединены с правилами запрета `Read(...)`.

#### `sandbox.filesystem.allowRead`
**Type:** массив строк
**Scope:** все
**По умолчанию:** `[]`

Пути для повторного разрешения доступа на чтение в регионах `denyRead`. Имеет приоритет над `denyRead`. Массивы объединяются во всех областях настроек.

Когда правила чтения перекрываются, более конкретный путь выигрывает в обоих направлениях: `denyRead: ["~/"]` с `allowRead: ["~/projects"]` открывает только это поддерево, а `allowRead: ["~/"]` с `denyRead: ["~/.env"]` блокирует этот один файл. Широкое разрешение не может молча повторно раскрыть тайну, которую скрывает точное отрицание.

#### `sandbox.filesystem.disabled`
**Тип:** логическое значение
**Scope:** пользователь, управляемый, `--settings` (настройки проекта игнорируются)
**По умолчанию:** `false`
**Начиная с:** v2.1.216

Пропустить изоляцию файловой системы, сохраняя изоляцию сети. Команды в песочнице получают неограниченный доступ на чтение и запись к хосту, а их выход остается ограниченным `allowedDomains`. Используйте, когда точка изолированной программной среды контролирует подключение команд, а не то, что они записывают.

Отключение слоя также отключает `filesystem.denyRead`, `credentials.files` и защиту собственных файлов настроек Claude Code, а также останавливает переопределение `$TMPDIR`. `credentials.envVars` по-прежнему применяется, поскольку очистка среды не зависит от уровня файловой системы.

В настройках проекта его нельзя установить, поэтому извлеченный репозиторий не может отключить изоляцию файловой системы. Если управляемые настройки вообще настраивают `sandbox.filesystem` или перечисляют любую запись `credentials.files`, ее можно установить только управляемыми настройками. `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` заставляет Claude Code игнорировать его из любого источника.

> При отключенном уровне файловой системы и автоматическом разрешении команд команда в песочнице может записывать файлы запуска оболочки, исполняемые файлы на `$PATH` или `~/.claude/settings.json` и использовать их для расширения собственного доступа при следующем запуске. Устанавливайте его только для тех рабочих нагрузок, которые, по вашему мнению, не будут увеличиваться.

#### `sandbox.credentials.files`
**Type:** массив `{ path, mode }`
**Scope:** all (`deny` только сужает, поэтому в любую область можно добавить один)
**По умолчанию:** `[]`
**Начиная с:** v2.1.187

Файлы учетных данных, которые можно скрыть от изолированных команд. `mode` принимает `"deny"`, который блокирует чтение так же, как `filesystem.denyRead`, и `"mask"` (v2.1.221+). При использовании `mask` в изолированных командах Linux и WSL2 считывается контрольная копия, а прокси-сервер заменяет реальное значение на выходе; на macOS файл просто не читается, тот же эффект, что и на `deny`, поэтому инструмент, который аутентифицируется с его помощью, перестает работать внутри песочницы. Частичная маскировка использует `extract` (регулярное выражение, обозначающее секрет), `decode: "jwt"` с `maskClaims`, `onExtractNoMatch` и `maskDuplicates` (v2.1.224+). `onExtractNoMatch: "warn"` по умолчанию пропускает запись, если шаблон ничему не соответствует, оставляя реальный файл доступным для чтения; используйте `deny`, когда секрет может присутствовать, но шаблон может его пропустить. Запись `mask` в каталоге, glob, файле размером более 8 МБ или файле, отличном от UTF-8, возвращается к `deny`. `mask` учитывается только из пользовательских, управляемых и `--settings` настроек.

Политика чтения песочницы по умолчанию охватывает **вся машина**, и нет встроенного списка запрещенных учетных данных, поэтому `~/.ssh` и `~/.aws/credentials` доступны для чтения каждой изолированной команде, пока вы их не перечислите. Пути подчиняются тем же правилам префиксов, что и `sandbox.filesystem.*`, и `deny` записи объединяются во всех областях: любая область может добавить одну, ни одна область не может удалить другую добавленную область.

```json
{
  "sandbox": {
    "credentials": {
      "files": [
        { "path": "~/.ssh", "mode": "deny" },
        { "path": "~/.aws", "mode": "deny" },
        { "path": "~/.gnupg", "mode": "deny" },
        { "path": "~/.config/gh", "mode": "deny" }
      ]
    }
  }
}
```

Проверено в версии 2.1.220: при наличии записи `ls ~/.ssh` из изолированной команды возвращает `Operation not permitted`, хотя каталог все еще отображается в списке домашнего каталога.

#### `sandbox.credentials.envVars`
**Type:** массив `{ name, mode, injectHosts? }`
**Scope:** `deny` из всех областей; `mask` от пользователя, управляемый, только `--settings`
**По умолчанию:** `[]`
**Начиная с:** v2.1.187 (`deny`), v2.1.199 (`mask`)

Переменные среды, которые следует скрыть от изолированных команд. В противном случае изолированные команды наследуют родительскую среду как есть, включая учетные данные, и это пробел, который оставляет открытой только запись `credentials.files`.

`deny` сбрасывает переменную перед запуском каждой изолированной команды. Это влияет только на изолированный Bash, поэтому серверы MCP сохраняют свои учетные данные: они выполняются как отдельные процессы, а не как изолированные команды. Подстановочные знаки, такие как `AWS_*`, не поддерживаются; перечислите каждую переменную. Файл запуска оболочки может отменить это: zsh считывает `~/.zshenv` при каждом запуске, поэтому экспортированная туда переменная снова устанавливается внутри изолированной команды, как измерено в версии 2.1.302 (см. поведение [по умолчанию](../security/sandbox-native.md#default-behavior) для зонда и защиты `CLAUDECODE`).

Для структурированных значений, таких как `DATABASE_URL` или JWT, `extract`, `decode`, `maskClaims` и `onExtractNoMatch`, инструменты синтаксического анализа продолжают работать (версия 2.1.224+). Запросы AWS SigV4 требуют маскировки `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY`, чтобы прокси-сервер мог их повторно подписать (v2.1.221+); группируйте переменные с разными именами с помощью `credentials.awsPairs` и используйте `credentials.sigv4` для пересылки потоковых загрузок, заранее назначенных URL-адресов или запросов SigV4A, которые прокси-сервер не может повторно подписать (обе v2.1.224+). `claude doctor` предупреждает, когда завершение TLS недоступно или запись `injectHosts` не может совпадать.

`mask` защищает учетные данные, сохраняя при этом работоспособность инструмента, выполняющего аутентификацию с его помощью. Команда видит дозорного для каждого сеанса; когда запрос покидает песочницу для одного из учетных данных `injectHosts`, прокси-сервер заменяет реальное значение. Команда и все, что она регистрирует, никогда не имеют настоящих учетных данных. Каждая запись `injectHosts` сама должна быть покрыта `allowedDomains`, а `network.tlsTerminate` требуется, поскольку прокси-сервер должен видеть содержимое запроса для замены. Без него маскирование не закроется: дозорный сервер достигнет сервера без изменений, аутентификация не удастся, а Claude Code сообщит о неправильной конфигурации при запуске.

```json
{
  "sandbox": {
    "network": { "tlsTerminate": {}, "allowedDomains": ["*.github.com"] },
    "credentials": {
      "envVars": [
        { "name": "ANTHROPIC_API_KEY", "mode": "deny" },
        { "name": "GH_TOKEN", "mode": "mask", "injectHosts": ["api.github.com"] }
      ]
    }
  }
}
```

`deny` выигрывает, когда одна и та же переменная появляется в обоих режимах в любой области видимости. Начните с `deny` и перемещайте переменную в `mask` только тогда, когда CLI фактически прерывается без нее, поскольку `mask` требует завершения TLS и разрешает прокси отправлять настоящие учетные данные указанным хостам.

Чтобы удалить Anthropic и учетные данные облачного провайдера из подпроцессов **all** независимо от изолированной программной среды, вместо этого установите `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB`.

#### `sandbox.network.tlsTerminate` `⚠️ Experimental`
**Type:** объект
**Scope:** пользователь, управляемый, `--settings` (настройки проекта игнорируются)
**Начиная с:** v2.1.199

Заставьте встроенный прокси завершать TLS. Требуется для записей `mask` в `credentials.envVars` и `credentials.files`. Это позволяет подменять учетные данные; он не добавляет фильтрацию контента.

#### `sandbox.network.strictAllowlist`
**Тип:** логическое значение
**Scope:** пользователь, управляемый, `--settings` (настройки проекта игнорируются)
**По умолчанию:** `false`
**Начиная с:** v2.1.219

Запретить изолированные команды для любого хоста за пределами белого списка вместо запроса. Список разрешенных — это `allowedDomains` плюс домены из разрешающих правил `WebFetch(domain:...)` или только управляемые записи, если установлен `allowManagedDomainsOnly`. Применяется только к изолированным командам: внутрипроцессные инструменты, такие как `WebFetch`, по-прежнему следуют своим правилам разрешений.

Включайте его в последнюю очередь, как только список доменов переживет неделю реальной работы. Перед этим он преобразует каждый отсутствующий домен из одноразового запроса в серьезный сбой.

#### `sandbox.allowAppleEvents`
**Тип:** логическое значение
**Scope:** пользователь, управляемый, `--settings` (настройки проекта игнорируются)
**По умолчанию:** `false`

Разрешите события Apple на macOS, которые песочница блокирует по умолчанию. Исправляет `open`, `osascript` и потоки аутентификации на основе браузера, завершающиеся ошибкой `-600`.

> Включение этого параметра удаляет изоляцию выполнения кода: изолированные команды могут запускать другие приложения без изолированной программной среды без запроса и отправлять AppleScript запущенным приложениям при условии получения запроса на согласие автоматизации macOS. Предпочитайте добавление конкретной команды в `excludedCommands`.

#### `sandbox.filesystem.allowManagedReadPathsOnly`
**Тип:** логическое значение
**Scope:** только управляемый
**По умолчанию:** `false`

При `true` учитываются только пути `allowRead` из управляемых настроек. Записи `allowRead` из пользовательских, проектных и локальных настроек игнорируются.

**Пример песочницы:**
```json
{
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true,
    "excludedCommands": ["git push *", "git fetch *", "docker *"],
    "filesystem": {
      "allowWrite": ["/tmp/build", "~/.kube"],
      "denyRead": ["~/.aws/credentials"]
    },
    "network": {
      "allowedDomains": ["github.com", "*.npmjs.org"],
      "allowLocalBinding": true
    }
  }
}
```

Исключения сокетов Unix намеренно отсутствуют в этом базовом варианте. Предоставление `/var/run/docker.sock` предоставит изолированный код управления демоном Docker и эффективный путь к хосту.

Пользовательское сообщение, добавленное к предупреждению о доверии плагину, отображаемому перед установкой. Используйте для контекста, специфичного для организации, например, для подтверждения проверки плагинов из внутреннего рынка.

### Конфигурация модели

#### `effortLevel`
**Type:** строка
**Scope:** все
**Значения:** `"low"` | `"medium"` | `"high"` | `"xhigh"`

Резервный вариант для модели без сохраненного выбора. Значения по умолчанию зависят от модели: Opus 5.5, Sonnet 5.5 и Haiku 5.5 используют `medium`; В Fable 5.1 используется `high`. Устаревшая версия Haiku 4.5 не имеет параметра усилия. Opus 5.5 игнорирует этот устаревший ключ в настройках пользователя, но явные значения проекта, локального, управляемого и `--settings` по-прежнему применяются.

#### `modelSettings`
**Type:** объект
**Scope:** все

Начиная с версии 2.1.251, `/effort` сохраняет здесь уровень активной модели. Подтвердите с помощью `Enter`, чтобы сохранить, или `s` только для этого сеанса. `max` предназначен только для сеанса и не может быть сохранен как `effortLevel`.

```json
{
  "modelSettings": {
    "claude-opus-5-5": { "effortLevel": "high" }
  }
}
```

В одном файле настроек уровень, специфичный для модели, имеет преимущество над резервным. Ко всем файлам применяется обычный приоритет настроек. `CLAUDE_CODE_EFFORT_LEVEL` отменяет выбранный уровень в соответствии с ограничениями организации. `/effort auto` очищает сохраненный выбор для активной модели.

#### `enforceAvailableModels`
**Тип:** логическое значение
**Scope:** все

Выполните сопряжение с `availableModels`, чтобы сохранить вариант `/model` по умолчанию в этом белом списке. Без этого параметра белый список сам по себе не ограничивает значение по умолчанию. См. официальную справку по настройкам модели [](https://code.claude.com/docs/en/settings-reference#enforceavailablemodels).

#### `modelOverrides`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Сопоставьте идентификаторы модели Anthropic с идентификаторами модели конкретного поставщика (например, ARN профиля вывода Bedrock). Каждый ключ представляет собой имя записи средства выбора модели; каждое значение представляет собой идентификатор модели поставщика.

```json
{
  "modelOverrides": {
    "claude-opus-4-6": "arn:aws:bedrock:us-east-1:123456789:inference-profile/anthropic.claude-opus-4-6-v1:0"
  }
}
```

**Ссылка на псевдонимы модели:**

| Псевдоним | Описание |
|-------|-------------|
| `"default"` | Рекомендуемая модель для вашего типа аккаунта |
| `"sonnet"` | Sonnet 5.5 на Anthropic API; псевдонимы облачных провайдеров могут разрешаться до 4.6 или 4.5. |
| `"opus"` | Opus 5.5 у большинства провайдеров; Opus 4.6 на Литейном заводе |
| `"haiku"` | Haiku 5.5 на Anthropic API (Claude Code v2.1.293+); Haiku 4.5 для облачных провайдеров |
| `"fable"` | Басня 5.1, если она доступна; Fable 5 через шлюз приложений Claude |
| `"best"` | Fable, если доступно, иначе Opus |
| `"sonnet[1m]"` | Sonnet с контекстом токена 1M |
| `"opusplan"` | Opus для планирования, Sonnet для исполнения. |

### Дисплей и UX

#### `statusLine`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Настройте пользовательскую строку состояния. Команда получает объект JSON на стандартный ввод с такими полями, как `context_window.used_percentage`, `rate_limits.five_hour.used_percentage` и т. д.

```json
  "statusLine": {
    "type": "command",
    "command": "~/.claude/statusline.sh",

  }
}
```

#### `fileSuggestion`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Настройте собственный скрипт для автозаполнения пути к файлу `@`. Команда получает JSON на стандартный вход с полем `query` и выводит пути к файлам, разделенные символами новой строки (максимум 15).

```json
{
  "fileSuggestion": {
    "type": "command",
    "command": "~/.claude/file-suggestion.sh"
  }
}
```

#### `outputStyle`
**Type:** строка
**Scope:** все
**По умолчанию:** `"Default"`

Управляет тем, как Claude взаимодействует на протяжении сеанса. Выберите с помощью `/output-style` или `/config`. Значение параметра чувствительно к регистру; команда принимает имена без учета регистра.

**Встроенные значения:**
- `"Default"`: нет инструкций по стилю, стандартная системная подсказка Claude Code.
- `"Proactive"`: сразу же приступает к реализации и делает разумные предположения по поводу рутинных решений; режим разрешений не изменен
- `"Concise"`: приводит результат, без преамбулы, повествования или заключительного резюме.
- `"Explanatory"`: добавляет блоки `Insight`, объясняющие выбор кода.
- `"Learning"`: добавляет блоки `Insight` и оставляет для вас сложные по дизайну детали на маркерах `TODO(human)`.

Значение, которое не соответствует точно имени стиля (например, `explanatory`), возвращается к значению по умолчанию. `/output-style` и меню `/config` сохраняют выбор в `.claude/settings.local.json`.

**Пользовательские стили:** ссылаются на имя стиля (имя файла без `.md`, если во вступительной части не задано `name`) из `.claude/output-styles/` для проекта или `~/.claude/output-styles/` для пользовательского стиля. В пользовательских стилях отсутствуют встроенные инструкции по разработке программного обеспечения Claude Code, если только их фронтальная часть YAML не устанавливает `keep-coding-instructions: true`. Выбор стиля применяется к следующему сообщению. Перезапустите, чтобы обнаружить вновь созданные файлы стилей.

```json
{ "outputStyle": "Explanatory" }
```

```json
{ "outputStyle": "strict-reviewer" }
```

Настройка сохраняется между сеансами. Пояснительные и обучающие жетоны увеличивают производительность; Быстрое кэширование может снизить стоимость повторного ввода, но не обесценивает генерируемый результат. См. [Section 9.7](../ultimate-guide.md#97-output-styles) для получения полной документации и примеров собственных стилей.

#### `spinnerTipsEnabled`
**Тип:** логическое значение
**Scope:** все
**По умолчанию:** `true`

Покажите подсказки в счетчике, пока Claude работает.

#### `spinnerVerbs`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Настройте глаголы действия, отображаемые в счетчике, и сообщения о продолжительности хода. Установите для `mode` значение `"replace"`, чтобы использовать только ваши глаголы, или `"append"`, чтобы добавить их к значениям по умолчанию.

```json
{
  "spinnerVerbs": {
    "mode": "replace",
    "verbs": ["Cooking", "Brewing", "Crafting", "Conjuring"]
  }

```

#### `spinnerTipsOverride`
**Type:** объект
**Scope:** все
**По умолчанию:** нет

Переопределить кончики счетчиков с помощью пользовательских строк. `tips`: массив строк. `excludeDefault`: при `true` показывать только пользовательские подсказки.

Контролируйте, учитывает ли средство выбора файлов `@` шаблоны `.gitignore`.

## <a name="quick-reference"></a>Шпаргалка

| Задача |  |
|------|--------------------|
| Установить модель по умолчанию | `model` в настройках или `ANTHROPIC_MODEL` env var |
| Блокировка выбора модели | Массив `availableModels` |
| Бесшумная телеметрия | `DISABLE_TELEMETRY=1` или `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` |
| Автоматическое одобрение bash | `permissions.defaultMode: "acceptEdits"` |
| Блокировать конфиденциальные файлы | `permissions.deny: ["Read(.env)"]` |
| Уменьшить сжатие контекста | `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=70` |
| Установить язык ответа | `language: "japanese"` |
| Пользовательский текст счетчика | `spinnerVerbs` + `spinnerTipsOverride` |
| Удалить атрибуцию | `attribution.commit: ""`, `attribution.pr: ""` |
| Прикрепить к стабильным выпускам | `autoUpdatesChannel: "stable"` |
| Токен динамической аутентификации | `apiKeyHelper: "/path/to/script.sh"` |
| Большой монорепозиторий | `worktree.symlinkDirectories` + `worktree.sparsePaths` |
| Включить песочницу | `sandbox.enabled: true` |
| Доверять всем серверам проекта MCP | `enableAllProjectMcpServers: true` |
