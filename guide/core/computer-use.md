# Использование компьютера в Claude Code

Использование компьютера позволяет Claude Code управлять утвержденными приложениями macOS и проверять их видимое содержимое на экране в интерактивном сеансе CLI. Это предварительная версия исследования для пользователей Pro и Max. Он недоступен в планах Team и Enterprise, в `claude -p` и в CLI на Linux или Windows. Текущая документация по использованию компьютера [Anthropic](https://code.claude.com/docs/en/computer-use) является авторитетным лицом по продукту для этой страницы.

Используйте его для собственного приложения, симулятора или инструмента только с графическим интерфейсом, который не имеет более точной интеграции. Для задачи браузера выберите [Claude в Chrome](https://code.claude.com/docs/en/chrome); для службы с API отдайте предпочтение серверу MCP. Официальный порядок выбора инструментов: MCP, Bash, Chrome, затем использование компьютера.

## Включить встроенный сервер

Использование компьютера — это встроенный сервер MCP с именем `computer-use`, отключенный до тех пор, пока он не будет включен в проект.

1. Запустите интерактивный сеанс Claude Code и запустите `/mcp`.
2. Выберите `computer-use` и выберите **Enable**. Проект сохраняет эту настройку.
3. Когда macOS спросит, предоставьте **Accessibility** для щелчка, ввода и прокрутки, а также **Screen Recording** для захвата экрана. Разрешение на запись экрана может потребовать перезапуска Claude Code.

Сервер появляется только в соответствующем интерактивном сеансе macOS, Pro или Max, аутентифицированном claude.ai. `/status` помогает проверить план. Вход только для стороннего поставщика, включая Amazon Bedrock, агентскую платформу Google Cloud или Microsoft Foundry, не делает поверхность CLI доступной.

## Чем может управлять Claude

Первый запрос приложения в сеансе представляет собой запрос на одобрение. Он называет приложения, любые дополнительные разрешения, такие как доступ к буферу обмена, и количество других приложений, которые будут скрыты. Одобрение действует только в течение этого сеанса.

| Класс приложения | Документированный уровень контроля | Проверка перед одобрением |
|---|---|---|
| Браузеры и торговые платформы | Только просмотр | Видимые данные по-прежнему могут попасть в модель через снимки экрана. |
| Терминалы и IDE | Нажмите только | Приглашение предупреждает, что приложение эквивалентно доступу к оболочке. |
| Искатель | Полный контроль | В приглашении предупреждается, что он может читать или записывать любой файл. |
| Системные настройки | Полный контроль | Подсказка предупреждает, что может изменить настройки системы. |
| Другие одобренные приложения | Полный контроль | Убедитесь, что приложение и задача находятся в пределах заданных границ. |

Claude скрывает другие видимые приложения, пока управляет экраном, а затем восстанавливает их после поворота. Терминал остается видимым и не отображается на скриншотах. Только один сеанс Claude Code может использовать использование компьютера одновременно: его блокировка на уровне всего компьютера сохраняется до завершения сеанса, даже после завершения немедленной задачи.

## Доступ к данным и граница безопасности

Использование компьютера происходит на реальном рабочем столе, а не внутри изолированной Bash границы [](../security/sandbox-isolation.md). Claude Code автоматически уменьшает размеры снимков экрана перед отправкой их в модель, но это не делает видимые данные приложения безопасными для раскрытия. Рассматривайте каждое одобренное приложение и его видимое содержимое как часть входной границы модели.

Claude Code документирует одобрение каждого приложения, предупреждения для приложений с широким охватом, исключение снимков экрана терминала, блокировку одного сеанса и `Esc` в качестве глобальной остановки. В нем также говорится, что Claude проверяет действия и отмечает возможное внедрение подсказок из содержимого на экране. Эти меры контроля снижают риск; они не преобразуют настольное приложение в изолированную песочницу.

Прежде чем включать сервер для конфиденциального рабочего процесса:

- закройте приложения, не относящиеся к задаче;
- используйте специальную локальную учетную запись или данные прибора, когда производственные данные не нужны;
- утвердить наименьший полезный набор приложений;
- держать человека у терминала на случай любого потока, который может изменить данные, деньги, учетные данные или конфигурацию системы;
- используйте [Tool и ссылку на разрешения](./tools-reference.md) и [руководство по усилению безопасности](../security/security-hardening.md) для элементов управления за пределами этой функции.

## Работайте и останавливайтесь безопасно

Дайте задаче конкретное условие успеха, например открытие определенного экрана, воспроизведение дефекта макета в указанном размере или запись состояния потока симулятора. Попросите скриншоты или письменный результат, если это необходимые вам доказательства. Использование компьютера может сочетать шаги графического интерфейса с Bash, но снимок экрана свидетельствует только о видимом состоянии, а не о внутреннем эффекте.

Нажмите `Esc` в любом месте, чтобы прервать текущее действие по использованию компьютера. `Ctrl+C` в терминале также останавливает его. Оба восстанавливают скрытые приложения, но блокировка использования компьютера сохраняется до завершения сеанса Claude Code. Не запускайте второй сеанс, ожидая, что он захватит рабочий стол.

## Виды отказов и проверка

| Симптом | Документированная причина или предел | Проверка или ответ |
|---|---|---|
| `computer-use` отсутствует в `/mcp` | Требования к платформе, плану, аутентификации или интерактивному сеансу не соблюдены. | Проверьте аутентификацию macOS, `/status`, claude.ai и убедитесь, что сеанс не был запущен с `-p`. |
| Другой сеанс содержит функцию | Блокировка на уровне компьютера действует до завершения сеанса. | Завершите указанный сеанс. Сбойный процесс снимает блокировку после того, как Claude Code обнаруживает, что он исчез. |
| macOS повторяет запрос разрешения. | Для записи экрана может потребоваться перезапуск процесса запроса. | Выйдите из Claude Code, начните новый сеанс и подтвердите запись экрана для приложения терминала в настройках macOS. |
| Текст или элементы управления трудно читать | Скриншоты автоматически уменьшаются, а целевой размер не настраивается. | Увеличьте размер текста или элемента управления в приложении, а затем повторите проверку видимого состояния. |
| Шаг графического интерфейса выглядит успешным | Состояние экрана не доказывает устойчивое изменение или последующий результат. | Подтвердите это собственным подтверждением приложения, обратным чтением, тестом или другими доказательствами, специфичными для задачи. |
