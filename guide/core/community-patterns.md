# Шаблоны сообщества и ссылки

Краткий справочник по шаблонам сообщества Claude Code, терминам рабочих процессов и инженерному словарю искусственного интеллекта. Стандартные термины CS/DevOps (JWT, CI/CD, REST) ​​исключены; поищите их в другом месте.
