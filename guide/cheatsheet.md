# Шпаргалка Claude Code

**Ежедневный справочник**. Для компактных изданий для печати используйте шпаргалки [на английском и французском языках](../whitepapers/README.md).

**Автор**: Florian BRUNIAUX | Внешний директор по ИИ

**Написано с помощью**: Claude (Anthropic)

**Версия**: 3.46.0 | **Последнее обновление**: 27 октября 2026 г.

## <a name="essential-commands"></a>Основные команды

Это избранные ежедневные команды. Доступность зависит от вашей версии, провайдера и плана: полный список находится в [§10.1 руководства](./ultimate-guide.md#101-commands-table), а всегда актуальная официальная ссылка — [code.claude.com/docs/en/commands](https://code.claude.com/docs/en/commands).

| Команда | Действие |
|---------|--------|
| `/help` | Контекстная помощь |
| `/powerup` | Интерактивные анимированные уроки, обучающие возможностям Claude Code |
| `/clear` | Сбросить разговор |
| `/compact` | Освободите контекст |
| `/status` | Настройки на вкладке Статус: версия, модель, аккаунт, подключение. |
| `/context` | Подробная разбивка токенов |
| `/plan` | Войдите в режим планирования (без изменений). Выйти, утвердив план или `Shift+Tab` |
| `/model` | Выберите модель и сохраните значение по умолчанию; нажмите `s` в средстве выбора только для этого сеанса |
| `/autocompact [auto\|500k]` | Выберите окно автоматического сжатия или восстановите модель по умолчанию. |
| `/output-style [style]` | Выберите «По умолчанию», «Проактивный», «Краткий», «Пояснительный», «Обучающий» или собственный стиль. |
| `/insights` | Аналитика использования + отчет об оптимизации |
| `/code-review [level]` | Проверьте разницу на наличие ошибок, `--fix` применяет их, `ultra` запускает в облаке. |
| `/simplify` | Проверка измененного кода только с очисткой: повторное использование, упрощение, эффективность (применяются исправления очистки; используйте `/code-review` для исправления ошибок) |
| `/security-review` | Сканируйте различия в ветках на наличие рисков внедрения, аутентификации и раскрытия данных. |
| `/batch` | Масштабные рефакторинги с использованием 5–30 параллельных агентов рабочих деревьев. |
| `/subtask <task>` | Передайте побочную задачу разветвленному субагенту, который будет отчитываться здесь (версия 2.1.212+). |
| `/teleport` | Сеанс телепортации из сети |
| `/tasks` | Мониторинг фоновых задач |
| `/remote-env` | Настройка облачной среды |
| `/remote-control` (`/rc`) | Подключите этот локальный сеанс к web/mobile; Team/Enterprise требует разрешения владельца |
| `/mobile` | QR-код для загрузки мобильного приложения Claude |
| `/fast` | Переключить более быстрый выход Opus; Opus 5.5 стоит $8/$40 за MTok в быстром режиме |
| `/voice [hold\|tap\|off]` | Переключить голосовой ввод (удерживайте пробел, чтобы говорить, отпустите, чтобы отправить). Требуется учетная запись Claude.ai. |
| `/recap` | Однострочный отчет о текущем сеансе по запросу (v2.1.108) |
| `/effort [level\|auto\|status\|ultracode [on\|off]]` | Усилие: low/medium/high/xhigh/max (макс. только для сеанса) или автоматически; `status` распечатывает его (v2.1.111) |
| `/tui [default\|fullscreen]` | Установите рендерер и перезапустите диалог без изменений; `fullscreen` не мерцает (v2.1.110) |
| `/focus` | Переключить вид с минимальным фокусом (только полноэкранный рендеринг), отдельно от Ctrl+O (v2.1.110) |
| `/auto-mode-setup` | Пошаговая настройка, которая считывает проект и последние сеансы для обучения автоматическому режиму вашей среды (v2.1.228+ для Pro/Max/Team, v2.1.283+ для Enterprise или консольного ключа API) |
| `/fewer-permission-prompts` | Сканируйте расшифровки и предложите список разрешенных инструментов, доступных только для чтения (поставляется как `/less-permission-prompts` в версии 2.1.111). |
| `/btw [question]` | Наложение дополнительных вопросов: эфемерный агент только для чтения, без загрязнения истории, без инструментов. |
| `/loop [interval] [prompt]` | Повторяйте с фиксированным интервалом или позвольте Claude выбрать интервал, если он опущен; Срок действия повторяющихся задач истекает через 7 дней (см. справочник по планированию). |
| `/usage` (`/cost`, `/stats`) | Токен + стоимость использования модели, лимиты плана, график активности (объединены в версии 2.1.118) |
| `/ultrareview` | Проверка кода многоагентного облака, теперь псевдоним `/code-review ultra` (v2.1.114). `/code-review --max-findings <n>\|all` ограничивает или увеличивает счетчик находок до `default` (v2.1.288) |
| `/goal [condition\|clear]` | Автономный многооборотный режим: Claude работает до тех пор, пока не будет выполнено условие, наложение в реальном времени показывает elapsed/turns/tokens (v2.1.139) |
| `/scroll-speed` | Настройте скорость прокрутки колесика мыши с помощью интерактивного ползунка предварительного просмотра в реальном времени; только полноэкранный рендеринг (v2.1.139) |
| `/rename [name]` | Назовите или переименуйте текущий сеанс |
| `/copy [N]` | Скопируйте N-й последний ответ; средство выбора блока кода или полного ответа |
| `/doctor` | Полная проверка настройки: установка, настройки, хуки, навороты `CLAUDE.md`, неиспользуемые навыки (v2.1.205+). `/doctor prompt-audit` помечает шаблоны подсказок, написанные для старых моделей в CLAUDE.md, навыки, агенты и команды (v2.1.283) |
| `/debug` | Включите ведение журнала отладки и устраняйте неполадки из журнала сеанса. |
| `/exit` | Выйти (или Ctrl+D) |

## <a name="permission-modes"></a>Режимы разрешения

| Режим | Редактирование | Исполнение |
|------|---------|-----------|
| Руководство (`default`) | Действуют правила разрешения | Действуют правила разрешения |
| принятьРедактирование | Авто | спрашивает |
| Режим планирования | Никаких изменений файлов | Разрешены инструменты исследования, доступные только для чтения. |
| авто | Классификатор решает | Классификатор решает |
| не спрашивай | Только если в разрешенных правилах | Только если в разрешенных правилах |
| обход разрешений | Авто | Авто (только CI/CD) |

**Shift+Tab** для переключения режимов. Начиная с версии 2.1.283, сеансы интерактивного терминала и VS Code запускаются в `auto`, когда режим разрешений не настроен; установите `permissions.defaultMode`, чтобы выбрать другой. `/auto-mode-setup` настраивает классификатор для вашей среды

## Типичный рабочий процесс

```
1. Start session      → claude
2. Check context      → /status
3. Plan Mode          → Shift+Tab × 2 (for complex tasks)
4. Describe task      → Clear, specific prompt
5. Review changes     → Always read the diff!
6. Accept/Reject      → Enter/Esc (y/n only via confirm:yes/confirm:no bindings, v2.1.280)
7. Verify             → Run tests
8. Commit             → When task complete
9. /compact           → When context >70%
```

## Управление контекстом (КРИТИЧНО)

### Статуслайн

```
Model: Sonnet | Ctx: 89.5k | Cost: $2.11 | Ctx(u): 56.0%
```
**Смотреть `Ctx(u):`** → >70% = `/compact`, >85% = `/clear`

**Расширенная строка состояния ([ccstatusline](https://github.com/sirmalloc/ccstatusline)):** Добавить в `~/.claude/settings.json`:
```json
{ "statusLine": { "type": "command", "command": "npx -y ccstatusline@latest", "padding": 0 } }
```

### Контекстные пороги

| Контекст % | Статус | Действие |
|-----------|--------|--------|
| 0-50% | Зеленый | Работайте свободно |
| 50-70% | Желтый | Будьте избирательны |
| 70-90% | Апельсин | `/compact` сейчас |
| 90%+ | Красный | Требуется `/clear` |

### Действия по симптомам

| Знак | Действие |
|------|--------|
| Краткие ответы | `/compact` |
| Частое забывание | `/clear` |
| >70% контекста | `/compact` |
| Задача выполнена | `/clear` |

### Команды восстановления контекста

| Команда | Использование |
|---------|-------|
| `/compact` | Подведение итогов и свободный контекст |
| `/clear` | Новый старт |
| `/rewind` | Отменить недавние изменения |
| `claude -c` | Возобновить последний сеанс (флаг CLI) |
| `claude -r <id>` | Возобновить конкретный сеанс (флаг CLI) |

Выбирайте наименьшую структуру управления, которая безопасно решает задачу: ограниченный цикл для одной повторяющейся задачи; явный граф для маршрутизации, соединений, параллелизма, прерываний или устойчивого восстановления; использование репозитория для повторяемого поведения проекта; и оркестратор для нескольких запусков или очередей. Оцените точную пару модель-оборудование для ограниченной задачи кодирования. Вводите оркестровку только тогда, когда координация является ограничением. Оптимизатор жгутов находится за пределами четырех рабочих уровней и меняет возможные жгуты в соответствии с отдельным протоколом оценки.

| **Режим планирования** | `Shift+Tab × 2` или `/plan` | Исследуйте, не изменяя |
| **OpusPlan** | `/model opusplan` | Opus для планирования, Sonnet для исполнения. |

> **Подтвержден 27 октября 2026 г.**: Opus 5.5, Sonnet 5.5 и Haiku 5.5 по умолчанию — `medium`; В Fable 5.1 по умолчанию используется `high`. Только устаревшая версия Haiku 4.5 не имеет параметра усилия. `ultrathink` добавляет инструкцию по обоснованию терна без изменения усилия API.

| Контроль | Действие | Упорство |
|---------|--------|-------------|
| **Option+T / Alt+T** | Переключить мышление на поддерживаемые модели; Opus 5.5, Sonnet 5.5, Haiku 5.5 и Fable всегда думают | Сессия |
| Слайдер **`/effort` или `/model`** | Выберите поддерживаемый уровень; `Enter` сохраняется для каждой модели, `s` применяется один раз. | За модель или сеанс |
| **`/effort max`** | Наивысшая поддержка усилий | Сессия |
| **`CLAUDE_CODE_EFFORT_LEVEL`** | Переопределить усилие в среде запуска | Технологическая среда |
| **`modelSettings` / `effortLevel`** | Сохраняйте `low`, `medium`, `high` или `xhigh`; не `max` | Настройки |
| **`effort` в области навыков** | Переопределить усилие во время действия навыка | Призыв |

**Совет по стоимости**: попробуйте уменьшить поддерживаемое усилие для ограниченных задач, а затем проверьте результат. В Opus 5.5 изменение усилия является элементом управления; отключение мышления не имеет никакого эффекта.

**Усилия по каждому навыку**: добавьте `effort: low` к механическим навыкам (фиксация, синхронизация, поддержка) и `effort: high` к аналитическим (аудит безопасности, проверка архитектуры). Автоматически переопределяет настройки сеанса.

Рабочий процесс **OpusPlan**: `/model opusplan` → `Shift+Tab × 2` (планирование с помощью Opus) → `Shift+Tab` (выполнение с помощью Sonnet)

**Требуется для**: возможности >3 файлов, архитектура, сложная отладка

### Динамическое переключение модели (середина сессии)

**Шаблон**: Пуск Sonnet (скорость) → поменять Opus (сложность) → назад Sonnet

**Workflow**:

**Рекомендации**:

## Создание пользовательских компонентов

### Агент (`.claude/agents/my-agent.md`)
```yaml
---
name: my-agent
description: Use when [trigger]
model: sonnet
tools: Read, Write, Edit, Bash
---
# Instructions here
```

### Навык: вызываемый пользователем (`.claude/skills/my-command/SKILL.md`)
```markdown
---
description: Brief description
argument-hint: "<required_arg> [--flag]"
disable-model-invocation: true
---
# Command Name
Instructions for what to do...
$ARGUMENTS[0] $ARGUMENTS[1] (or $0 $1) - user args
```

### Динамический рабочий процесс (`.claude/workflows/name.js`)

```js
export const meta = {
  name: 'my-workflow',
  description: 'What this orchestrates',
  phases: [{ title: 'Analyze' }, { title: 'Verify' }],
};
// meta must be the first statement, a pure literal (no variables/spreads)

export default async function ({ agent, parallel, pipeline, phase, log, args, budget }) {
  phase('Analyze');
  const results = await parallel(
    ITEMS.map((item) => () => agent(`Analyze ${item}.`, { schema: MY_SCHEMA }))
  );
  return results.filter(Boolean);
}
```

Триггер: введите `ultracode` в командной строке (или спросите своими словами). Монитор: `/workflows`.

| Примитивный | Поведение |
|-----------|----------|
| `agent(prompt, { schema })` | Создать один субагент; возвращает текст или проверенный JSON |
| `parallel([() => agent(...)])` | Барьер: все запускаются одновременно, возвращаются, когда финиширует самый медленный. |
| `pipeline(items, stage1, stage2)` | Никаких барьеров: предметы проходят этапы независимо друг от друга. |
| `phase(title)` | Обновление метки прогресса в пользовательском интерфейсе `/workflows` |
| `log(msg)` | Выдать сообщение о ходе выполнения |
| `budget.remaining()` | Защита открытых циклов (в противном случае бюджет достигнет предела в 1000 агентов) |

Ключевые правила: оркестратор потребляет 0 токенов; `Date.now()`/`Math.random()` недоступен (прерывает возобновление); отфильтровать результаты `parallel()` с помощью `.filter(Boolean)`.

Полная ссылка: [Динамические рабочие процессы](./workflows/dynamic-workflows.md)

## Управление задачами (v2.1.16+)

**Availability**: новые модели, включая Opus 5.5, Sonnet 5.5 и Fable, по умолчанию не получают инструменты отслеживания задач. Начните с `CLAUDE_CODE_ENABLE_TODO_TOOLS=1 claude`, чтобы согласиться. `CLAUDE_CODE_ENABLE_TASKS=0` выбирает устаревшую версию TodoWrite только там, где включены инструменты задач. [Официальная доступность инструмента](https://code.claude.com/docs/en/tools-reference#task-tool-availability).

**Доступны две системы:**

| Система | Когда использовать | Упорство |
|--------|-------------|-------------|
| **Задачи API** (v2.1.16+) | Многосессионные проекты, зависимости | ✅ Диск (`~/.claude/tasks/`) |
| **TodoWrite** (устаревшая версия) | Простой односессионный | ❌Только сеанс |

### Задачи Команды API

```bash
# Enable persistence across sessions
export CLAUDE_CODE_TASK_LIST_ID="project-name"
CLAUDE_CODE_ENABLE_TODO_TOOLS=1 claude

# Inside Claude: Create task hierarchy
> "Create tasks for auth system with dependencies"

# Resume later (new session)
export CLAUDE_CODE_TASK_LIST_ID="project-name"
CLAUDE_CODE_ENABLE_TODO_TOOLS=1 claude
> "TaskList to see current state"
```

**Ключевые возможности:**
- 📁 **Persistent**: выдерживает завершение сеанса, сжатие контекста.
- 🔗 **Dependency**: Задача A блокирует задачу B.
- 🔄 **Multi-session**: передача состояния на несколько терминалов.
- 📊 **Status**: ожидание → в_прогрессе → завершено

**⚠️ Ограничение**: в TaskList отображаются только `id`, `subject`, `status`, `blockedBy`.
Для `description`/`metadata` → используйте `TaskGet(taskId)` для каждой задачи.

**Tip**: сохраните ключевую информацию в `subject` для быстрого сканирования.

**Флаг миграции** (v2.1.19+):
```bash
# Revert to old TodoWrite system
CLAUDE_CODE_ENABLE_TODO_TOOLS=1 CLAUDE_CODE_ENABLE_TASKS=0 claude
```

## <a name="the-golden-rules"></a>Золотые правила

1. **Всегда проверяйте различия** перед принятием
2. **Используйте `/compact`** до того, как контекст станет критическим (>70%)
3. **Будьте конкретны** в запросах (ЧТО, ГДЕ, КАК, ПРОВЕРИТЬ)
4. **Первый режим планирования** для задач complex/risky
5. **Создайте CLAUDE.md** для каждого проекта.
6. **Часто фиксируйте** после каждой выполненной задачи.
7. **Узнать, что отправлено**: подсказки, файлы, результаты MCP → Anthropic ([обучение по отказу от участия](https://claude.ai/settings/data-privacy-controls))

## Краткий справочник по инструментам поиска

Быстрое решение (5 секунд): точный текст → `rg` | точное имя → `rg`/Серена | концепция → грепай | структура → ast-grep

| Задача | Инструмент | Команда |
|------|------|---------|
| «Найти комментарии TODO» | `rg` | `rg "TODO"` |
| «Найти код авторизации» | `grepai` | `grepai search "authentication"` |
| «Кто вызывает логин?» | `grepai` | `grepai trace callers "login"` |
| «Получить файловую структуру» | `Serena` | `serena get_symbols_overview` |
| «Асинхронность без try/catch» | `ast-grep` | `ast-grep "async function $F"` |

Скорость: `rg` (~20 мс) → Серена (~100 мс) → ast-grep (~200 мс) → grepai (~500 мс)

> Полные рабочие процессы: [workflows/search-tools-mastery.md](./workflows/search-tools-mastery.md)
