# Инфографика модельных осей

Две редакционные инфографики на английском языке, созданные с помощью Google Gemini (`gemini-3-pro-image`) и проверенные на наличие текста, стрелок и претензий к страницам, на которых они используются. Они суммируют прозу путеводителя; они не описывают внутреннюю архитектуру Claude, которую Anthropic публично не документирует.

| Тема | Изображение | Используется в |
| --- | --- | --- |
| Восемь терминов, семь осей | [Английская инфографика](model-axes-en-gemini.webp) | [AI Границы концепции](../../core/ai-concept-boundaries.md#architecture-size-class-modality-and-task) |
| Память имеет значение для каждого эксперта, вычисления имеют значение для двоих | [Английская инфографика](moe-memory-compute-en-gemini.webp) | [Локальный или облачный вывод](../../ecosystem/local-vs-cloud-inference.md#what-actually-fits-named-models) |

Инфографика осей сортирует восемь общих терминов модели по осям, которые они описывают: класс модели, архитектура, размерный класс, модальность ввода, цель обучения, метка задачи или продукта и единица представления. Ярлыки не являются исключительными категориями; одна модель может сочетать в себе несколько из них. Таблица страниц дает каждой строке источник и изменения, которые она вносит для пользователя Claude Code.

В качестве примера в инфографике Министерства энергетики используется опубликованная маршрутизация Mixtral: два из восьми экспертов на каждый токен на каждом уровне. Все эксперты остаются в памяти, а вычисления ведут только избранные. В других моделях MoE используются другие подсчеты экспертов, а также некоторые альтернативные плотные слои и слои MoE. Источники: [Mixtral of Experts](https://arxiv.org/html/2401.04088), [Коммутационные трансформаторы](https://ar5iv.labs.arxiv.org/html/2101.03961).

Оба ресурса представляют собой файлы WebP размером 1376 × 768, преобразованные из собственных ответов JPEG с качеством 90, без обрезки, заполнения или масштабирования. Они следуют кремовому миллиметровому стилю инфографики обзора [harness](../harness-review/README.md). Страницы содержат эквивалентную прозу и ссылки на полноразмерные изображения для узких экранов.
