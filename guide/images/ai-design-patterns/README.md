# Инфографика шаблонов проектирования ИИ

Четыре редакционные диаграммы на английском и французском языках для страницы [AI Design Patterns](../../core/ai-design-patterns.md), созданные с помощью Google Gemini (`gemini-3-pro-image`) и проверенные слово за словом на основе набора данных в [`machine-readable/ai-design-patterns.json`](../../../machine-readable/ai-design-patterns.json). Они не содержат измеренных значений.

| Тема | Английский | Французский |
| --- | --- | --- |
| Три поколения шаблонов проектирования | [Английская инфографика](lineage-en.webp) | [Французская инфография](lineage-fr.webp) |
| Детали подвески Claude Code и их наиболее близкий классический образец | [Английская инфографика](harness-map-en.webp) | [Французская инфография](harness-map-fr.webp) |
| Где аналогия нарушается | [Английская инфографика](analogy-breaks-en.webp) | [Французская инфография](analogy-breaks-fr.webp) |
| Десять антипаттернов упряжи в четырех семьях | [Английская инфографика](failure-map-en.webp) | [Французская инфография](failure-map-fr.webp) |

Только на английском языке:

- [Обзор 29 шаблонов](overview-en.webp), сгруппированных в шесть семейств.
- По одной карте на шаблон в [`patterns/`](patterns/), названной в честь идентификатора шаблона (например, [`patterns/circuit-breaker.webp`](patterns/circuit-breaker.webp)): 21 классическая карта (классическое намерение, механизм Claude Code, при поломке проверка запуска) и 8 собственных карт агента (что он делает, механизм Claude Code, что нового). Тексты карточек представляют собой короткие версии полей набора данных, а альтернативный текст каждой карточки в наборе данных повторяет каждую видимую строку.

Карта жгутов показывает ближайший классический аналог для каждой детали, а не эквивалентность. В карте отказов используются три категории MAST ([Cemri и др.](https://arxiv.org/abs/2503.13657)) плюс четвертая категория для механики Claude Code; отнесение каждого антипаттерна к категории является чтением руководства. Названия шаблонов во французских версиях остаются на английском языке, поскольку разработчики используют их на английском языке.

Все 38 ресурсов представляют собой файлы WebP размером 1376 × 774 в целевой палитре: кремовый фон, угольные чернила, ярко-оранжевый акцент. Преобразование добавляет три пикселя выше и ниже созданной композиции размером 1376 × 768, чтобы получить соотношение 16:9 без обрезки или масштабирования. Страница руководства содержит то же содержание, что и текст, поэтому изображения никогда не являются единственным источником претензии.
