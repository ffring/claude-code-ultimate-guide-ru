# Модуль 01: Установка и настройка

**Time**: 15 минут | **Сложность**: ⭐ Новичок

## Цель

Установите и запустите Claude Code в своей системе. Убедитесь, что это работает с вашей первой командой.

---

## Что вы узнаете

- Установите Claude Code для вашей платформы (macOS/Linux/Windows)
- Поймите базовый цикл подсказки → ответа.
- Запустите свою первую команду
- Доступ к справочной системе

---

## Установка

### macOS (рекомендуется)

```bash
brew install anthropic/tap/claude-code
```

Verify:
```bash
claude --version
```

### Linux

```bash
curl -sSL https://dl.claudecode.com/install.sh | bash
```

Verify:
```bash
claude --version
```

### Windows

Загрузите установщик с https://dl.claudecode.com/windows или используйте:

```powershell
iex ((New-Object System.Net.WebClient).DownloadString('https://dl.claudecode.com/install.ps1'))
```

### Docker (любая платформа)

```bash
docker run -it anthropic/claude-code:latest
```

## Первый запуск

Перейдите в любой каталог проекта и запустите Claude:

```bash
cd ~/my-project
claude
```

Вы увидите:

```
Claude Code v2.x.x ready
Project: ~/my-project (git: main)
Context: 0% · Tokens available: 200,000

Type /help for commands or ask me anything
>
```

## <a name="essential-commands"></a>Основные команды

| Команда | Цель |
|---------|---------|
| `/help` | Показать все доступные команды |
| `/status` | Проверьте использование контекста и состояние сеанса |
| `/clear` | Начать заново (очищает историю разговоров) |
| `Ctrl+C` | Отменить текущую операцию |
| `/exit` | Закрывать Claude Code |

## Ваши первые 5 минут

### <a name="exercise-1-view-available-commands"></a>Упражнение 1. Просмотр доступных команд
```bash
/help
```

Просмотрите список команд. Уведомление:
- **Рабочий процесс**: `/plan`, `/rewind`, `/think`
- **Навигация**: `/goto`, `/read`
- **Memory**: загрузка памяти при запуске
- **Расширенный**: `/model`, `/mode`

### Упражнение 2. Проверка состояния сеанса
```bash
/status
```

Вы увидите:
- Процент использования контекста
- Доступные токены
- Текущий проект
- Git-ветвь

### Упражнение 3. Спросите Claude о чем-нибудь.

```
What files are in my project?
```

Claude прочитает структуру проекта и ответит. Это основной цикл:

```
Your prompt → Claude reads files → Claude suggests changes → You review → Apply
```

### Упражнение 4. Просмотр предлагаемого изменения

Если Claude предложит внести изменения в код, вы увидите:
1. Описание изменения
2. Представление `diff` (что такое added/removed)
3. Подсказка принять или отклонить

**Rule**: Всегда проверяйте различия перед принятием. Это защитит вас от неожиданных изменений.

## Основная концепция: цикл

Каждое взаимодействие следует этому шаблону:

```
┌─────────────┐
│ You ask     │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Claude      │
│ reads files │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Claude      │
│ suggests    │
│ changes     │
└──────┬──────┘
       │
       ▼
┌──────────────────┐
│ You review diff  │
│ and approve      │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Changes applied  │
│ to your files    │
└──────────────────┘
```

## Ключевые понятия

### Сессии

Каждый раз, когда вы бежите `claude`, ты начинаешь новый **сессия**. Сеанс – это разговор с Claude это сохраняется, пока вы используете Claude Code.

- Сессии **не сохраняются** по умолчанию (они завершаются при выходе)
- Сеансы **привязаны к одному проекту** за раз.
- Ваш контекст растет по мере того, как вы задаете больше вопросов (максимум ~ 200 тыс. токенов)

### Контекст

**Context** — это то, какую часть разговора запоминает Claude. Оно отображается в процентах (0–100%).

- 0–50 %: Много места, работайте свободно.
- 50–70 %: будьте избирательны, `/compact` необязательно.
- 70%+: Запустите `/compact`, чтобы освободить место.
- 90%+: вас заставят убираться.

### Осведомленность о Git

Claude Code поддерживает **git**. Это:
- Обнаруживает вашу текущую ветку
- Показывает незафиксированные изменения
- Помогает с коммитами и обзорами
- Предотвращает случайные критические изменения

## <a name="troubleshooting"></a>Поиск неисправностей

### «Клод: команда не найдена»
Ваша установка не завершена. Пытаться:
- **macOS**: Опять `brew install anthropic/tap/claude-code`
- **Linux**: перезапустите сценарий установки.
- **Windows**: Загрузите установщик с https://dl.claudecode.com/windows.

### «Проект не найден»
Убедитесь, что вы находитесь в каталоге с `package.json`, `.git` или другим файлом проекта. Claude Code лучше всего работает в проектах.

### «В разрешении отказано» (macOS)
Try:
```bash
chmod +x /usr/local/bin/claude
```
