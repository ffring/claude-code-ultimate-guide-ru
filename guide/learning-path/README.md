# Claude Code путь обучения

Это ваша структурированная точка входа. Следуйте модулям по порядку, а затем перейдите к полному руководству по глубине.

## Как использовать этот путь

### Шаг 1: Оцените свой уровень

**Beginner** (первый день Claude Code):
- Пройдите быстрый путь: 01 → 02 → 03 (2 часа).
- Затем перейдите к полному руководству `Part 1: Quick Start`.

**Intermediate** (при использовании Claude Code 1–4 недели):
- Пройдите полный путь: 01 → 07 (8-11 часов)
- Для глубины сосредоточьтесь на модулях 04, 05, 06, 07.

**Advanced** (при использовании Claude Code 1+ месяцев):
- Просмотр 01–03, углубление 04–07
- Перейти к руководству «Часть 9: Расширенные шаблоны оркестрации»

### Шаг 2. Выберите трек

**Курс A: Освойте основы** (11 часов)
- Следуйте модулям 01–07 по порядку.
- Выполните все упражнения
- Принимайте `/lesson-quiz [topic]` после каждого модуля.
- Закончите с `/self-assessment comprehensive`

**Трек B: Глубокое погружение с упором на навыки** (4–6 часов)
- Модуль 01-02 (основы)
- Перейдите к модулю 04, 05 или 06 в зависимости от вашей цели.
- Углубитесь в этот модуль
- Ссылка на расширенные шаблоны по мере необходимости

**Трек C: Принятие команды** (5–7 часов)
- Модуль 01-02 (обучение основам)
- Модуль 03 (конфигурация команды)
- Модули 04-07 (рабочие процессы команды)
- Проведите `/self-assessment` по всей команде, выявите пробелы
- Создайте план последующего обучения с учетом пробелов

### Шаг 3. Изучите и подтвердите

Каждый модуль включает в себя:
- 📖 **Чтение** (10–30 мин): Концепции и ментальные модели.
- 🔨 **Практическая практика** (20–45 мин): Реальные примеры из `examples/`
- 📝 **Validation**: `/lesson-quiz [topic]` для проверки понимания

### Шаг 4: Идите глубже

После этого пути у вас есть варианты:

**Вариант A: Глубокая справка**
→ Перейти к соответствующему разделу в `guide/ultimate-guide.md`

**Вариант Б: освоить домен**
→ Прочтите специальные руководства (например, `guide/security/`, `guide/ops/`).

**Опция C: сборка с использованием плагинов**
→ Установите пакет плагинов от `examples/plugins/`.

**Вариант D: Самооценка**
→ Запустите `/self-assessment comprehensive`, чтобы определить оставшиеся пробелы.

### Шаг 5. Поддерживайте прогресс в проекте

Устанавливаемый навык [](../../examples/skills/learning-path/SKILL.md) превращает семь модулей в локальный прогресс. Он выбирает только те модули, для которых выполнены предварительные условия, требует непустое свидетельство и записывает состояние в `.claude/learning/claude-code-guide-progress.json` в проекте учащегося.

Используйте этот навык, когда путь чтения охватывает несколько сеансов или когда другому человеку необходимо проверить выполненное. График рассмотрения составляет 1, 3, 7, 14, 30, 60 и 90 дней. Эти интервалы являются политикой проекта, а не утверждением, что один график является оптимальным для каждого учащегося.

Сопутствующий проект [Proofpack](../../examples/learning-project/README.md) содержит одну проблему, связанную с конфигурацией, реализацией, тестированием, защищенной проверкой выпуска, проверкой доказательств, упаковкой и дополнительной границей Docker. Используйте его, если вам нужно одно непрерывное упражнение по всем семи модулям.

Слайды [с учебным планом](../../docs/distribution/claude-code-learning-path-slides.pptx) представляют собой краткую версию семинара. Видео-брифы [](../../docs/distribution/quick-win-video-series.md) соединяют отдельные упражнения с наблюдаемыми проверками.

**Цель:** Запустите Claude Code и убедитесь, что он работает.

- Запустите свою первую команду
- Поймите подсказку → цикл вывода
- **Упражнение:** Завершите рабочий процесс «Первые 5 минут».

**Сложность:** ⭐ (Новичок)
**Читать:** [Модуль 01: Установка и настройка](01-installation.md)
**Затем:** Часть 1: Быстрый старт в главном руководстве

**Цель:** Понять, как Claude Code работает на уровне системы.

- **Упражнение:** Используйте `/plan`, чтобы спланировать реальную задачу, наблюдайте за ходом выполнения.

**Сложность:** ⭐ (Новичок)

## Общие вопросы

**Q: Могу ли я пропустить модули?**
О: Да, но 01-03 являются обязательными условиями. Если вы знаете основы, начните с 04.

**Q: Сколько времени это действительно занимает?**
О: Полный путь занимает 8-11 часов. Выделите дополнительное время для упражнений.

**Q: Нужен ли мне предыдущий опыт работы с Claude Code?**
О: Нет, начните с модуля 01. Если вы уже использовали его раньше, просмотрите 01-02.

**Q: Каково полное руководство после этого?**
О: `guide/ultimate-guide.md` (25 тыс. строк) — ваша ссылка. Этот путь приведет вас к тому моменту, когда вы сможете эффективно его читать.
