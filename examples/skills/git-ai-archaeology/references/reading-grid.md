# Сетка чтения для археологии упряжи

Каждый индикатор взят из `{slug}-harness.json`. Пороги — это средства чтения, а не вердикты: репозиторий каталога, в котором каждый коммит настроен, читается иначе, чем монорепозиторий продукта.

| Индикатор | Как вычислить | Что это предполагает | Осторожно |
| --- | --- | --- | --- |
| Используйте долю коммитов | коммиты использования / коммиты репозитория | Вес работы конфига AI в репозитории | Почти 100 % в каталоге навыков по замыслу |
| Первое появление в семье | первый коммит на семью | Порядок принятия инструмента | При переименовании сохраняется исходная дата. |
| Доля самого активного участника | лучший автор коммитит / использует коммит | Более 60 %: подвеска опирается на одного человека. | Небольшие репозитории достигают 100 % с одним автором. |
| Участники с одним коммитом | авторы с одним коммитом | Многие: конфиг, написанный когда-то прохожими | Массовый импорт раздувает его |
| Никогда не редактировалось после создания | представить файлы одним коммитом/представить файлы | Более 50 %: конфигурация с однократной записью, вероятно, отклоняющаяся от кода. | Ожидается, что сгенерированные файлы останутся нетронутыми. |
| Нетронутый в течение 180 дней | представить файлы, последний коммит которых старше 180 дней | Устаревшие инструкции | Стабильный эталонный материал является законным |
| Удаленные файлы и медианное время жизни | файлы отсутствуют по ссылке; последний созданный минус | Время жизни до 14 дней: метод проб и ошибок в основной ветке | Перемещение между инструментами отображается как переименование, а не удаление. |
| Идентичные копии по ссылке | группы файлов с одним и тем же BLOB-объектом | Копипаст распространения без единого источника | Символические ссылки не считаются копиями. |
| Копирование распространения | тот же объект добавлен по новому пути | Как файл распространяется между модулями и когда | Видны только точные копии |
| Необъединенные коммиты жгута | `--remotes --not ref` | Работа, которая живет за пределами основной ветки | Ветки, объединенные в сквош, все еще появляются. |
| Доля AI-трейлера в месяц | трейлер фиксирует / фиксирует | Нижняя граница коммитов с помощью ИИ | Встроенное завершение не оставляет трейлера |
| Использование по сравнению с ремнями безопасности | сравнить два ежемесячных ряда | Использование без ремня: инструменты используются в сыром виде. Жгут без использования: конфиг, который никто не подписывает | Трейлеры зависят от настроек инструмента по умолчанию. |
