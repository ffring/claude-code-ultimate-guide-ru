# Шаблон Twitter/X

Два режима: одиночный твит (280 символов) или поток (2-3 твита).

## Одиночный твит

Используйте, когда: 1-2 выделения, простое обновление версии.

### шаблон FR

```
{hook_line_fr}

{highlight_fr}

{link}
```

### RU-шаблон

```
{hook_line_en}

{highlight_en}

{link}
```

### Правила

- Всего максимум 280 символов (включая ссылку)
- Макс. 2 смайлика
- Ссылка на репозиторий GitHub
- FR: обучение
- RU: прямой адрес

## Тема (2-3 твита)

Используйте, когда: 3+ ярких моментов, насыщенный version/week.

### шаблон FR

```
Tweet 1/N:
{hook_line_fr}

{context_fr}

Thread [down_arrow]

---

Tweet 2/N:
{highlight_1_fr}
{highlight_2_fr}

---

Tweet 3/N (optional):
{highlight_3_fr}

{cta_fr}
{link}
```

### RU-шаблон

```
Tweet 1/N:
{hook_line_en}

{context_en}

Thread [down_arrow]

---

Tweet 2/N:
{highlight_1_en}
{highlight_2_en}

---

Tweet 3/N (optional):
{highlight_3_en}

{cta_en}
{link}
```

## Правила полей

### крючок_line (максимум 100 символов)

Самая короткая форма выделения сверху. Должно вписываться в первый твит с учетом контекста.

| Шаблон | фр. | RU |
|---------|-----|-----|
| Number-led | `30 nouvelles questions quiz Claude Code` | `30 new Claude Code quiz questions` |
| Прямой | `Nouveau guide : sandbox isolation Docker` | `New guide: Docker sandbox isolation` |

### контекст (максимум 80 символов)

```
FR: "Guide v3.20.5 vient de sortir"
EN: "Guide v3.20.5 just dropped"
```

### основные моменты (максимум 120 символов каждый)

Преобразованные записи, по одной в строке. Никаких пунктов (используйте разрывы строк).

```
FR: "4 diagrammes ASCII pour TDD, UVAL, securite"
EN: "4 ASCII diagrams for TDD, UVAL, security"
```

### призыв к действию (максимум 60 символов)

```
FR: "Tout est open source"
EN: "All open source"
```

### связь

URL-адрес репозитория GitHub. Учитывается ограничение в 280 символов (23 символа для t.co).

## Решение: одиночный или потоковый

| Состояние | Формат |
|-----------|--------|
| 1–2 основных момента, все умещаются в 280 символов. | Одиночный твит |
| 3+ основных моментов или богатый контент | Тема (2-3 твита) |
| Неделя с несколькими версиями | Нить |
| Только технические изменения | Одиночный твит (или пропуск) |

## Ограничения

- Каждый твит: максимум 280 символов.
- Бюджет эмодзи: всего 2 в теме.
- Никаких рекламных слов
- FR: обучение
- RU: Американский английский
- Максимум тем: 3 твита (не 5+)
