# Обновление информации об угрозах через AgentSec

AgentSec Triage владеет техническим источником истины. Этот навык гида
делегатором и не имеет частной копии базы данных угроз.

## <a name="workflow"></a>Рабочий процесс

1. Найдите родственный элемент оформления заказа `agentsec-triage` или используйте `AGENTSEC_REPO`.
2. Прочтите `AGENTS.md` AgentSec и
   `.claude/commands/update-threat-db.md` полностью.
3. Выполнение проверки исходного кода, тестирование Red-First, авторские изменения и сборщики.
   внутри изолированного рабочего дерева AgentSec.
4. Синхронизируйте `exports/security-feed.v1.json` только с направляющей и приземлением.
   после того, как AgentSec пройдет локально.
5. Следуйте инструкциям `.claude/commands/update-threat-db.md` в руководстве для обеспечения совместимости.
   обновления базы данных и команда sync/check в каталоге лендинга с возможностью поиска.
   Текущий значок ленты не доказывает, что каталог содержит новые записи.
6. Запустите проверку направляющих и целевых зеркал, а затем сообщите о каждом репозитории.
   Статус отдельно.

Не считайте базу данных совместимости руководства канонической. Не публикуйте,
тег или нажмите AgentSec, пока его решение о лицензии блокирует публичный выпуск.

База данных совместимости, по-прежнему используемая командами руководства,
`examples/commands/resources/threat-db.yaml`.
