# Исполняемый путь обучения Claude Code

Этот прототип без зависимостей превращает существующий семимодульный путь обучения [](../../../guide/learning-path/README.md) в локальный прогресс. Он сохраняет только состояние, принадлежащее учащемуся, в `.claude/learning/claude-code-guide-progress.json` в рамках целевого проекта.

## Что он делает

- создает один из четырех треков: «Новичок», «Практик», «Продакшн» или «Мейнтейнер»;
- разблокирует модули только после того, как их предварительные условия зафиксировали доказательства;
- требует непустой записи доказательств для каждого завершения;
- создает детерминированный следующий модуль, текущий статус и список подлежащих проверке;
- планирует проверки через 1, 3, 7, 14, 30, 60 и 90 дней;
- записывает состояние JSON атомарно и отказывается от поврежденного состояния.

Это местное учебное пособие. Он не доказывает компетентность, не загружает доказательства и не заменяет человеческую оценку учений.

## <a name="quick-start"></a>Быстрый старт

Сначала используйте рабочий процесс общедоступной самооценки:

```text
/self-assessment quick
```

Затем начните самый низкий трек, соответствующий вашей непосредственной цели:

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Beginner
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" next
```

После выполнения упражнения зафиксируйте доказательства:

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" complete module-01 \
  --evidence "Installed Claude Code, ran /help, and recorded the version."
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" status
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" due
```

Этот навык работает из стороннего проекта, поскольку он обращается к установленному скрипту через `CLAUDE_SKILL_DIR` и записывает состояние в текущий каталог. Например:

```bash
cd /path/to/project
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Practitioner
```

## Треки

| Отслеживать | Ожидаемый результат | Требуемые модули |
| --- | --- | --- |
| Новичок | Безопасная работа с первым рабочим процессом Claude Code | 01, 02, 03 |
| Практикующий | Создавайте многоразовые рабочие процессы для локальных агентов и навыков. | с 01 по 05 |
| Производство | Добавьте хуки, проверку и расширенную координацию. | с 01 по 07 |
| Сопровождающий | Поддерживать общие практики и оперативные гарантии | с 01 по 07 |

Диагностика помогает выбрать начальную версию, но не удаляет предварительные проверки. Учащийся, выбравший «Производство», по-прежнему выполняет последовательность действий по порядку.

### Картирование самооценки

| Результат самооценки | Выбрать этот трек |
| --- | --- |
| Новичок | Новичок |
| Средний | Практикующий |
| Передовой | Производство |

Сопровождающий — это выбор вручную, а не результат самооценки. Используйте его только в том случае, если цель включает в себя совместное управление, например поддержание командных инструкций, средств контроля или практики сбора доказательств.

## Состояние и восстановление

Файл состояния содержит только выбранный трек, даты завершения модуля и примечания к доказательствам. `init` не перезапишет его. Каждое сохранение записывает полный временный файл в тот же каталог, сбрасывает его и атомарно заменяет старый файл.

Если `status`, `next`, `complete` или `due` сообщает о поврежденном состоянии, остановитесь. Сохраните копию `.claude/learning/claude-code-guide-progress.json` для проверки, исправьте ее вручную только после выявления причины или удалите намеренно и запустите новый профиль. Прототип не будет догадываться, как восстановить данные учащегося.

## Тесты

```bash
python3 -m unittest -v examples/skills/learning-path/tests/test_progress.py
```

Целенаправленный пакет охватывает создание профилей, атомарное постоянство, соблюдение предварительных условий, шлюзы доказательств, выбор следующего модуля, интервалы проверки и сбой в поврежденном состоянии.

## Граница проверки навыков

`path.yaml` является действительным JSON и, следовательно, действительным YAML. Среда выполнения без зависимостей проверяет именно это подмножество JSON с помощью стандартной библиотеки Python. Входящий в комплект валидатор навыков `quick_validate.py` требует PyYAML, поскольку он импортирует `yaml` перед анализом заголовка `SKILL.md`. Если PyYAML отсутствует, проверка заголовка — `UNKNOWN`. Не сообщайте об этом как о пройденной проверке навыков. Пакет локальных модулей по-прежнему проверяет, может ли среда выполнения загрузить определение отправленного пути.
