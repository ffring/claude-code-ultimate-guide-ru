# Claude Code путь обучения

Используйте этот навык, чтобы следовать ограниченному локальному прогрессу по существующему руководству из семи модулей. Движок выбирает только модули, предварительные условия которых выполнены, ничего не сохраняет за пределами каталога `.claude/learning/` текущего проекта, требует непустое свидетельство и отклоняет поврежденное состояние.

## Начни с диагностики

Запустите `/self-assessment quick` перед выбором трека. Это средство самоотчета, а не сертификация. Сопоставьте его результат намеренно:

| Результат самооценки | Путь обучения |
| --- | --- |
| Новичок | Новичок |
| Средний | Практикующий |
| Передовой | Производство |

Сопровождающий не является результатом самооценки. Выбирайте его вручную только в том случае, если целью является совместное управление, например поддержание командных инструкций, средств контроля или практики сбора доказательств.

Выберите самый нижний путь, который соответствует вашей непосредственной цели:

| Отслеживать | Исход | Модули |
| --- | --- | --- |
| Новичок | Безопасный первый ежедневный рабочий процесс | с 01 по 03 |
| Практикующий | Многоразовые рабочие процессы проекта | с 01 по 05 |
| Производство | Автоматизация с контролем проверки | с 01 по 07 |
| Сопровождающий | Совместная практика и управление | с 01 по 07 |

Определения модулей, ссылки на руководства, упражнения, предварительные требования и интервалы проверки находятся в [assets/path.yaml](assets/path.yaml). Исходной учебной программой является существующая программа обучения [, состоящая из семи модулей](../../../guide/learning-path/README.md).

## Команды

Запускайте команды из репозитория или изучаемого проекта. `CLAUDE_SKILL_DIR` — это каталог установленных навыков, предоставляемый Claude Code. `--root "$PWD"` делает текущий проект учащегося, а не приобретенный навык, единственной государственной целью.

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Beginner
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" status
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" next
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" complete module-01 \
  --evidence "Installed Claude Code, ran /help, and recorded the version."
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" due
```

Файл состояния — `.claude/learning/claude-code-guide-progress.json`. Это принадлежит проекту учащегося, а не этому установленному навыку. `init` отказывается перезаписывать существующий файл состояния. Сохраняйте статус местного значения, если только вы сознательно не решите поделиться доказательствами.

## Завершающие ворота

Прежде чем завершить модуль:

1. Прочтите связанную страницу руководства.
2. Выполните связанное упражнение в реальном проекте.
3. Запишите конкретное свидетельство, которое может проверить другой человек, например команду, измененный файл, результат теста или артефакт проверки.
4. Используйте `next`, чтобы получить следующий разблокированный модуль.

Пустая заметка, невыполненное предварительное условие, неизвестный модуль, модуль за пределами выбранной дорожки или поврежденное состояние являются ошибкой. Инструмент не делает вывод о завершении на основе процента, кода завершения команды или утверждения учащегося.

## Отзывы

Для каждого завершения запланированы проверки ровно через 1, 3, 7, 14, 30, 60 и 90 дней после зарегистрированной даты завершения. `due` возвращает все запланированные проверки, подлежащие выполнению не позднее сегодняшнего дня. Вернитесь к связанному упражнению и обновите отдельный артефакт доказательства, если знания изменились.

## Граница безопасности

Все записи являются локальными и атомарными. Неверно сформированный файл состояния не закрывается и остается нетронутым для проверки или восстановления. Прототип не вызывает сетевой сервис, не устанавливает пакеты, не оценивает компетентность автоматически и не редактирует руководство.

## Граница проверки

Среда выполнения проверяет `path.yaml` с помощью синтаксического анализатора Python JSON, поскольку файл использует подмножество JSON YAML. Входящий в комплект валидатор навыков `quick_validate.py` импортирует PyYAML перед анализом заголовка `SKILL.md`. Если этот импорт не удался, это предварительная проверка `UNKNOWN`, а не успешная проверка навыков. Тесты времени выполнения без зависимостей все равно могут установить, что загружается именно это определение пути.
