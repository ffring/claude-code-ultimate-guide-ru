# Ссылки

Этот каталог содержит документацию, которая будет загружаться контекстно во время выполнения навыка.

## Рекомендации

- Держите файлы целенаправленными и хорошо организованными
- Используйте формат уценки для удобства чтения.
- Включите конкретные примеры, где это возможно.
- Обновлять при изменении знаний о предметной области

## Файлы

Добавьте сюда свои справочные документы. Примеры:
- `api-docs.md` - API документация
- `style-guide.md` – Рекомендации по форматированию
- `domain-knowledge.md` — информация, специфичная для домена
