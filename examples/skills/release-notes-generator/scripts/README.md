# Скрипты

Этот каталог содержит исполняемые сценарии для детерминированных повторяемых задач.

## Рекомендации

- Скрипты должны быть самостоятельными и хорошо документированными.
- Включите примеры использования в заголовки скриптов.
- Грамотно обрабатывайте ошибки с помощью четких сообщений
- Используйте соответствующие коды выхода (0 для успеха, 1 для неудачи).

## Файлы

Добавляйте сюда свои скрипты. Примеры:
- `generate.py` - Основной скрипт генерации
- `validate.py` — Утилиты проверки
- `transform.py` — Помощники по преобразованию данных
