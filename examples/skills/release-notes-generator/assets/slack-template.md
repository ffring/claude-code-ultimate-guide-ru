# Шаблон объявления Slack

Используйте этот шаблон для создания сообщений Slack, ориентированных на продукт.

```
Version X.Y.Z - Deployed to production

PR : [Release PR URL, e.g.: https://github.com/{owner}/{repo}/pull/XXX]

In brief : [Sentence describing the main objective of this release]

---

New Features

[Feature Name 1]
> [1-2 sentence description of user impact]
> Who is affected: [End-users / Admins / All]

[Feature Name 2]
> [1-2 sentence description]
> Who is affected: [Roles]

---

Important Fixes

- [Bug fix described in user-friendly language]
- [Bug fix described in user-friendly language]

---

Improvements

- [UX/UI or workflow improvement in user language]
- [...]

---

By the numbers

- X new features
- Y bugs fixed
- Z improvements

---

Questions? Contact @[team-lead] or the dev team
```

## Рекомендации

### ДЕЛАТЬ
- Используйте доступный язык (без технического жаргона)
- Сосредоточьтесь на влиянии на пользователя
- Будьте краткими (максимум 10 строк в разделе).
- Используйте смайлы экономно

### ИЗБЕГАТЬ
- «Реализация паттерна DataLoader для решения запросов N+1»
- «Полный рефакторинг системы разрешений с областью действия ANY/ASSIGNED»
- «Миграция с вебпака на турбопак»

### Технологии -> трансформация продукта

| Технический | Продукт |
|-----------|---------|
| Оптимизация запросов N+1 с помощью DataLoader | Ускоренная загрузка списков пользователей и функций. |
| Реализация встраивания ИИ с помощью pgvector | Новый интеллектуальный поиск похожих предметов |
| Исправьте разрешения области в getPermissionScope(). | Исправлена ​​ошибка, из-за которой некоторые пользователи не могли получить доступ к своим данным. |
| Миграция на кебаб-кейс для файлов | *Не общаться (чисто техническая)* |
| Исправлено соединение с БД с логикой повтора. | Повышенная стабильность соединения с базой данных |
| Добавить мониторинг ошибок для потерянных записей. | Автоматическое обнаружение потерянных записей |

### Дополнительные разделы

Если в релизе есть важные пункты, добавьте:

Берегись
- [Важная информация, которую должны знать пользователи]
- [Изменения в поведении, которые они могут заметить]

Вскоре
- [Тизер следующей большой функции]
- [Функция в разработке скоро появится]
