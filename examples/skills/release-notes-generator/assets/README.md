# Ресурсы

Этот каталог содержит шаблоны, изображения и шаблонный код.

**Note**: Ресурсы НЕ загружаются в контекст автоматически. На них должна быть явная ссылка.

## Рекомендации

- Используйте описательные имена файлов
- Включайте инструкции по использованию в заголовки файлов.
- Сохраняйте шаблоны минимальными и настраиваемыми

## Файлы

Добавьте сюда свои активы. Примеры:
- `template.md` — Шаблон вывода
- `boilerplate.ts` — шаблон кода
- `config.json` — шаблон конфигурации
