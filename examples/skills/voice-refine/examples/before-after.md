## Пример 1: компонент таблицы React (на французском языке)

### До (147 слов)

> Alors euh j'aimerais que tu m'aides à faire un Truc, en fait j'ai une API
> qui renvoie des données utilisateurs et je voudrais les afficher dans un
> таблица React, больше внимания уделите тому, что вы видите на странице
> Beaucoup de Données, жанр миллеров-утилизаторов и др.
> pouvoir trier по имени или по дате надписи, и т. д. используйте Tailwind
> В проекте я не понимаю, что матч с этим, и я говорю, что это не так
> Больше всего важных вещей, связанных с одеждой и композицией. Кнопка, которая позволяет использовать часть файла.
> faudrait l'utiliser aussi, et puis j'imagine qu'il faut un état de
> зарядка aussi quand les données прибыла...

### После (45 слов)

```markdown
## Contexte
App React + Tailwind, API users existante, composant Button réutilisable

## Objectif
Tableau utilisateurs avec pagination et tri

## Contraintes
- Pagination (milliers d'entrées)
- Tri: nom, date inscription
- Loading state
- Utiliser Button existant

## Output
Composant React + TypeScript
```

**Ratio**: сжатие 3,3x

## Пример 2: Процесс аутентификации (на английском языке)

### До (189 слов)

> Итак, я думал о процессе аутентификации и, в принципе,
> нам нужно что-то, что обрабатывает как обычный вход в систему, так и
> войдите в социальную сеть с помощью Google и, возможно, GitHub, и дело в том, что
> у нас уже есть код для этого, но это какая-то путаница, и я хочу
> чтобы очистить его, кстати, мы используем Next.js 15, и у нас есть
> Prisma для базы данных, и я думаю, нам следует использовать токены JWT, но
> возможно, и с токенами обновления, потому что мы не хотим, чтобы пользователям приходилось
> заходить в систему каждый час, это будет раздражать, и нам тоже нужно
> обрабатывать случай, когда срок действия токена истекает, пока он находится в
> в процессе выполнения чего-либо, например заполнения формы, мы не должны просто
> выгоните их, и я думаю, нам нужно какое-то промежуточное программное обеспечение для проверки
> статус аутентификации на защищенных маршрутах, имеет ли это смысл?

### После (52 слова)

```markdown
## Context
Next.js 15 + Prisma, existing auth code needs refactoring

## Objective
Implement clean auth flow with credentials + OAuth (Google, GitHub)

## Constraints
- JWT + refresh tokens
- Graceful token expiry handling (no mid-action logout)
- Middleware for protected routes
- Silent token refresh

## Output
Auth module with middleware and hooks
```

**Ratio**: сжатие 3,6x.

## Пример 3: Отчет об ошибке (смешанный)

### До (112 слов)

> Привет, вот такая странная ошибка, в основном, когда пользователи пытаются загрузить
> изображение очень большое, примерно 5 МБ или что-то в этом роде,
> приложение просто зависает, а потом, думаю, время ожидания истекает,
> и сообщение об ошибке вообще не помогает, оно просто говорит: «что-то
> пошло не так", что совершенно бесполезно, поэтому нам, вероятно, нужно это исправить.
> добавьте некоторую проверку перед началом загрузки и покажите правильное
> сообщение об ошибке, если файл слишком большой, да, возможно, нам тоже следует
> добавьте индикатор выполнения, чтобы пользователи знали, что что-то происходит...

### После (38 слов)

```markdown
## Bug
Image upload hangs/times out for files >5MB, unhelpful error message

## Fix Required
- Client-side size validation before upload
- Clear error message for oversized files
- Progress indicator during upload

## Files
Likely: upload component, API route
```

**Ratio**: сжатие 2,9x

> например, последние 7 дней, последние 30 дней, последние 90 дней и тому подобное,
> и о, они также упомянули о желании экспортировать данные в CSV в какой-то момент
> точка, но это может быть этап 2, и команда разработчиков прислала несколько

Dashboard page + components

## Выявленные закономерности

### Удалены общие фразы-вставки.

- «в принципе», «типа», «ну ты знаешь», «я имею в виду»
- «что-то вроде», «что-то вроде», «я думаю», «я думаю»
- «так что да», «что-то в этом роде», «или что-то в этом роде»
- "кстати", "да", "тоже"

### Картирование структуры

| Голосовой образец | Структурированный раздел |
|---------------|-------------------|
| «мы используем X» | Контекст |
| "Я хочу..." | Цель |
| «нужно...» | Ограничения |
| "наверное, стоит..." | Ограничения (если технические) |
| "срок - это..." | Ограничения |
| "выход должен быть..." | Выход |
