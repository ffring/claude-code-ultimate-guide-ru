# Обсуждение навыков конвейера

Шестиэтапный конвейер навыков, который преобразует исходный материал (статью, стенограмму, заметки) в полноценное выступление на конференции со слайдами, созданными искусственным интеллектом.

## <a name="install"></a>Установка

Скопируйте каталог `talk-pipeline/` в папку `.claude/skills/` вашего проекта:

```bash
cp -r examples/skills/talk-pipeline ~/.claude/skills/
```

Или установите только те этапы, которые вам нужны (каждый этап независим).

## Этапы

| Этап | Файл навыков | Режим | Описание |
|-------|-----------|------|-------------|
| 1 | `stage-1-extract/SKILL.md` | РЕКС + Концепция | Извлечение исходного материала в структурированное резюме |
| 2 | `stage-2-research/SKILL.md` | только РЕКС | Git археология + график |
| 3 | `stage-3-concepts/SKILL.md` | РЕКС + Концепция | Каталог концепций с оценками |
| 4 | `stage-4-position/SKILL.md` | РЕКС + Концепция | Ракурсы, титры, описания + CHECKPOINT |
| 5 | `stage-5-script/SKILL.md` | РЕКС + Концепция | Презентация из 5 актов + спецификация слайдов + подсказка Кими |
| 6 | `stage-6-revision/SKILL.md` | РЕКС + Концепция | Листы изменений + шпаргалка вопросов и ответов |
| — | `orchestrator/SKILL.md` | РЕКС + Концепция | Запуск всего конвейера с одного вызова |

## <a name="quick-start"></a>Быстрый старт

**Полный конвейер (рекомендуется)**:
```
/talk-pipeline
```
Оркестратор запрашивает метаданные и запускает все применимые этапы.

**Одноступенчатый**:
```
/talk-stage1-extract
/talk-stage4-position
```

**С флагами**:
```
/talk-pipeline --rex --slug=my-talk --event="Conf 2026" --duration=30
/talk-pipeline --concept --slug=my-idea
```

## Соглашение о выводе

Все файлы попадают в `talks/` в корне вашего проекта:
```
talks/{YYYY}-{slug}-summary.md
talks/{YYYY}-{slug}-git-archaeology.md
talks/{YYYY}-{slug}-concepts.md
talks/{YYYY}-{slug}-angles.md
talks/{YYYY}-{slug}-pitch.md
talks/{YYYY}-{slug}-kimi-prompt.md
...
```

## Использование подсказки Кими

На этапе 5 генерируется `{slug}-kimi-prompt.md`. Чтобы создать слайды:
1. Откройте файл и убедитесь, что `{PLACEHOLDER}` не осталось.
2. Перейдите на [kimi.com](https://kimi.com) (бесплатно, API не требуется)
3. Скопируйте и вставьте всю подсказку
4. Кими создает презентацию в темной теме с содержимым вашего слайда.
