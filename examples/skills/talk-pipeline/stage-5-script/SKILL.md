# Обсуждение, этап 5: Сценарий

Полный доклад состоит из трех частей: повествования в пяти действиях с заметками докладчика, спецификации слайдов и подсказки Кими, готовых к копированию и вставке.

**Предварительное условие**: Пользователь подтвердил угол + заголовок на этапе 4 CHECKPOINT. Не запускайте этот этап без этого подтверждения.

## Когда использовать этот навык

- После подтверждения этапа 4 CHECKPOINT
- Когда у вас есть проверенный ракурс + заголовок
- Создание полного сценария и спецификации слайдов

## Что дает этот навык

1. **Проверяет входные данные**: все исходные файлы + подтверждение angle/title
2. **Загружает шаблон Кими**: из `templates/kimi-prompt-template.md`
3. **Создает презентацию**: 5-актная структура с примечаниями докладчика и таймингом
4. **Создает спецификацию слайда.**: слайд за слайдом с визуальными элементами, текстом и примечаниями.
5. **Генерирует подсказку Кими.**: заполняет шаблон содержанием выступления.
6. **Сохраняет 3 файла**

## Вход

- `talks/{YYYY}-{slug}-summary.md`
- `talks/{YYYY}-{slug}-concepts.md`
- `talks/{YYYY}-{slug}-angles.md`
- `talks/{YYYY}-{slug}-titre.md`
- `talks/{YYYY}-{slug}-timeline.md` (необязательно, дополняет заметки докладчика)
- **Выбранный ракурс + выбранный заголовок** (явное подтверждение пользователя на этапе 4)

## Выход

- `talks/{YYYY}-{slug}-pitch.md`
- `talks/{YYYY}-{slug}-slides.md`
- `talks/{YYYY}-{slug}-kimi-prompt.md`

## kimi-prompt.md

Заполните шаблон по адресу `templates/kimi-prompt-template.md` содержанием доклада.

Обязательные разделы для заполнения:
- Полное название и подзаголовок
- Имя докладчика + событие + дата + продолжительность + язык + количество слайдов
- Требования к дизайну (отрегулируйте цветовую палитру, если она отличается от стандартной)
- Структура содержания слайда (раздел за разделом, все 5 актов)
- Заполнители скриншотов (слайды, ожидающие реальных снимков)
- Эталон тона (адаптируйтесь к стилю выступления)

**Подтвердите нет `{PLACEHOLDER}` остается в конечном файле** перед передачей пользователю.

## Правила построения скрипта

- **1 идея на слайд**: ни больше, ни меньше
- **Заметки докладчика = то, что вы говорите, а не то, что вы читаете**: минимум слайдов, разговорные заметки
- **Цифры — герои**: показатели на слайде отображаются большими и одинокими
- **Анекдоты > пояснения**: "однажды во вторник утром, 3 ошибки..." > "рабочие деревья git включают параллелизм"
- **Явные переходы**: обратите внимание на связь между каждым действием в примечаниях.
- **Реалистичное время**: добавьте 10% общего буфера (слайды всегда выполняются долго)

## Anti-patterns

- Слайды насыщены маркерами (никогда не более 5 слов в строке).
- Заметки докладчика на техническом жаргоне (прочитайте их вслух для проверки)
- Расплывчатая подсказка Кими («сделай так, чтобы это выглядело красиво»): каждый слайд должен быть точным.
- Исключение заполнителей скриншотов из подсказки Кими
- Создание большего количества слайдов, чем позволяет длительность (2-3 min/slide для REX)

## Контрольный список проверки

- [ ] Высота тона охватывает 5 действий с согласованным ритмом (в пределах 10 % от целевой продолжительности).
- [ ] Каждый слайд имеет визуальные + текстовые + заметки докладчика.
- [ ] Определены ключевые моменты (паузы, кульминации, переходы)
- [ ] Спецификация слайдов готова для передачи дизайнеру
- [ ] Приглашение Кими завершено (все разделы шаблона заполнены)
- [ ] Скриншоты для захвата указаны с указанием источника
- [ ] Нет `{PLACEHOLDER}` оставшийся в kimi-prompt.md
- [ ] 3 файла сохранены

## Использование подсказки Кими

1. Открыть `{slug}-kimi-prompt.md`
2. Убедитесь, что `{PLACEHOLDER}` не осталось (найдите файл)
3. Перейдите на [kimi.com](https://kimi.com) (бесплатная учетная запись, API не требуется)
4. Начать новый разговор
5. Скопируйте и вставьте всю подсказку
6. Кими создает презентацию

Для итеративного уточнения: добавьте последующие сообщения, ориентированные на определенные слайды. «Слайд 7: увеличьте число, удалите маркированный список».

## <a name="tips"></a>Советы

- Заметки докладчика — это сердце этого этапа; именно они отличают хорошую речь от хорошей презентации
- Шаблон Кими включает в себя темную систему дизайна с оранжевыми акцентами. Адаптируйте `Color Palette` в шаблоне, если у вашего бренда разные цвета.
- Сгенерируйте больше слайдов, чем необходимо, за первый проход, а затем вырежьте (проще, чем писать с нуля).
