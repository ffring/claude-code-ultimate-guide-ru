## Требования к презентации

**Название**: {FULL_TITLE}
**Speaker**: {SPEAKER_NAME}
**Event**: {EVENT_NAME} — {MONTH_YEAR}
**Целевая аудитория**: {AUDIENCE_DESCRIPTION}
**Duration**: {DURATION} минут (слайдов: {SLIDE_COUNT})
**Language**: {LANGUAGE}
**Format**: Выступление на конференции — повествование, минимум текста, большие цифры, высокий визуальный эффект.

## Требования к дизайну

**Визуальный стиль**:
- Темная тема, современная и минималистичная
- Максимум визуального воздействия с минимумом текста
- Крупный шрифт для ключевых цифр (минимум 48 пт для показателей).
- Значки над пунктами, когда это возможно.
- Очистите шрифты без засечек (Inter, SF Pro или аналогичные).
- Достаточно белого пространства даже на темном фоне
- Высокая контрастность для удобства чтения на экранах проекторов

**Цветовая палитра**:
- Основной фон: почти черный (#0a0a0a).
- Фон поверхности: темно-серый (#141414) — для карточек, блоков контента.
- Повышенный фон: (#1e1e1e) — для выделенных разделов.
- Граница: (#2a2a2a) — тонкое разделение между элементами.
- Основной текст: кремово-белый (#e5e5e5).
- Дополнительный текст: средне-серый (#a3a3a3).
- Приглушенный текст: (#8a8a8a) — для надписей и подписей.
- Акцент — оранжевый: (#f97316) — для ключевых цифр, выделения, призывов к действию.
- Акцент при наведении — светло-оранжевый: (#fb923c) — для второстепенных бликов.
- Зеленый цвет успеха: (#22c55e) — только для положительных показателей.
- Предупреждение красное: (#ef4444) — только для проблем, ошибок и отрицательных показателей.

**Настройки макета**:
- 1 идея на слайд — не больше
- Согласованный нижний колонтитул с номером слайда (отдельно, внизу справа)
- Текст выровнен по левому краю для удобства чтения.
- Максимум 30 слов на слайд (исключая заголовки)
- Числа отображаются очень большими и центрированными, когда они являются основной точкой
- Блоки кода со слегка более светлым фоном (#1e293b) и моноширинным шрифтом.
- Диаграммы с использованием простых прямоугольников, стрелок и акцентной цветовой палитры.

## Рекомендации по заметкам докладчика

Примечания докладчика к каждому слайду включают:
- Ключевой сюжетный ход (к чему стремиться emotion/reaction)
- Точная формулировка критических моментов (изюминки, переходы)
- Рекомендации по выбору времени
- Индикаторы паузы для драматического эффекта

Ключевые моменты повествования, требующие намеренных пауз:
1. {PAUSE_MOMENT_1} — {WHY_PAUSE}
2. {PAUSE_MOMENT_2} — {WHY_PAUSE}
3. {PAUSE_MOMENT_3} — {WHY_PAUSE}

## Дополнительные требования

- Общее количество слайдов: ровно {SLIDE_COUNT} слайдов.
- Включите номера страниц на все слайды, кроме слайда 1 (заголовок).
- Добавьте тонкие маркеры перехода разделов между актами (маленький номер акта в углу).
- Темный фон повсюду (база #0a0a0a, #141414 для карточек) — подходит для проектора.
- На всех диаграммах используется акцентная цветовая палитра (оранжевый #f97316 для темных элементов, #1e1e1e для надземных элементов).
- Числа — главные герои этой презентации — сделайте их незабываемыми
- Никакой анимации и сложных переходов — простое плавное затухание между слайдами.
- Нижний колонтитул: отдельный номер слайда внизу справа, имя докладчика внизу слева.
- Общее ощущение должно быть таким: {TONE_DESCRIPTION}

## Доступность

- Убедитесь, что контрастность текста соответствует стандартам WCAG AA (минимум 4,5:1).
- Используйте крупные, читаемые шрифты (минимум 20 пт для основного текста, 28 пт+ для заголовков, 48 пт+ для ключевых номеров).
- Не полагайтесь только на цвет для передачи информации (используйте значки + цвет).
- Проверьте читаемость при типичном разрешении проектора (1920x1080).
