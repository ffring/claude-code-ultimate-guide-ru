# Этап обсуждения 1: Извлечение

Преобразует исходный материал (статью, стенограмму, заметки или смесь) в структурированное резюме, готовое для последующих этапов конвейера. Автоматически определяет тип источника.

## Когда использовать этот навык

- Начало нового выступления из любого исходного материала
- Первый этап конвейера обсуждения (всегда выполняется перед другими этапами)
- Аудит существующего исходного материала перед тем, как приступить к разговору

## Что дает этот навык

1. **Собирает метаданные**, запрашивая ярлык, событие, дату, продолжительность, аудиторию и режим, если они не указаны.
2. **Читает исходный код** и загружает исходный файл или встроенный контент.
3. **Определяет тип источника** (REX с реальным подтверждением или Concept с ideas/thesis) на основе сигналов контента
4. **Извлекает повествовательную арку** (хронологическая для REX, тематическая для Concept)
5. **Извлекает метрики** с каждым измеримым числом и его источником.
6. **Определяет основные темы** (3–7 тем)
7. **Флаги пробелов**: чего не хватает для полноценного разговора
8. **Записывает `{slug}-summary.md`**

## Вход

Required:
- Путь к исходному файлу или встроенное содержимое (статья `.mdx`, расшифровка `.md`, примечания)
- Метаданные: `slug`, `event`, `date`, `duration`, `audience`, `type` (--rex или --concept).

Если метаданные отсутствуют -> `AskUserQuestion`, прежде чем продолжить.

## Выход

`talks/{YYYY}-{slug}-summary.md`

## Определение типа источника

| сигналы REX | Концептуальные сигналы |
|-------------|-----------------|
| Конкретные даты | Тезисы, аргументы |
| Измеренные показатели | Общие замечания |
| Project/tool имена | Наблюдения за тенденциями |
| Коммиты, релизы, PR | Аналогии, метафоры |
| «Я отправил», «Мы построили» | «Я думаю», «По моему мнению» |

Если гибрид -> обратите внимание на оба компонента в сводке.

## Выходной формат

```markdown
# Talk Summary: {Provisional Title}

**Slug** : {slug}
**Event** : {event}
**Date** : {date}
**Duration** : {duration} min
**Audience** : {audience description}
**Type detected** : REX | Concept | Hybrid
**Source** : {source file path}

---

## Narrative Arc

{Arc description: 3-5 sentences. Chronological if REX, thematic if Concept.}

## Main Themes

| # | Theme | Short description | Weight |
|---|-------|------------------|--------|
| 1 | {theme} | {description} | High/Medium/Low |
...

## Key Metrics Extracted

{All measurable numbers found in the source}

Format: `{value}`: {context} (Source: {section/page/git})

Examples:
- `1,200 commits` over 7 months (Source: "acceleration" section)
- `-97% traffic` after SSE migration (Source: CHANGELOG v1.1.0)

If none -> "No verifiable metrics found (Concept mode)"

## Narrative Potential

{3-5 sentences on the strengths and possible narrative angles.
What makes this talk potentially strong. What might be missing.}

## Gaps Identified

- [ ] {gap 1}: {how to fill it}
- [ ] {gap 2}: {how to fill it}

If no obvious gaps -> "No major gaps identified."

## Recommendations for next stages

- **Research**: {recommended / not applicable (Concept mode)}: {why}
- **Concepts**: {priority themes to explore}
- **Position**: {angles already visible from the source material}

---

*Generated by talk-stage1-extract: {date}*
*Source: {source path}*
```

## Правила извлечения метрик

- Не округлять без указания этого
- Всегда указывайте источник показателя
- Если два источника противоречат друг другу, отметьте оба, не выбирая один.
- Никаких придуманных показателей для заполнения пробелов
- Используйте формат `{before} -> {after}` для эволюции.

## Anti-patterns

- Расплывчатое резюме («Этот текст об ИИ…»)
- Опускаем метрики, даже приблизительные с указанием их источника
- Сокрытие пробелов (лучше назвать их, чем делать вид, что их не существует)
- Изменение обнаруженного типа без обоснования
- Придумывание сюжетной линии, отсутствующей в источнике

## Контрольный список проверки

- [ ] Тип источника обнаружен и подтвержден
- [ ] Повествовательная дуга в 3-5 четких предложениях.
- [ ] Все измеримые показатели, извлеченные из их источника
- [ ] Перечислены основные темы (максимум 3–7)
- [ ] Явно выявленные пробелы
- [ ] Файл сохранен в `talks/{YYYY}-{slug}-summary.md`.

## <a name="tips"></a>Советы

- Запустите это перед оркестратором, если хотите убедиться, что исходный материал можно использовать.
- Резюме является основой: его читают все последующие этапы
- Гибридные источники (частично REX, частично Concept) подходят, четко назовите оба компонента.
