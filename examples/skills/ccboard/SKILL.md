# ccboard — приборная панель Claude Code

Комплексная панель управления TUI/Web для мониторинга и управления использованием Claude Code.

## Обзор

ccboard предоставляет унифицированный интерфейс для визуализации и изучения всех ваших данных Claude Code:

- **Sessions**: просмотр всех разговоров в ваших проектах.
- **Statistics**: использование токенов в реальном времени, частота попаданий в кеш, тенденции активности.
- Серверы **MCP**: мониторинг и управление серверами Model Context Protocol.
- **Costs**: отслеживайте расходы с подробной разбивкой токенов и ценами.
- **Configuration**: просмотр настроек каскадирования (Глобальный > Проект > Локальный).
- **Hooks**: изучите хуки выполнения и автоматизацию pre/post.
- **Agents**: управление пользовательскими агентами, командами и навыками.
- **History**: поиск по всем сообщениям с помощью полнотекстового поиска.

## Установка

### Через груз (рекомендуется)

```bash
# Using Claude Code command
/ccboard-install

# Or manually
cargo install ccboard
```

### Требования

- Ржавчина 1.70+ и Груз
- Claude Code установлен (читается из `~/.claude/`)

## <a name="features"></a>Функции

### 8 интерактивных вкладок

#### 1. Панель управления (нажмите `1`)
- Статистика использования токенов
- Количество сеансов
- Сообщения отправлены
- Коэффициент попадания в кэш
- Количество серверов MCP
- Спарклайн активности за 7 дней
- Топ-5 моделей индикаторов использования

#### 2. Сессии (нажмите `2`)
- Двойная панель: дерево проекта + список сеансов.
- Метаданные: временные метки, продолжительность, токены, модели.
- Поиск: фильтрация по проекту, сообщению или модели (нажмите `/`).
- Операции с файлами: `e` для редактирования JSONL, `o` для отображения в поисковике.

#### 3. Конфигурация (нажмите `3`)
- Каскадное представление из 4 столбцов: Глобальный | Проект | Местный | Объединено
- Визуализация наследования настроек
- Конфигурация серверов MCP
- Предварительный просмотр правил (CLAUDE.md)
- Разрешения, перехватчики, переменные среды
- Отредактируйте конфигурацию с помощью ключа `e`.

#### 4. Хуки (нажмите `4`)
- Просмотр перехватчиков на основе событий (PreToolUse, UserPromptSubmit)
- Предварительный просмотр сценария Hook bash
- Сопоставление шаблонов и условий
- Отслеживание пути к файлу для удобства редактирования

#### 5. Агенты (нажмите `5`)
- 3 подвкладки: Агенты (12) | / Команды (5) | ★ Навыки (0)
- Извлечение метаданных Frontmatter
- Предварительный просмотр и редактирование файлов
- Рекурсивное сканирование каталогов

#### 6. Стоимость (нажмите `6`)
- 3 просмотра: Обзор | По модели | Ежедневный тренд
- Разбивка токена: ввод, вывод, кеш read/write
- Цены: общая сметная стоимость
- Распределение моделей

#### 7. История (нажмите `7`)
- Полнотекстовый поиск по всем сеансам
- Гистограмма активности по часам (24 часа)
- 7-дневный спарклайн
- Все сообщения доступны для поиска

#### 8. MCP (нажмите `8`) **NEW**
- Двойная панель: Список серверов (35%) | Детали (65%)
- Обнаружение статуса в реальном времени: ● Работает, ○ Остановлено, ? Неизвестный
- Полная информация о сервере: команда, аргументы, переменные среды.
- Быстрые действия: редактирование конфигурации `e`, открытие файла `o`, обновление статуса `r`.

### Навигация

**Глобальные ключи**:
- `1-8` : Перейти на вкладку.
- `Tab` / `Shift+Tab`: переход по вкладкам.
- `q` : Выйти
- `F5` : Обновить данные.

**Vim-style**:
- `h/j/k/l` : Навигация (left/down/up/right)
- `←/→/↑/↓` : Альтернативы стрелкам.

**Общие действия**:
- `Enter` : Просмотр подробностей/Панель фокуса
- `e` : Редактировать файл в $EDITOR.
- `o`: Показать файл в поисковике.
- `/` : Поиск (во вкладках Sessions/History)
- `Esc` : Закрыть всплывающее окно/Отменить.

### Мониторинг в реальном времени

ccboard включает в себя средство наблюдения за файлами, которое отслеживает `~/.claude/` на предмет изменений:

- **Обновление статистики**: обновление в реальном времени при изменении `stats-cache.json`.
- **Обновления сеансов**: Новые сеансы появляются автоматически.
- **Обновления конфигурации**: изменения настроек отражены в пользовательском интерфейсе.
- **500ms debounce**: предотвращает чрезмерные обновления.

### Редактирование файлов

Нажмите `e` на любом элементе, чтобы открыть его в предпочитаемом вами редакторе:

- Использует `$VISUAL` > `$EDITOR` > платформу по умолчанию (nano/notepad)
- Поддерживает: сеансы (JSONL), конфигурации (JSON), хуки (Shell), агенты (Markdown).
- Состояние терминала сохранено (альтернативный режим экрана)
- Кроссплатформенность (macOS, Linux, Windows)

### Управление сервером MCP

Вкладка MCP обеспечивает комплексный мониторинг сервера:

**Обнаружение статуса** (Unix):
- Проверяет запущенные процессы через `ps aux`
- Извлекает имя пакета из команды
- Отображает PID во время работы
- Windows показывает статус «Неизвестно»

**Сведения о сервере**:
- Полная команда и аргументы
- Переменные среды со значениями
- Путь к файлу конфигурации (`~/.claude/claude_desktop_config.json`)
- Быстрые действия edit/reveal

**Navigation**:
- `h/l` или `←/→`: переключение между списком и подробностями.
- `j/k` или `↑/↓`: выберите сервер.
- `Enter` : Панель сведений о фокусе.
- `e`: изменить конфигурацию MCP.
- `o`: показать конфигурацию в поисковике.
- `r` : Обновить статус сервера.

## Веб-интерфейс

Запустите браузерный интерфейс для удаленного мониторинга:

```bash
# Launch web UI
/ccboard-web

# Or with custom port
ccboard web --port 8080

# Access at http://localhost:3333
```

**Features**:
- Те же данные, что и у TUI (общий бэкэнд)
- События, отправленные сервером (SSE) для оперативных обновлений
- Адаптивный дизайн (desktop/tablet/mobile)
- Одновременный многопользовательский доступ

**Запустите оба одновременно**:
```bash
ccboard both --port 3333
```

## Архитектура

ccboard — это один двоичный файл Rust с двумя интерфейсами:

```
ccboard/
├── ccboard-core/      # Parsers, models, data store, watcher
├── ccboard-tui/       # Ratatui frontend (8 tabs)
└── ccboard-web/       # Axum + Leptos frontend
```

**Источники данных**:
- `~/.claude/stats-cache.json` - Статистика
- `~/.claude/claude_desktop_config.json` - Конфигурация MCP
- `~/.claude/projects/*/` — файлы JSONL сеанса
- `~/.claude/settings.json` - Глобальные настройки
- `.claude/settings.json` - Настройки проекта
- `.claude/settings.local.json` — локальные переопределения
- `.claude/CLAUDE.md` - Правила и поведение

## <a name="troubleshooting"></a>Поиск неисправностей

### плата не найдена

```bash
# Check installation
which ccboard

# Install if needed
/ccboard-install
```

### Данные не видны

```bash
# Verify Claude Code is installed
ls ~/.claude/

# Check stats file exists
cat ~/.claude/stats-cache.json

# Run with specific project
ccboard --project ~/path/to/project
```

### Статус MCP показывает «Неизвестно».

- Для определения статуса требуется Unix (macOS/Linux)
- Windows по умолчанию показывает «Неизвестно».
- Проверьте, действительно ли запущен серверный процесс: `ps aux | grep <server-name>`

### Не работает наблюдатель файлов

- Убедитесь, что ящик `notify` поддерживает вашу платформу.
- Проверьте права доступа к файлам на `~/.claude/`
- Перезапустите ccboard, если события файловой системы пропущены.

### <a name="integration-with-claude-code"></a>Интеграция с Claude Code

ccboard читает **только для чтения** из каталогов Claude Code:

- Неинвазивный мониторинг
- Никаких изменений в данных Claude.
- Безопасно работать одновременно с Claude Code.
- Наблюдатель за файлами обнаруживает изменения в режиме реального времени

## Производительность

- **Двоичный размер**: 2,4 МБ (релизная сборка)
- **Первоначальная загрузка**: <2 с для более чем 1000 сеансов.
- **Memory**: типичное использование ~50 МБ
- **CPU**: <5% во время мониторинга
- **Отложенная загрузка**: содержимое сеанса загружается по требованию.

## <a name="limitations"></a>Ограничения

Текущая версия (0.1.0):

- **Только чтение**: операции записи в данные Claude запрещены.
- Статус **MCP**: только для Unix (Windows показывает «Неизвестно»)
- **Web UI**: в разработке (TUI — основной интерфейс)
- **Search**: базовое сопоставление подстроки (пока нет нечеткого поиска)

Будущая дорожная карта:

- Расширенное управление сервером MCP (start/stop)
- Проверка работоспособности протокола MCP
- Экспорт отчетов (PDF, JSON, CSV)
- Редактирование конфига (запись settings.json)
- Интеграция возобновления сеанса
- Расширенный поиск с нечетким соответствием
