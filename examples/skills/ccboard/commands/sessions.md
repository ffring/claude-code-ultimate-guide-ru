# Команда браузера сеансов

Запустите ccboard и перейдите непосредственно на вкладку исследования сеансов.

## <a name="features"></a>Функции

- **Дерево проектов**: навигация по более чем 33 проектам с вложенной структурой.
- **Список сеансов**: более 1,2 тыс. сеансов с метаданными
- **Search**: фильтрация сеансов по проекту, сообщению или модели (нажмите `/`).
- **Подробности сеанса**:
  - Временные метки (начало, конец, продолжительность)
  - Разбивка по использованию токенов
  - Используемые модели
  - Предварительный просмотр первого сообщения
- **Операции с файлами**:
  - `e`: открыть сеанс JSONL в редакторе.
  - `o`: показать файл сеанса в поисковике.

## Использование

```bash
# Open sessions tab directly
/sessions

# Alternative: run with tab argument
ccboard --tab sessions
```

## Навигация по вкладке «Сессии»

- `←/→`: переключение между деревом проекта и списком сеансов.
- `↑/↓` : Навигация по элементам.
- `Enter`: просмотреть детали сеанса.
- `/` : Открыть ввод поиска.
- `e`: редактировать JSONL-файл выбранного сеанса.
- `o` : Показать файл сеанса.

## Метаданные сеанса

Каждая сессия показывает:
- **ID**: уникальный идентификатор сеанса.
- **Started**: временная метка первого сообщения.
- **Duration**: общее время разговора.
- **Messages**: количество сообщений
- **Tokens**: общее количество использованных токенов.
- **Models**: используемые модели ИИ (например, opus-4.5, sonnet-4.5)
- **Preview**: первое сообщение пользователя (200 символов).

## Примеры поиска

```
# Search by project name
/my-project

# Search by model
/opus

# Search by message content
/implement feature
```

## Требования

ccboard должен быть установлен. При необходимости запустите `/ccboard-install`.

## Выполнение

```bash
#!/bin/bash

# Check if ccboard is installed
if ! command -v ccboard &> /dev/null; then
    echo "❌ ccboard is not installed"
    echo "Run: /ccboard-install"
    exit 1
fi

# Launch ccboard with Sessions tab (tab index 1, accessible with '2' key)
# For now, launch and user presses '2'
exec ccboard
```

**Note**: в настоящее время запускает ccboard в виде информационной панели. Нажмите `2`, чтобы получить доступ к вкладке «Сеансы».
Будущая версия будет поддерживать `ccboard --tab sessions` для прямого доступа.
