# ccboard — плагин панели управления Claude Code

> Комплексная панель управления TUI/Web для мониторинга и управления Claude Code.

[![Лицензия](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](../../../LICENSE)
[![Ржавчина](https://img.shields.io/badge/rust-1.70%2B-orange.svg)](https://www.rust-lang.org)

## <a name="quick-start"></a>Быстрый старт

### Установка

```bash
# Using Claude Code command
/ccboard-install

# Or manually via cargo
cargo install ccboard
```

### Запустить панель мониторинга

```bash
# Launch TUI
/dashboard

# Or run directly
ccboard
```

## Команды

| Команда | Описание |
|---------|-------------|
| `/dashboard` | Запустить интерактивную панель управления TUI |
| `/mcp-status` | Мониторинг серверов MCP (нажмите `8`) |
| `/costs` | Просмотрите аналитику затрат (нажмите `6`) |
| `/sessions` | Просмотрите историю разговоров (нажмите `2`) |
| `/ccboard-web` | Запустить веб-интерфейс |
| `/ccboard-install` | Установите или обновите ccboard |

## <a name="features"></a>Функции

- **8 Интерактивные вкладки**: Панель управления, Сеансы, Конфигурация, Хуки, Агенты, Затраты, История, MCP
- **Мониторинг в реальном времени**: средство отслеживания файлов для обновлений в реальном времени
- **MCP Management**: состояние и конфигурация сервера.
- **Отслеживание затрат**: аналитика использования токенов и цен (например, всего 9 145 долларов США)
- **Session Explorer**: просмотрите более 1,2 тыс. бесед в более чем 33 проектах.
- **Редактирование файлов**: Нажмите `e`, чтобы редактировать файлы в $EDITOR.
- **Двойной интерфейс**: терминал (TUI) и веб-интерфейс из одного двоичного файла

## Навигация

**Перейти на вкладку**:
- `1` Панель управления
- `2` Сессии
- Конфигурация `3`
- `4` Хуки
- `5` Агенты
- `6` Затраты
- История `7`
- `8` MCP

**Общие ключи**:
- `Tab` / `Shift+Tab`: переход по вкладкам.
- `e`: Редактировать файл в редакторе.
- `o`: Показать файл в поисковике.
- `q` : Выйти
- `F5` : Обновить

## Мониторинг сервера MCP

Вкладка MCP (нажмите `8`) предоставляет:

- **Live Status**: ● Работает, ○ Остановлен, ? Неизвестный
- **Сведения о сервере**: полная команда, аргументы, переменные среды.
- **Быстрые действия**:
  - `e` : Редактировать `claude_desktop_config.json`
  - `o`: показать конфигурацию в поисковике.
  - `r` : Обновить статус сервера.

## Аналитика затрат

Отслеживайте свои расходы Claude Code:

- Всего токенов: 17,32 млн.
- Общая стоимость: 9 145,20 долларов США.
- Разбивка по моделям: Opus 4,5 (76%), Sonnet 4,5 (14%)
- Вероятность попадания в кэш: 99,9%

## Обозреватель сеансов

Просмотр и поиск бесед:

- 1,2 тыс. сессий по 33+ проектам
- Полнотекстовый поиск (нажмите `/`)
- Метаданные: временные метки, токены, модели.
- Редактируйте файлы JSONL напрямую

## Веб-интерфейс

```bash
# Launch web UI
/ccboard-web

# Or with custom port
ccboard web --port 8080

# Run both TUI and Web
ccboard both --port 3333
```

## Требования

- **Rust 1.70+** и Грузы
- **Claude Code** установлен (читается из `~/.claude/`)

## Архитектура

Один двоичный файл Rust (2,4 МБ) с:
- **TUI**: интерфейс терминала на основе Ratatui.
- **Web**: Веб-интерфейс Axum + Leptos
- **Core**: общий уровень данных с наблюдателем файлов.

## Источники данных

ccboard читает из:
- `~/.claude/stats-cache.json` - Статистика
- `~/.claude/claude_desktop_config.json` - Конфигурация MCP
- `~/.claude/projects/*/` — файлы JSONL сеанса
- `.claude/settings.json` — Конфигурация

**Только чтение**: Неинвазивный мониторинг, безопасная работа с Claude Code.

## Производительность

- Начальная загрузка: <2 с для более чем 1000 сеансов.
- Память: ~50 МБ (типичное использование)
- Отложенная загрузка: содержимое сеанса загружается по требованию.

## <a name="limitations"></a>Ограничения

Текущая версия (0.1.0):

- **Только чтение**: операций записи нет.
- Статус **MCP**: только Unix (macOS/Linux)
- **Web UI**: В разработке

## <a name="troubleshooting"></a>Поиск неисправностей

### плата не найдена
```bash
which ccboard          # Check if installed
/ccboard-install       # Install if needed
```

### Данные не видны
```bash
ls ~/.claude/          # Verify Claude Code directory
cat ~/.claude/stats-cache.json  # Check stats file
```

### Статус MCP "Неизвестно"
- Требуется Unix (macOS/Linux)
- Windows по умолчанию показывает «Неизвестно».
- Убедитесь, что сервер работает: `ps aux | grep <server-name>`.
