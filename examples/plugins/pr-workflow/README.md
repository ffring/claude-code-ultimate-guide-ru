# Плагин для работы с PR

Автоматизированная система рассмотрения и проверки запросов на включение.

## <a name="install"></a>Установка

```bash
bash install.sh
```

## Компоненты

- **Агент проверки кода**: Автоматизированные проверки качества и безопасности кода.
- Команда **/review-pr**: анализируйте запросы на запросы и предоставляйте подробные отзывы.
- Команда **/pr**: быстрый рабочий процесс подготовки к PR
- **привязка pre-pr-check**: проверка изменений перед созданием PR.

## <a name="quick-start"></a>Быстрый старт

```bash
# Review an existing PR
/review-pr 123

# Prepare a new PR
/pr

# Check what will be submitted
/validate-changes
```

## <a name="features"></a>Функции

✓ Анализ качества кода
✓ Сканирование безопасности
✓ Проверка тестового покрытия
✓ Проверки соответствия
✓ Автоматические предложения
✓ Уведомления команды
