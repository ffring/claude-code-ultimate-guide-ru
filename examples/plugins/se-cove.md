# <a name="se-cove-chain-of-verification"></a>SE-CoVe: цепочка проверок

Программная адаптация методологии цепочки проверки Meta для Claude Code.

## Исследовательский фонд

**Paper**: «Цепочка проверок уменьшает галлюцинации в больших языковых моделях»
**Авторы**: Дулиавала и др. (Мета ИИ)
**Опубликовано**: Результаты ACL 2024
**Источники**: [arXiv:2309.11495](https://arxiv.org/abs/2309.11495) | [ACL Антология](https://aclanthology.org/2024.findings-acl.212/)

## <a name="how-it-works"></a>Как это работает

5-этапный конвейер, обеспечивающий независимую проверку:

1. **Baseline**: создание исходного решения.
2. **Planner**: создание проверочных вопросов на основе заявок на решение.
3. **Executor**: отвечает на вопросы самостоятельно (никогда не видит базовый уровень)
4. **Синтезатор**: Сравните результаты, выявите расхождения
5. **Output**: создание проверенного решения.

**Критическая инновация**: Верификатор работает без доступа к черновому коду, что предотвращает предвзятость подтверждения.

## Показатели производительности

Результаты исследования Меты (модель Llama 65B):

| Тип задачи | Метрика | Улучшение | Вычислительная стоимость |
|-----------|--------|-------------|-------------------|
| Поколение биографии | ФАКТЫ | +28% (55.9→71.4) | -26% объема выпуска (16,6→12,3 фактов) |
| Закрытый контроль качества | Оценка F1 | +23% (0.39→0.48) | ~2x потребление токенов |
| Вопросы на основе списка | Точность | +112% (0.17→0.36) | Меньше всего ответов |

**Источник**: Дулиавала и др., Результаты ACL 2024 (таблица 1, раздел 4.3).

**Ключевая мысль**: Более высокая точность достигается за счет увеличения объема вычислений и уменьшения объема вывода.

## <a name="when-to-use"></a>Когда использовать

### ✅ Рекомендуется

- **Критический анализ кода**: Архитектурные решения, код, чувствительный к безопасности
- **Комплексная отладка**: Многокомпонентный анализ отказов
- Интеграция **API/library**: Когда правильность > скорость
- **Приемлемая двойная стоимость**: бюджет токенов позволяет получать премию за качество

### ❌ Не рекомендуется

- **Тривиальные изменения**: Простые исправления, форматирование, опечатки.
- **Исследовательское программирование**: быстрое прототипирование, экспериментирование.
- **Жесткие бюджеты токенов**: Когда стоимость является основным ограничением
- **Нужны комплексные результаты**: Когда вам нужны все факты, а не только точная подгруппа

## Установка

```bash
# Add plugin marketplace
/plugin marketplace add vertti/se-cove-claude-plugin

# Install plugin (in separate command)
/plugin install chain-of-verification
```

**Примечание**: команды необходимо вставлять отдельно (ограничение рынка Claude Code).

```bash
# Invoke verification

# Autocomplete available
/ver<Tab>
```

## <a name="limitations"></a>Ограничения

Из исследовательской статьи (раздел 6):

1. **Не панацея.**: уменьшает галлюцинации, но не устраняет их.
2. **Вычислительные затраты**: ~2x использование токена по сравнению с базовым поколением (оценено на основе реализации)
3. **Компромисс объема вывода**: генерирует меньше, но более точные результаты
4. **Зависит от модели**: Протестировано на Llama 65B; обобщение на GPT-4/Claude/Sonnet не проверено
5. **Зависимость задач**: Производительность значительно варьируется в зависимости от типа задачи (23–112%).
6. **Только фактические галлюцинации**: Не учитываются неправильные рассуждения или мнения.
