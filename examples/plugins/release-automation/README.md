# Плагин автоматизации выпуска

Семантическое управление версиями, создание журнала изменений и управление выпусками.

## <a name="install"></a>Установка

```bash
bash install.sh
```

## Компоненты

- Команда **/release**: обновление семантической версии и тегирование
- Команда **/changelog**: создание примечаний к выпуску на основе коммитов.
- **Навык генератора примечаний к выпуску**: Документация по автоматизированному выпуску
- **Обработчик синхронизации версий**: сохранение единообразия версий во всех файлах.

## <a name="quick-start"></a>Быстрый старт

```bash
# Bump version and create release
/release patch      # v1.0.0 → v1.0.1
/release minor      # v1.0.1 → v1.1.0
/release major      # v1.1.0 → v2.0.0

# Generate changelog
/changelog 10       # Last 10 releases

# The hook auto-syncs VERSION across docs
```

## <a name="features"></a>Функции

✓ Семантическое версионирование
✓ Автоматизированный журнал изменений
✓ Маркировка Git
✓ Примечания к выпуску
✓ Согласованность версий
