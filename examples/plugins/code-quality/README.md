# Плагин качества кода

Анализ кода, рефакторинг и обеспечение чистоты кода.

## <a name="install"></a>Установка

```bash
bash install.sh
```

## Компоненты

- **Агент-специалист по рефакторингу**: Автоматическое улучшение кода
- **Агент проверки чистого кода**: Обеспечение соблюдения стандартов качества кода
- Команда **/refactor**: безопасный рефакторинг с проверкой
- Команда **/optimize**: оптимизация производительности

## <a name="quick-start"></a>Быстрый старт

```bash
# Refactor a file or folder
/refactor src/auth/

# Analyze code quality
/audit-codebase

# Get design pattern suggestions
/design-patterns
```

## <a name="features"></a>Функции

✓ Анализ сложности
✓ Предложения по рефакторингу
✓ Руководство по шаблонам проектирования
✓ Оптимизация производительности
✓ Оценка ремонтопригодности
