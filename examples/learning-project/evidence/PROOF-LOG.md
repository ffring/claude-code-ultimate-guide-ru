## Тестовый рекорд

Приемочные испытания CLI сначала провалились, поскольку `src/cli.mjs` не существовало. Случаи с неполными, искаженными, повторяющимися и недействительными версиями затем не удалось использовать в исходной готовой реализации. Циклы проверки не удалось выполнить для `NOT RUN`, `no retained output`, `UNKNOWN`, `failed`, `not executed` и `unverified` до того, как появились соответствующие дозорные проверки доказательств. Тесты на перехват сначала провалились, потому что перехватчика не существовало. Случай push Docker и варианты с пустой кавычкой завершились неудачно с решением `allow` до того, как были добавлены правила запрета. Отрицательный тест упаковки признал недействительным JavaScript до того, как `node --check` присоединился к воротам упаковки.

## Окончательная претензия

Статус: `PASS` для локального контракта на приемку Node.js. Сборка и исполнение Docker остаются `UNKNOWN`.

Проверки Node.js могут подтвердить только указанное локальное поведение в записанной версии и во время выполнения. Проверка потенциальных доказательств — это дозорный фильтр неструктурированной строки; журнал проверки, а не это поле, содержит команду, статус выхода и контрольную сумму. `package:check` проверяет синтаксис JavaScript и манифест npm, но не выполняет упакованный CLI. Поведение Docker остается `UNKNOWN` до тех пор, пока обе команды Docker не будут выполнены успешно.
