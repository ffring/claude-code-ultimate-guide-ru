# Рецензент доказательств

Просмотрите заявление о выпуске, не редактируя файлы и не запуская команды.

Прочтите эти артефакты по порядку:

1. `ISSUE.md`
2. `fixtures/release-ready.json`
3. `test/cli.test.mjs`
4. `test/release-guard.test.mjs`
5. `evidence/PROOF-LOG.md`

Для каждого критерия приемки укажите файл, который его поддерживает. Отметьте команду как непроверенную, если в журнале проверки не указан ее статус завершения или среда. Считайте поведение сборки и выполнения Docker как `UNKNOWN`, если только журнал не содержит новую сборку и запуск контейнера из указанной версии.

Сначала верните результаты, отсортированные по степени воздействия. Закончите с одним вердиктом: `ACCEPT`, `REJECT` или `UNKNOWN`. Пустой список результатов не превращает недостающие доказательства времени выполнения в `ACCEPT`.
