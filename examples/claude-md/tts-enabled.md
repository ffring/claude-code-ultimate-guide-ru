# Проект с включенной TTS

Это файл шаблона `CLAUDE.md` для проектов, использующих Agent Vibes TTS.

## Конфигурация ТТС

**Provider**: Пайпер TTS
**Voice**: fr_FR-tom-medium (французский мужчина)
**Verbosity**: низкий (рекомендуется)
**Effects**: Легкая реверберация.
**Фоновая музыка**: отключено

## Настройки TTS для конкретного проекта

### Отключение звука во время работы с фокусировкой

При работе над задачами, требующими глубокой концентрации, отключите TTS:

```bash
# Mute for this session
/agent-vibes:mute

# Unmute when done
/agent-vibes:unmute
```

### Выборочный TTS (только ошибки)

В этом проекте TTS выдает только сообщения об ошибках:

- ✅ Ошибки, сбои, исключения
- ❌ Регулярные ответы, подтверждения
- ❌Информационные сообщения

**Reason**: Это критически важная производственная система, в которой звуковые оповещения об ошибках полезны, но постоянное повествование отвлекает.

## Голосовые настройки

| Тип задачи | Рекомендуемый голос | Причина |
|-----------|-------------------|--------|
| Обзоры кода | fr_FR-tom-medium | Профессионально, понятно |
| Документация | fr_FR-siwis-medium | Теплый, поучительный тон |
| Отладка | fr_FR-tom-medium (низкая многословность) | Только критические оповещения |

## Справочник команд

Краткая справка для членов команды:

```bash
# Check current voice
/agent-vibes:whoami

# Switch voice
/agent-vibes:switch fr_FR-tom-medium

# Mute/unmute
/agent-vibes:mute
/agent-vibes:unmute

# Adjust verbosity
/agent-vibes:verbosity low

# Disable effects (faster)
/agent-vibes:effects off
```

## Руководящие принципы команды

### Когда отключить звук

- Занятия парным программированием (спикер объясняет, TTS отвлекает)
- Видеовстречи (избегайте конфликтов со звуком)
- Работа с глубоким фокусом (приоритет состояния потока)
- Общественные места (не беспокоить других)

### Когда включать

- Индивидуальные обзоры кода (слушайте, просматривая различия)
- Длительные задачи (звуковые уведомления о завершении)
- Фоновый мониторинг (оповещения об ошибках)
- Режим обучения (двуязычная практика)

## Установка для членов команды

Новым членам команды следует следовать:

1. **Руководство по установке**: [Установка агента Vibes](../integrations/agent-vibes/installation.md)
2. **Выбор голоса**: используйте `fr_FR-tom-medium` для единообразия.
3. **Configuration**: скопировать настройки из этого файла.

## <a name="troubleshooting"></a>Поиск неисправностей

Общие проблемы:

- **Нет звука**: отметьте `cat .claude/tts-provider.txt` → должно быть `piper`
- **Неправильный голос**: Запустить `/agent-vibes:switch fr_FR-tom-medium`
- **Слишком многословно**: Запустите `/agent-vibes:verbosity low`

**Полное устранение неполадок**: [Устранение неполадок Agent Vibes](../integrations/agent-vibes/troubleshooting.md)

## Примечания

- TTS — **optional** — не требуется для вклада в проект.
- Статус отключения звука **project-specific** (`.claude/agentvibes-muted`)
- Голосовые модели **используются глобально** (`~/.claude/piper-voices/`)
