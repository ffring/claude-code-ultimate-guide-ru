# Контракт ограниченного агентского цикла

Используйте этот шаблон, когда один агент может выполнить задание путем повторных действий и проверок. Он сохраняет поток управления явным, не вводя структуру рабочего процесса.

Работоспособный компаньон — [`bounded-loop-example.py`](./bounded-loop-example.py).

## Договор

| Поле | Требуемое решение |
| --- | --- |
| Цель | Какой результат требуется? |
| Действие | Что может измениться при каждой попытке? |
| Наблюдение | Какие доказательства предоставила казнь? |
| Верификатор | Какая независимая проверка принимает или отвергает доказательства? |
| Бюджет | Сколько попыток или сколько затрат может потребовать цикл? |
| Стоп-правило | Какое именно условие возвращает принятый результат? |
| Эскалация | Что произойдет, когда истечет бюджет? |

В примере записывается каждый переход. Отклоненная попытка возвращается в `act`; проверенная попытка переходит на `accepted`; истощение бюджета переходит к `escalated`.

```text
act -> verify -> accepted
 ^        |
 |        v
 +----- rejected

act or verify -> escalated  when the attempt budget is exhausted
```

## Бегать

```bash
python3 examples/workflows/bounded-loop-example.py
```

Ожидаемый результат:

```text
accepted after 2 attempts
```

## Когда переходить к графику

Продолжайте цикл, пока каждый отклоненный результат возвращается к следующему действию. Вводите явный граф, когда рабочему процессу требуется несколько ветвей, параллельная работа, объединения, постоянные контрольные точки или разные полномочия для разных переходов.

См. [Loop & Graph Engineering](../../guide/core/loop-graph-engineering.md) для правил проектирования и [Agent Harness Engineering](../../guide/core/agent-harness.md) для границ времени выполнения вокруг цикла.
