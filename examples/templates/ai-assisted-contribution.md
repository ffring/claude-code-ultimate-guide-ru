# Пакет вкладов с помощью ИИ

Скопируйте поля, необходимые принимающему проекту, в собственный выпуск или шаблон PR. Этот пакет дополняет политику проекта; он не отменяет его и не сертифицирует исправление.

## Потребность и объем

- Вклад проекта и политика поддержки ИИ проверены:
- Существующая проблема или согласованное предложение по функциям:
- Затронутая версия и среда:
- Ожидаемое поведение и его источник:
- Наблюдаемое поведение и минимальное размножение:
- Измененные файлы и причина необходимости каждого из них:
- Намеренно исключены работы:

## Доказательство

| Проверять | Редакция | Точная команда или проверка | Наблюдаемый результат | Лимит |
|---|---|---|---|---|
| Воспроизведение до исправления | | | | |
| Регрессионная проверка после исправления | | | | |
| Соответствующие существующие проверки | | | | |

Запишите «не выполняется» и укажите причину отсутствия проверки. Различают ожидаемый провал теста, неожиданный провал, провал среды и успех. Изменения, вносимые только в документацию, могут использовать сравнение исходных текстов и проверку ссылок вместо искусственных тестов.

## Объяснение автора

- Первопричина:
- Почему это изменение решает эту проблему:
- Соседнее поведение, которое может регрессировать:
- Что я проверил сам:
- Что остается неясным:
- Раскрытие информации о помощи, если этого требует политика проекта:

## Подача и последующее сопровождение

- Мне нужна обратная связь от сопровождающего перед внедрением или отправкой:
- Лицо, ответственное за ответ на отзыв и редактирование исправления:
- Доказательства, признанные недействительными в последней редакции:
- Готово к рассмотрению или отсутствуют доказательства:

Не включайте учетные данные, частный источник, личные данные или несвязанные журналы агентов. Направьте результаты безопасности через политику безопасности проекта.
