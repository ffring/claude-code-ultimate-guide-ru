# Распространение полного руководства Claude Code

В руководстве уже есть глубокая справочная информация. Работа по распространению должна облегчить поиск, обработку, перевод и атрибуцию полезного первого результата. Основное руководство не должно превращаться в рекламный текст.

## Граница

Этот рабочий процесс подготавливает активы и записывает каналы. Публикация, размещение на рынке, распространение информации, изменение лицензии и сообщения, отправленные от имени автора, требуют отдельного разрешения.

Используйте три взаимосвязанных источника истины:

- [`machine-readable/distribution-channels.yaml`](../../machine-readable/distribution-channels.yaml) записывает поля канала, локали, актива, владельца, состояния, атрибутивного URL-адреса и 30-дневного результата;
- [`machine-readable/translations.json`](../../machine-readable/translations.json) записывает право собственности на перевод и его свежесть;
- [рабочий процесс перевода](translations.md) определяет, что означают `current`, `stale` и «поддерживается сообществом».

## Один результат для каждого актива

Каждый актив распределения должен обещать результат, который может быть завершен и проверен.

| Объект | Результат чтения | Место назначения |
| --- | --- | --- |
| Репозиторий README | Решите, соответствует ли руководство целям читателя. | [Руководство по навигации](../../guide/README.md) |
| Целевая страница | Достигните правильной точки входа в обучение или справочную информацию | [Путь обучения](../../guide/learning-path/README.md) |
| Примечание к выпуску | Поймите, что изменилось и кого это должно волновать | [История изменений](../../CHANGELOG.md) |
| EPUB | Прочтите версионную ссылку в автономном режиме | [Рабочий процесс экспорта](whitepaper-build.md) |
| Слайд-дека | Научите один ограниченный рабочий процесс | [Слайды с обучающими маршрутами](../distribution/claude-code-learning-path-slides.pptx) |
| Видео быстрого выигрыша | Выполните одно задание и проверьте его доказательство. | [Быстровыигрышная видеосерия](../distribution/quick-win-video-series.md) |
| Запись в каталоге | Охарактеризуйте ресурс в одном абзаце | [Сравнительный аудит](../resource-evaluations/mltut-learning-resources-comparative-audit.md) |

## Запись канала

Добавьте канал перед созданием его ресурса. Используйте стабильный идентификатор и храните канонический пункт назначения отдельно от атрибутивной ссылки.

```json
{
  "id": "youtube-fr",
  "channel": "youtube",
  "locale": "fr",
  "owner": "Florian Bruniaux",
  "asset": "planned: quick-win video series",
  "asset_status": "planned",
  "production_brief": "docs/distribution/quick-win-video-series.md",
  "production_brief_status": "ready",
  "canonical_url": "https://www.youtube.com/",
  "tagged_url": "https://cc.bruniaux.com/?utm_source=youtube&utm_medium=video&utm_campaign=ccug-learning-path-2026",
  "status": "planned",
  "placement_status": "planned",
  "published_at": null,
  "observed_at": null,
  "submission_date": null,
  "measurement_started_at": null,
  "placement_evidence_url": null,
  "placement_verified_at": null,
  "outcome": {
    "impressions": null,
    "visits": null,
    "clones": null,
    "stars": null
  }
}
```

Реестр `.yaml` намеренно содержит JSON-совместимый YAML. Поэтому валидатор использует только стандартную библиотеку Python.

## Статусная модель

`asset_status` описывает готовность производства. `status` и `placement_status` описывают размещение кампании. Таким образом, готовый актив может оставаться `blocked`, пока отсутствует одобрение или свободный рецензент.

| Статус | Значение | Обязательное следующее действие |
| --- | --- | --- |
| `planned` | Результат и пункт назначения определены | Произвести актив |
| `ready` | Актив существует и прошел проверки | Получить одобрение публикации |
| `submitted` | Внешняя платформа получила его | Запишите дату подачи |
| `published` | Ссылка на кампанию размещена в открытом доступе и проверена. | Запишите URL-адрес доказательства, дату проверки и начало 30-дневного периода. |
| `blocked` | Именованная зависимость отсутствует | Назначьте владельца или создайте необходимое условие |

Не меняйте `blocked` на `ready`, потому что проза существует. Например, китайский ресурс Bilibili также нуждается в текущем переводе, рецензенте, который читает локаль, миниатюре и авторитете публикации.

## Ворота перевода

Прежде чем создавать локализованный ресурс:

1. запустите `python3 scripts/check-translations.py`;
2. проверить записанную версию языка и исходный хэш;
3. назвать имя сопровождающего сообщества, если перевод не является официальным;
4. ссылка на канонический репозиторий перевода;
5. не отправляйте переведенные материалы до тех пор, пока квалифицированный рецензент не проверит копию.

Китайский перевод руководства поддерживается сообществом. Реестр описывает наблюдаемый охват и актуальность данных; он не содержит официальных заявлений о публикации полного руководства.

## Серия быстрого выигрыша

Полезный первый сериал содержит четыре ограниченных эпизода:

1. первое проверенное исправление за 15 минут;
2. выбирать между навыком, субагентом и сервером MCP;
3. построить и протестировать один безопасный хук;
4. сравнить несколько возможных решений и сохранить пакет доказательств.

Каждый выпуск ссылается на одну каноническую страницу, использует URL-адрес канала и заканчивается наблюдаемой проверкой. Стенограмма с отметкой времени позже может быть проиндексирована через YT Insights, но успешная загрузка не доказывает, что урок научил предполагаемому навыку.

Готовые к производству трусы входят в серию видеороликов [, быстро завоевавших успех,](../distribution/quick-win-video-series.md). Слайды курса обучения [](../distribution/claude-code-learning-path-slides.pptx) представляют собой общий рассказ из девяти слайдов для выступлений, семинаров и планирования видео. Оба ресурса остаются неопубликованными до тех пор, пока владелец канала не одобрит внешнее действие.

## Тридцатидневное измерение

Запишите одни и те же четыре необработанных такта для каждого канала после `measurement_started_at`:

- впечатления, когда платформа их демонстрирует;
- посещения отмеченного места назначения;
- клоны репозитория;
- stars.

Сохраните недостающие меры как `null`. Не конвертируйте недостающую аналитику в ноль. Сравнивайте каналы только в течение одного и того же 30-дневного окна наблюдения и сохраняйте дату публикации, дату наблюдения, начало измерения, региональный стандарт, актив и кампанию.

Даты отвечают на разные вопросы:

- `published_at`: когда сам актив стал общедоступным, если известно;
- `observed_at`: когда государственный актив непосредственно наблюдался;
- `submission_date`: когда было отправлено место размещения кампании;
- `placement_verified_at`: когда приписываемая ссылка кампании была проверена на общедоступном канале;
- `measurement_started_at`: когда началось 30-дневное окно результатов.

Существующий общедоступный объект может по-прежнему иметь статус кампании `planned`. Публичное существование не доказывает, что указанная ссылка на кампанию была размещена.

Сами по себе звезды не определяют завершенность обучения или качество обучения. Они измеряют одно видимое действие после воздействия.

## Валидация

Run:

```bash
python3 scripts/check-distribution-channels.py
python3 -m unittest scripts/test-check-distribution-channels.py
```

Валидатор проверяет идентификаторы, места назначения HTTPS, параметры атрибуции, согласованность кампании, согласованность состояния активов и мест размещения, порядок небудущих дат, доказательства размещения, 30-дневное окно и показатели неотрицательных результатов. Он не посещает внешние страницы и не доказывает, что URL-адрес доказательства все еще содержит атрибутивную ссылку.
