# README и контракт на навигацию по веб-сайту

Веб-сайт принадлежит людям, которые просматривают и находят информацию. В репозитории руководств хранятся исходные коды Markdown, файлы многократного использования, машиночитаемые индексы и история вкладов. `machine-readable/navigation.json` соединяет эти поверхности.

## Право собственности

| Поверхность | Ответственность | Каноническое расположение |
|---|---|---|
| Человеческая навигация | Маршруты намерений, поиск, отображаемые страницы, загрузки | `https://cc.bruniaux.com/` |
| Содержание руководства | Полная Markdown и примеры | `guide/`, `examples/`, `docs/` |
| Кураторская модель намерений | `Start`, `Build`, `Scale`, `Resources`, `Updates` | `machine-readable/navigation.json` |
| Сводка репозитория | Короткая точка входа в проект и доступ к исходному коду | `README.md` |
| История гида | Изменения репозитория | `CHANGELOG.md` и `/changelog/` |
| История Claude Code | Версии продукта и влияние на эксплуатацию | `machine-readable/claude-code-releases.yaml` и `/releases/` |

README не должен дублировать карту сайта сайта. Он предоставляет сгенерированный отрывок намерения, краткое руководство для конкретного репозитория и ссылки на источники для участников или читателей в автономном режиме.

## Изменить рабочий процесс

1. Отредактируйте `machine-readable/navigation.json` в репозитории руководств.
2. Запустите `python3 scripts/sync-navigation.py --write`.
3. Просмотрите сгенерированный блок README и результат проверки исходного пути.
4. Создайте площадку, используя репозиторий руководств, доступный как аналог или через `GUIDE_REPO_PATH`.
5. Проверьте `/sitemap/`, `/guide/`, навигацию по заголовку, поиск и общедоступный маршрут, на который нацелена каждая измененная запись.
6. Сохраняйте маршруты только для посадки в общем манифесте с `source_path: null`.

## Приемные ворота

- Пять групп намерений остаются в следующем порядке: `Start`, `Build`, `Scale`, `Resources` и `Updates`.
- Идентификаторы элементов и общедоступные маршруты уникальны.
- Каждый ненулевой `source_path` существует внутри репозитория справочников.
- Каждая объявленная привязка источника преобразуется в заголовок Markdown.
- Отмеченный блок README соответствует байту манифеста после рендеринга.
- Целевая копия соответствует манифесту руководства до сборки Astro.
- Ссылки для публичного чтения нацелены на `cc.bruniaux.com`; Ссылки на репозиторий идентифицируют исходные или загружаемые файлы.
- Подсчеты производятся на потребляющей поверхности или опускаются.
