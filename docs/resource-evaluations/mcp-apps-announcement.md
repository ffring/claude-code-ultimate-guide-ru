## 📄 Резюме

Приложения **MCP (сентябрь 1865 г.)** — это первое официальное расширение Model Context Protocol, позволяющее серверам MCP предоставлять интерактивные пользовательские интерфейсы наряду с традиционными ответами инструментов.

**Ключевые моменты**:
- В соавторстве с создателями OpenAI, Anthropic и MCP-UI.
- Стабильная версия: 26 января 2026 г.
- SDK: `@modelcontextprotocol/ext-apps`
- Поддержка платформ: Claude Desktop, VS Code, ChatGPT, Goose.
- 9 интерактивных инструментов при запуске (Asana, Slack, Figma, Amplitude, Box, Canva, Clay, Hex, monday.com)
