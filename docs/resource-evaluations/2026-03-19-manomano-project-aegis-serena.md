## Управляющее резюме

Команда инженеров ManoMano запустила «Project Aegis», внутренний тест агентов кодирования искусственного интеллекта в своем стеке разработчиков. Их вывод: Серена MCP стала незаменимым инструментом. В статье представлены данные о реальном производственном использовании Serena, сервера MCP на базе LSP, который обеспечивает навигацию по коду на уровне символов и память сеансов. В руководстве уже подробно описана Серена (8+ файлов, большая глубина в `ultimate-guide.md` и `search-tools-mastery.md`), но есть определенный пробел в согласованности: нет записи в `mcp-servers-ecosystem.md`, где GrepAI указан как единственный код search/analysis MCP. Читатель, попадающий на эту страницу, получает неполную картину.

## Краткое содержание

**О чем рассказывается в статье** (реконструировано — не удалось получить прямую выборку):

- Внутренний тест («Проект Эгида»), сравнивающий несколько агентов ИИ-кодирования при выполнении производственных задач.
- Serena MCP признана выдающимся инструментом для навигации по большой базе кода.
- Обоснование: навигация по символам на основе LSP (в отличие от поиска embedding/vector, такого как GrepAI) обеспечивает точные, детерминированные результаты с малой задержкой.
- Эффективность токена: Serena предоставляет целевой контекст (символ + callers/references), а не чтение всего файла.
- Вывод: Серена теперь является частью стандартной системы разработки искусственного интеллекта ManoMano.

**Что делает Серена** (проверено через GitHub oraios/serena + Perplexity):

- Использует протокол языкового сервера (LSP) для понимания семантического кода — фактическое разрешение символов на уровне компилятора, а не встраивание.
- Встроенная поддержка более 30 языков (Python, TypeScript/JS, PHP, Go, Rust, C/C++, Java из коробки)
- Основные инструменты: `find_symbol`, `find_referencing_symbols`, `get_symbols_overview`, `replace_symbol_body`.
- Сеансовая память: `write_memory` / `read_memory` / `list_memories` хранится в `.serena/memories/`.
- Поведенческие режимы: планирование, редактирование, интерактивный, одноразовый — контексты: настольное приложение, агент, помощник по идеям
- Бесплатный, с открытым исходным кодом (GitHub: oraios/serena), запускается локально через `uvx`.
- Интегрируется с Claude Code, Claude Desktop, VSCode, Cursor, Cline

Ключевое отличие **от GrepAI**:

| Аспект | Серена | ГрепАИ |
|--------|--------|--------|
| Подход | LSP (символы уровня компилятора) | Вложения (поиск векторов Олламы) |
| Задержка | ~100 мс | ~500 мс |
| Вариант использования | Навигация по известным символам, рефакторинг | Обнаружение на основе намерений, незнакомый код |
| Настройка | Языковой сервер для каждого языка | Оллама + nomic-embed-text |
| Память | Встроенная сессионная память. | Никто |
| Точность | Детерминированный (точные символы) | Вероятностный (оценка сходства) |

## Заметки о вызовах (агент технического писателя)

Задача агента во время оценки выявила три важных момента:

1. **Score должен отделять качество ресурса от серьезности недостатков.**: 4/5 изначально присваивал смешанные значения «насколько важна Серена» и «насколько хороша эта статья». После разделения их изменено на 3/5.

2. **LSP сложности с настройкой преуменьшены.**: Серене требуется работающий языковой сервер для каждого языка. Для многоязычных репозиториев это нетривиально. Стоит отметить в руководстве.

3. Сеансовая память **Serena пересекается с ICM**: в настоящее время в руководстве нет четкого различия между `.serena/memories/` Серены и межсессионной памятью ICM. Поясняющее примечание предотвратит путаницу пользователей, если оба настроены.
