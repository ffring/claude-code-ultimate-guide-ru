## Резюме содержания

- **Thèse**: Традиционный SDLC устарел с агентами IA, который сжимается в одном букле: «Намерение → Агент → Код + Тесты + Развертывание → Путь? → Идет или грузоотправитель».
- **Инженеры, работающие с искусственным интеллектом**: Ceux qui ont стартует после Cursor, но не только с планированием спринта, сюжетными обзорами или PR-обзорами, а также с работой над продуктами.
- **Как выполняется преобразование**: Требования = итерация, Проектирование = разработка и сотрудничество с агентом, Тестирование = одновременно с генерацией, Проверка кода = восстановление с нуля.
- **Observabilité = tissu conjonctif**: На последнем этапе происходит механизм обратной связи, позволяющий агентам обнаружения и корректировать регрессии автономного образа.
- **Avantage Compétitif = контекстная инженерия**: Обеспечивает качественный контекст для агентов, которые управляют процессами и церемониями.

**Données/métriques**: Aucune. Концепция очистки статьи.

## Причины отказа

1. **Zero donnée empirique**: Заявления, не поддающиеся проверке, являются точными показателями производства. «SDLC мертв» — это экстраординарное заявление без доказательств.
2. **Концепции, которые можно найти**: «Контекстная инженерия» и «петля обратной связи наблюдаемости» документированы из лучших источников. Интеграция этой статьи представляет собой ошибочный источник для темы déjà Solide.
3. **Потенциальный внутренний конфликт**: Это технический директор Highlight.io, платформа для наблюдения. Заявление о том, что «отказ от PR-обзоров» отдает предпочтение направлению на продукт (плюс ошибки в производстве = плюс ценность для наблюдения). Этот предвзятый источник не является сигналом в статье.
4. **Риск отсутствия интеграции = почти нулевой**: Нарратив «SDLC мертв» вездесущ. Руководство для размышлений без донне.
