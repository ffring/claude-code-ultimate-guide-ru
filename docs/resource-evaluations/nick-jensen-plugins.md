## Почему счет упал с 4/5 до 2/5

1. **Статистика устарела**: 63/85/47 была более ранней версией, теперь 67/99/107
2. **Заявление о приеме на работу носит анекдотический характер**: «4–6 недель → 1–2 недели» больше нигде не встречается.
3. **Существуют и лучшие первоисточники**:
   - Официальная документация Anthropic: code.claude.com/docs/en/plugins.
   - wshobson/agents README (текущая статистика)
   - Реестр claude-plugins.dev (11 989 плагинов, 63 065 навыков)

## Предпринятые действия по интеграции

Вместо интеграции статьи Ника Дженсена мы интегрировали **первичные источники**:

### 1. Исправлен раздел 8.5 "Создание пользовательских плагинов" (guide/ultimate-guide.md)

**Before** (неверно):
```
my-plugin/
├── plugin.json           # Plugin manifest
```

**After** (правильно согласно документации Anthropic):
```
my-plugin/
├── .claude-plugin/
│   └── plugin.json       # Plugin manifest (ONLY file in this dir)
├── agents/
├── skills/
├── commands/
├── hooks/
│   └── hooks.json
├── .mcp.json
├── .lsp.json
└── README.md
```

## Извлеченные уроки

1. **Всегда сверяйте статистику с первоисточниками** — в сообщениях в блогах часто приводятся устаревшие данные.
2. **Заявления о производительности требуют внешней проверки** – отдельные улучшения не подлежат обобщению
3. **Исследование Perplexity выявило лучшие источники** - данные реестра > комментарий в блоге
4. **Сначала следует проверить официальную документацию.** - Anthropic содержит подробную документацию по плагинам.
