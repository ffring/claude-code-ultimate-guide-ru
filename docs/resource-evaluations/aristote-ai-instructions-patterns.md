## Выявлены и устранены пробелы

### 1. Политика раскрытия кода ИИ
**Gap**: отсутствует шаблон командного управления для обеспечения видимости кода, созданного ИИ.
**Fix**: в конце раздела 3.5 добавлен раздел «Политика раскрытия кода AI».
**Content**: порог >10 строк, шаблон PR, поэтапное применение по уровням, предупреждение об антишаблоне.

### 2. claude-mem с Gemini (оптимизация затрат)
**Gap**: В руководстве указано «суммирование ИИ через Claude» — пропущена альтернатива Gemini 2.5 Flash ($14/month против $102 Haiku, -86%).
**Fix**: В разделе claude-mem добавлен блок «Оптимизация затрат — используйте Gemini вместо Claude».
**Источник данных**: `claude-mem-analysis-corrected.md` (553 сеанса, ~400/month, измеренные затраты).

### 3. Сосуществование хуков claude-mem
**Gap**: инструкции по установке не предупреждали о риске перезаписи массива перехватчиков.
**Fix**: добавлена ​​ошибка «Критическая установка — сосуществование перехватчиков» с примерами before/after JSON.
**Source**: `claude-mem-install-prompt.md` (6 существующих перехватчиков, явный контрольный список сохранения).

### 4. Клауд-мем при отказе открытия (v9.1.0+)
**Gap**: нет упоминания о поведении надежности, когда рабочий процесс не работает.
**Fix**: Добавлен блок «Надежность: отказоустойчивая архитектура» с инструкциями по перезапуску.
