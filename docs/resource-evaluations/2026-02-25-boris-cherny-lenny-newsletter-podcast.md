## 📄 Резюме содержания

**Подсказки направляют Claude Code :**
- Utiliser le modèle le plus способный (Opus) — un model for end plus vite = moins de tokens au total
- Режим планирования для **~80% результатов** (коэффициент эмпирического изобретательства)
- «Мультиклаудинг»: примеры lancer plusieurs в параллельном режиме
- Запросить Claude конфигуратора своих настроек
- Различные интерфейсы Essayer (настольный компьютер, мобильный телефон, Slack, GitHub)

**Философские продукты/рабочие процессы:**
- Не принуждайте к жестким рабочим процессам — выберите цель + инструменты, отпустите модель навигации
- Прогрессия цепочки работ (1 вещь → цепочка)
- **«Сборка для модели через 6 месяцев»**: разработка будущей модели, не актуальной

**Консоль управления/оборудования:**
- Общие требования: разработчик + проектировщик + дизайн (слияние ролей более 50%)
- **Добавление безграничных жетонов для инженеров** для выхода из дома, оптимизатор в номере
- **Управление проектами** Принцип: интенсивное использование информационных ресурсов, ускорение доставки

**Статистика городов :**
- Claude Code представляет ~**4% от коммитов GitHub publics**
- Активные пользователи за день в два раза больше предыдущего (янвье-феврье 2026 г.)
- Борис ненадолго воссоединяется с курсором перед возвращением через Anthropic (2 недели)

## 📍Рекомендации

### Приоритеты интеграции (без обсуждения)

**1. Коэффициент «Режим плана 80%» → раздел `guide/ultimate-guide.md` Режим плана**

Формат: одна фраза с указанием авторства, весь раздел.
```
"Boris Cherny (Head of Claude Code) recommends starting ~80% of tasks in Plan Mode —
letting the model plan before any code is written."
```
Источник: Информационный бюллетень Ленни, 19 февраля 2026 г.

**2. «Создание модели на 6 месяцев вперед» → раздел «Долгосрочная стратегия» или «Лучшие практики CLAUDE.md**»

Principe strategique nommé et memorable. Seul l'inventeur du produit может быть легитимным с этим авторством. Добавлен номер принципа в разделе philosophie/strategy руководства.

**3. Рекомендации по управлению (неограниченное количество токенов + недостаточный ресурс) → раздел team/enterprise**

Новая су-секция с тремя принципами Бориса для сына:
- Целенаправленно недофинансировать проекты
- Дайте инженерам как можно больше токенов (оптимизируйте только после успеха)
- Поощряйте людей идти быстрее

Cible: технические руководители и менеджеры, которые слушают руководство.

### Варианты интеграции (дополнительная проверка)

- «Запрос на настройку Claude в настройках» → проверка, если вы хотите выполнить автоматическое улучшение в CLAUDE.md
- Общий угол разработки+PM+дизайн → упомянуть во введении или в разделе «Влияние» Claude Code

## 🔥 Челлендж (агент технического писателя)

**Используемый агент** : `technical-writer` (субагент)

**Вердикт агента:**

> «Оценка 3/5 — FAUX. Ca devrait être 4/5.»

Аргументы, необходимые для вызова:

1. **Неоцененный авторитетный источник**: Информационный бюллетень Ленни заставляет Бориса стать статьей для публичного PM/product — формулировки различных методов предыдущих источников. Шаблон établi: les évaluations Борис sous-estiment systématiquement le Gap «документированная особенность против философии использования».

2. **«Режим планирования 80%» не входит в руководство**: Paddo.dev может «перепланировать, если застрял», но чаще всего. Эмпирическое соотношение изобретателя — это другая особенность документирования.

3. **«Создание на 6 месяцев вперед» отсутствует во всех предыдущих оценках.**: решение об архитектуре рабочего процесса, долгосрочное влияние на комментарии пользователей, инвестирующих в CLAUDE.md.

4. **Рекомендации по управлению = нулевое дублирование**: комментарий к руководству по документированию UTILISER Claude Code, а также комментарий DÉPLOYER для использования бюджетных жетонов.

**Очки, полученные при первоначальной оценке**:
- Контекстная аудитория PM/product генерирует контент, отличающийся от разработчиков источников.
- «Попросить Claude настроить параметры» sous-évalué (метацикл различения компаундирования памяти)
- Общий угол в длинной жизни в руководстве

**Риски неинтеграции**:
- Режим Ratio Plan: пользователи продолжают работать спорадически или вместо системы.
- «6 месяцев спустя»: руководство по скрытой оптимизации для мгновенного настоящего
- Рекомендации по управлению: руководство по переходу на другие ресурсы
- Доверие: игнорировать длинное интервью Бориса Черного в информационном бюллетене Ленни - это сигнал смерти для "исчерпывающего руководства"

**Пейволл:**
> «Это проблема: прямое цитирование невозможно без доступа к проверке. Это не проблема: интеграция не требуется, чтобы лекторы проверяли источник. Борис Черный + информационный бюллетень Ленни + дата = точное указание авторства».

- **Регулируемый балл для агента**: 4/5
- **Управляемые точки** : контекст PM/product, настройки мета-цикла, эти общие параметры.
- **Риски отсутствия интеграции**: барабаны по приоритетным 3 очкам
