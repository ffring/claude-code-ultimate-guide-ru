## Краткое содержание

Vitals — это плагин Claude Code (альфа-версия 0.1, MIT, Python stdlib + git), который определяет «горячие точки» кода с помощью составной метрики: `git churn × structural complexity × coupling centrality`. Затем Claude считывает помеченные файлы и предоставляет семантическую диагностику, а не необработанные показатели.

**Ключевые моменты**:
1. Вычисляет отток × сложность × центральность связи — ни один линтер не делает эту комбинацию
2. Claude читает файлы с верхним флагом: в диагностике говорится, что «этот класс обрабатывает маршрутизацию, кэширование, ограничение скорости и метрики в 7137 строках», а не просто «высокую сложность».
3. Фоновое отслеживание изменений, внесенных искусственным интеллектом, с помощью перехватчиков PostToolUse.
4. Ноль зависимостей, ноль ключей API — только Python stdlib + git
5. Версия 0.1 альфа: обнаружение ядра работает, отслеживание тенденций запланировано на версию 0.2+
