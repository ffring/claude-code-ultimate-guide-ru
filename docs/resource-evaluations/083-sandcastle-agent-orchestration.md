## Краткое содержание

Библиотека TypeScript для управления агентами кодирования ИИ в изолированных изолированных программных средах. Предоставляет программный JS/TS API для запуска агентов (Claude Code, Codex, pi, opencode) внутри контейнеров Docker, Podman или Vercel Firecracker со встроенным управлением стратегией ветвей и системой шаблонов подсказок.

**Основные возможности**:
- `run()`, `createSandbox()`, `createWorktree()`, `interactive()` API с автоматической очисткой ресурсов (`await using`)
- Три стратегии ветвления: `head` (прямая запись), `merge-to-head` (безопасная временная ветвь), `branch` (ветвь с явным именем).
- Система подсказок: подстановка `{{KEY}}` + динамическая инъекция контекста `` !`command` ``.
- Захват и возобновление сеанса для Claude Code (автоматический захват JSONL на хост)
- 5 шаблонов рабочих процессов: пустой, простой цикл, последовательный рецензент, параллельный планировщик, параллельный планировщик с проверкой.
- Поставщик пользовательской песочницы API (`createBindMountSandboxProvider`, `createIsolatedSandboxProvider`)

## Задача технического писателя

Агент вызова (Sonnet) рекомендовал понизить версию **до 3/5** на основании:

1. **TypeScript только барьер**: требуется настройка `npx tsx`; исключает пользователей Python/shell-first; ни один другой инструмент в разделе не навязывает этого
2. **Жесткая зависимость от песочницы**: Docker Desktop или Podman должны быть запущены; Провайдер Vercel оплачивается отдельно; настоящий блокировщик для сред corporate/CI
3. Несоответствие ключевой модели **API**: используется `ANTHROPIC_API_KEY` напрямую, а не сеанс подписки Claude Code; расходы выходят за пределы максимального платежного плана
4. **Архитектурная неправильная классификация**: это не «структура оркестровки» в смысле Руфло; запускает двоичный файл `claude` как подпроцесс внутри контейнера (ближе к агенту CI)
5. **Активные критические изменения**: версия 0.5.x с известной ошибкой: шаблон Sequential Reviewer неправильно создает ветку.

**Рекомендация**: Только просмотр записи. Полная документация может ввести в заблуждение читателей, оценивающих производственное оборудование.

**Accepted**: Оценка установлена ​​на 3/5..
