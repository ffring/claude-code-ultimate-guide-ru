## Обновление (01.06.2026)

*Этот блок документирует изменения, произошедшие с момента оценки в марте 2026 года. Оригинальный французский корпус сохранен ниже.*.

**Изменения статуса с марта 2026 г.:**

- Миграция **npm: решена.** Пакет теперь опубликован как `ruflo` на npm (подтверждено с помощью значков README: `npmjs.com/package/ruflo`). Старое имя пакета `claude-flow` устарело. Предупреждение `curl|bash` остается действительным: URL-адрес CDN по-прежнему ссылается на старое имя репо.
- **Ребрендинг: стабильный.** `github.com/ruvnet/ruflo` — активный репозиторий. Переход, отмеченный в мартовской оценке как «выполняемый», завершен.
- **Агент федерации: отправлен.** Это наиболее важная новая возможность. Ruflo теперь поддерживает межмашинное сотрудничество агентов с нулевым доверием через mTLS и проверку личности ed25519, а также конвейер обнаружения PII 14 типов, удаляющий конфиденциальные данные перед любым исходящим сообщением. Оценка поведенческого доверия постоянно обновляется для каждого узла. 9 инструментов MCP и 10 команд CLI управляют полным жизненным циклом. Эта возможность не имеет эквивалента в LangGraph, AutoGen или CrewAI (по умолчанию все они одноэкземплярные). Именно **отсутствовал во всем гайде** до этого обновления.
- **Торговая площадка плагинов: поставляется.** 33 собственных плагина Claude Code, охватывающих Swarm, RAG-память, безопасность, тестирование браузера, Интернет вещей, торговлю и многое другое. Теперь четко документированы два пути установки (облегченный плагин и полный CLI), что устраняет существовавший ранее риск «сложности для новых пользователей», позволяя новичкам начинать с нулевым количеством файлов рабочей области.
- **Обновления шкалы:** 98 специализированных агентов (вместо 60+), 30 навыков (вместо 42+ в предыдущем заявлении), 314 инструментов MCP (путь CLI).
- **Веб-интерфейсы:** Дополнительный размещенный веб-интерфейс на сайте flo.ruv.io и планировщик целей GOAP на сайте target.ruv.io. Ни то, ни другое не требуется для использования CLI.

## Резюме содержания

- **Мультиагентная оркестровка**: преобразование Claude Code в многоагентную платформу с несколькими иерархиями рабочих, ячеистой топологией или роями
- **Архитектура на диванах**: CLI + MCP сервер → Маршрутизатор Q-Learning → Смесь экспертов (8) → 60+ агентов, специализирующихся (программисты, тестировщики, рецензенты, архитекторы, аудиторы безопасности...)
- **42+ навыков, 17 крючков** интегрируется
- **RuVector**: составная WebAssembly, векторный поиск HNSW, самооптимизация SONA, 9 алгоритмов обучения с подкреплением
- **SQLite persistence** (AgentDB, режим WAL) + 8 типов памяти, включая межагентный раздел
- **Установка**: `npx ruflo@latest init --wizard` (рекомендованный голос) или `curl -fsSL https://cdn.jsdelivr.net/gh/ruvnet/claude-flow@main/scripts/install.sh | bash` (выездной)
- **Заявки на производительность** (см. раздел «Проверка фактов»):
  - 84,8% Скорость решения SWE-Bench
  - Снижение токенов на 32,3%
  - Ускорение в 2,8-4,4 раза при параллельной координации
  - 352x преобразования WASM против вызовов LLM
  - 16 400 векторов queries/seconde
  - Самооптимизация SONA <0,05 мс

## Рекомендации

**Действие: интегратор в ближайшее время — после проверки источника и разъяснения претензий**

**Ou интегратор**: `guide/ecosystem/third-party-tools.md` раздел «Многоагентная оркестрация» — для входа в отдельный раздел, как первый пример первой новой категории **«Внешние оркестровки»**, отличающиеся друг от друга многоэкземплярными действиями (Gas Town, мультиклауда).

Самое важное различие: Gas Town / multiclaude = lancer plusieurs Claude Code параллельно. Ruflo = remplacer/augmenter внутренняя оркестровка Claude Code с завершенной структурой. Это две разные архитектуры.

**Ce, который делает передовую интеграцию:**

1. **Аудит источника `npx ruflo@latest`** через `npm pack ruflo` — верификатор отсутствия вредоносных предустановленных скриптов, подтверждение того, что пакет соответствует тому, что README decrit
2. **Clarifier le rebrand**: подтверждение того, что `ruvnet/ruflo` является хорошим активным репозиторием и что claude-flow является архивом или перенаправлением
3. **Бализатор всех заявлений** как «заявка автором, не проверенная» — указанное значение (84,8%, 352x, 16,400/s) не может быть введено в руководство без опубликованной методологии.
4. **Exclure la voie curl|bash** из рекомендаций (безопасный раздел)

**Правильное оформление закуски:**
> Ruflo (anciennement claude-flow) представляет собой внешнюю структуру оркестровки, плюс принятую для Claude Code (18,9 тыс. звезд, сейчас 66 272 по состоянию на 28 июля 2026 г.). В Claude Code есть полный многоагентный диван: более 60 специализирующихся агентов, Q-обучение маршрутизации, постоянство SQLite. Утилизатор, имеющий встроенные возможности Claude Code (инструмент для выполнения задач, су-агенты), недостаточен для случая использования.
