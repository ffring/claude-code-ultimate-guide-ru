## Краткое содержание

Конвейерные мультиагенты с открытым исходным кодом созданы для Claude Code, которые преобразуют `requirements.md` в проект, который можно использовать с помощью 4 последовательных этапов и 6 внешних этапов проверки.

**Очки:**
- Методология **BREAK → МОДЕЛЬ → ДЕЙСТВИЕ → ДЕБРИФ** с 6 воротами (Ворота 0–5)
- Два инварианта абсолютных автоматических проверок: «Нет спецификации, нет кода» и «Нет задачи, нет фиксации».
- Полная цепочка отслеживания: `COMMIT → TASK → US → EPIC → BRIEF`
- Прозрачный номинальный этап токена бюджета: всего ~900 тыс. (ПЕРЕРЫВ 70 тыс., МОДЕЛЬ 100 тыс., ПЛАН 120 тыс., ПОСТРОЙКА 500 тыс.+, ОТЧЕТ 80 тыс.)
- Клонирование репозитория: конкретная реализация (просто документация)

**Ограничения:**
- Jeune (22 коммита, 8 звезд) — pas encore validé en Production à big échelle
- Уникальность JavaScript (React на основе чистой архитектуры)
- Верхний массив (~900K tokens/projet) — адаптация к важным проектам с нуля

## Разбивка очков

### 1. Соответствие Claude Code (5/5)

✅ **Entièrement construit sur Claude Code**: навыки управления фазами, перехваты, действительные инварианты, специальные агенты по роли
✅ **Паттерны направляют**: используйте навыки + хуки + агенты в точном соответствии с руководством и документацией.
✅ **Ссылка на реализацию**: клонируемый репозиторий, иллюстрирующий концепции руководства в реальной ситуации.

### 2. Техническая точность (4/5)

✅ **Проверенные фазы**: BREAK→MODEL→ACT→DEBREF подтверждены в README
✅ **Gates проверены**: Ворота 0-5 через скрипты Node.js (требования, структура, secrets/PII, планирование, качество кода, выпуск)
✅ **Invariants réels**: принудительное применение через tools/validate-commit-msg.js — просто предложения
⚠️ **Ограничение срока созревания**: 4 сезона, архитектура на бис в эволюции

### 3. Novelty/uniqueness (3/5)

✅ **Enforcement outillé** : Скрипты Node.js, которые *bloquent* не используются — шаблон не документирован в руководстве
✅ **Бюджетный токен по фазе**: конкретная оценка ~900 тыс. с разбивкой — уникально в экосистеме
✅ **Цепочка отслеживания**: ЗАДАЧА→США→ЭПИК→КРАТКАЯ информация, указанная в руководстве.
⚠️ **Redondance ~80%** : spec-first.md (830 строк), methodologies.md (Spec Kit/OpenSpec), agent-teams.md, что действительно важно.

### 4. Практичность (3/5)

✅ **Очистить в основном**: клонируемый репозиторий, структура готова.
⚠️ **Coût élevé**: ~900 тыс. токенов × 0,003 доллара США = ~$2.70/projet + хуки обслуживания.
⚠️ **JavaScript uniquement** : Clean Architecture React — полиглот
⚠️ **Комплексная настройка**: Git-хуки + скрипты Node.js в конфигураторе

### 5. Достоверность источника (3/5)

✅ **Представлено публично** : Обсуждение в IA CAFE CLUB (Париж), действительно по общению.
⚠️ **Ограничение на принятие**: 8 звезд, 2 форка, 2 участника (автор + Claude)
⚠️ **Pas encore versionné**: 0 официальных релизов
