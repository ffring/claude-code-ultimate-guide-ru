## Краткое содержание

Справочный репозиторий лучших практик Claude Code. Постоянно обновляется по мере развития Claude Code. Ключевое содержание:

- Полные справочники по агентам (15 полей), навыкам (10 полей) и командам.
- Таксономия глобальных и проектных настроек (система задач v2.1.16, экспериментальные команды агентов)
- Борис Черный: 12 советов по настройке (12 февраля 2026 г., официальный источник)
- Разделы «Мой опыт» с практическими советами (CLAUDE.md < 150 строк, /compact на 50% и т.д.)
- Команда → Агент → Шаблон архитектуры навыков с рабочим примером
- Полная ссылка на флаги запуска CLI
- Серверы MCP для ежедневного использования (Context7, Playwright, Claude в Chrome, DeepWiki, Excalidraw)
- Области памяти агента (user/project/local) с шаблонами межсессионного обучения
- Шаблон саморазвивающегося агента (агент обновляет свои навыки после выполнения)
