## Резюме Кайрн

Сервер MCP Python предлагает организованную память и график знаний с 18 функциями.

Отличия **от Serena/doobidoo**:
- Типизированные отношения (`depends-on`, `resolves`, `causes`)
- Модель биологического распада: решения ~200j, обходные пути ~50j (автоматическая обрезка)
- Полнотекстовый поиск + доверительная маршрутизация
- Межсессионный и перекрестный IDE
