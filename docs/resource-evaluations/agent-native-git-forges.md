# Собственные для агента подделки Git: Entire, Cursor Origin, Cloudflare Artifacts, Anthropic Scion.

**Проверено:** 27 октября 2026 г. **Триггер:** Запуск полной версии Git forge компанией Entire 26 октября 2026 г. **Решение:** интегрировать небольшой альбомный раздел в [Сторонние инструменты](../../guide/ecosystem/third-party-tools.md#agent-native-git-forges-2026), и исправьте каждый существующий отрывок Entire CLI в руководстве в соответствии с текущей документацией Entire.

Оценки измеряют редакционную ценность этого руководства, а не качество, безопасность или производительность продукта. Для этой оценки ни один продукт не был установлен или запущен. Каждое приведенное ниже утверждение было перечитано в его первоисточнике 27 октября 2026 года. Более широкое вторичное сканирование (пресса, Hacker News, конкуренты) использовалось только для поиска кандидатов; претензии, найденные только там, были опущены.

## Решения кандидата

| Кандидат | Счет | Особый вклад | Решение |
|---|---|---|---|
| Вся кузница (Трейлы, хостинг, память) | 4/5 | Первая кузница, которая заменяет запрос на включение оценкой агента и слиянием Гейтса; расширяет уже документированный весь CLI | Пейзажная часть плюс исправленное покрытие CLI |
| Anthropic Потомок | 3/5 | Первичные данные об объеме слияния в масштабе агента и о том, почему классическая очередь слияния прерывается; не продукт | Один абзац, оформленный как урок, а не как инструмент |
| Происхождение курсора | 3/5 | Хостинг внутри агента IDE, при этом GitHub остается источником истины. | Один ряд |
| Артефакты облачного сияния | 3/5 | Программируемое хранилище Git, один репозиторий на сеанс агента. | Один ряд; статус более поздней бета-версии не перепроверялся |

## Исправления, внесенные в существующее содержание руководства.

В репортаже Entire CLI ([evaluation](./entire-cli.md)) за февраль 2026 г. содержались утверждения, которые текущая документация не поддерживает:

| Предыдущая претензия | Текущий источник говорит | Исправить |
|---|---|---|
| «Сертифицировано SOC2 Тип II» | Никакого подтверждения для Entire не найдено; DPA ссылается на SOC 2 и ISO 27001 только для поставщиков инфраструктуры. | Удаленный; указано как не найдено |
| Команды `entire init`, `capture`, `checkpoint --name`, `log`, `rewind`, `handoff`, `approve --approver`, `review --checkpoint`, `audit-export`, `--compliance-mode` | Отсутствует в ссылке [CLI](https://docs.entire.com/cli-reference). | Заменено на `enable`, `checkpoint list/explain`, `session resume`, `search`, `why`, `trail approve/merge`. |
| Неактивное шифрование AES-256, столбец FedRAMP | Не задокументировано | Удалено |
| Контрольные точки в бесхозной ветке `entire/checkpoints/v1` | Хранилище на основе ссылок в `refs/entire/checkpoints/` используется по умолчанию, начиная с CLI 0.10.0; ветка остается для старых репозиториев | Обновлено с обоими бэкэндами |
| Написано на TypeScript; Только macOS/Linux, Windows через WSL | Иди CLI; Установщик Windows PowerShell | Обновлено |
| Ворота утверждения как локальная функция CLI | Ворота принадлежат Тропам в размещенной кузнице. | Обновлено |
| «Независимые от пути» контрольные точки с относительными путями | Не документировано; контрольные точки перемещаются, потому что они являются ссылками на Git | Измененный текст, резюме из нескольких папок помечено как не проверенное. |
| Накладные расходы на хранение «~ 5–10 % от размера проекта» | Не задокументировано | Заменено процедурой измерения |

## Что не было проверено

- Результаты ForgeMark от Entire (418 операций в секунду для Entire против 4,7 для GitHub) и экономия токенов «до 71%» на всем графе: измерения поставщиков, независимое воспроизведение не обнаружено
- Статус Cloudflare Artifacts после апреля 2026 г.
- Какая часть возобновленного сеанса Claude Code сохраняется при изменении пути проекта?
- Конкуренты, встречающиеся только во вторичных источниках (Pierre, GitHub Agent HQ, GitLab Duo Agent Platform, Bitbucket Agentic Pipelines, GitButler, Jujutsu, Graphite, Agent Trace и другие), не перечитывались и не цитируются в руководстве из этой оценки.

## Отслеживание

Entire публикует индекс по адресу [entire.com/llms.txt](https://entire.com/llms.txt) и нумерованный «отправочный» журнал изменений. Перечитывание этого указателя и ссылки на CLI — самый дешевый способ поддерживать актуальность руководства. Повторно проверьте эту оценку, когда Entire CLI достигнет 1.0, когда Entire опубликует аттестацию соответствия или когда появится независимая репродукция ForgeMark.
