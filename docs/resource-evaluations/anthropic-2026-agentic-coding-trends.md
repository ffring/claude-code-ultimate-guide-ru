## 📄 Резюме содержания

**8 перспективных трендов** организуется в 3 категориях:

**Основные тенденции (трансформация SDLC)**:
1. **SDLC кардинально меняется**: Инженеры прошли этап реализации в оркестраторах. Эволютивные уровни абстракции (ассемблер → C → высокий уровень → агентное кодирование). Адаптация: семинары → часы
2. **Один → Скоординированные команды**: Многоагентные системы, параллельное рассуждение, шаблоны оркестратора

**Тенденции возможностей**:
3. **Длительные агенты**: минуты → дни, автономная работа, сдвиг экономики жизнеспособности проекта
4. **Масштабирование человеческого надзора**: автоматизированный контроль качества с помощью искусственного интеллекта, операторы обращаются за помощью, интеллектуальная эскалация
5. **Новые поверхности и пользователи**: исчезают языковые барьеры (COBOL, Fortran), демократизация за пределами инженерного дела

**Тенденции воздействия**:
6. **Изменение производительности**: 3 множителя (возможности × оркестровка × опыт), сжатие временной шкалы, сдвиг совокупной стоимости владения
7. **Случаи нетехнического использования**: юридические вопросы, эксплуатация, автоматизация маркетинга. Эксперты предметной области реализуют напрямую
8. **Security Dual-Use**: демократизированные знания в области безопасности, масштабирование субъектов угроз, агентная киберзащита

**Примеры** (7 предприятий):
- **Fountain**: проверка на 50 % быстрее, иерархическая многоагентная оркестровка.
- **Rakuten**: 7-часовая автономная реализация vLLM (12,5 млн строк, точность 99,9%)
- **CRED**: скорость исполнения в 2 раза, качество сохраняется (финтех)
- **TELUS**: сэкономлено 500 тысяч часов, 13 тысяч индивидуальных решений, доставка на 30 % быстрее.
- **Legora**: Юридическая платформа, юристы автоматизируют без программирования
- **Zapier**: внедрение 89%, более 800 внутренних агентов
- **Код дополнения**: проект 4–8 месяцев → 2 недели

**Исследовательские данные** (внутренний Anthropic):
- 60% работы использует ИИ
- 0–20 % «полностью делегировано» (сотрудничество > делегирование)
- На 67% больше PR merged/engineer/day
- 27% новых работ (без ИИ было бы невозможно)
- Производительность за счет объема выпускаемой продукции, а не только скорости
