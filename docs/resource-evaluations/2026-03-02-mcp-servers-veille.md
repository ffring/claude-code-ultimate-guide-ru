## Краткое содержание

Отчет об исследовании, оценивающий 3 сервера MCP с открытым исходным кодом для рабочих процессов разработки Claude Code, с применением критериев: ≥50 звезд, недавний выпуск (<3 месяцев), четкие README, tests/CI, конкретный вариант использования.

Основные выводы из завесы:

- **GitHub MCP Server** (`github/github-mcp-server`): 27,1 тыс. звезд (теперь 31 775 по состоянию на 28 июля 2026 г.), выпуск v0.31.0 19 февраля 2026 г., официальный GitHub, Go, удаленный MCP на `api.githubcopilot.com/mcp/`, OAuth 2.1 + PAT, крышки Issues/PRs/Projects/Enterprise
- **Exa MCP Server** (`exa-labs/exa-mcp-server`): заявлено 3,1 тыс. звезд (теперь 4780 по состоянию на 28 июля 2026 г., не проверено, см. проверку фактов), официальных выпусков GitHub нет, TypeScript, ключевая функция `get_code_context_exa` для поиска кода, ориентированного на разработчиков.
- **Graphiti MCP Server** (`rawr-ai/mcp-graphiti`): 74 звезды (теперь 100 по состоянию на 28 июля 2026 г.), граф знаний для нескольких проектов на Neo4j + Docker, Python/pipx, CLI (`graphiti compose`, `graphiti up`), проект на ранней стадии

## Вызов (агент технического писателя)

**GitHub MCP — введенные очки**:
- Отсутствует: предупреждение о конфиденциальности для удаленного режима `api.githubcopilot.com` (отправляет данные на серверы GitHub)
- Отсутствует: явное сравнение с сервером Git MCP (два взаимодополняющих уровня: локальный и облачный).
- Отсутствует: рекомендация проверить существующий `git-mcp-server-evaluation.md` (5/5 CRITICAL, никогда не интегрировался)
- Скорректированная оценка: 4/5 (не 5/5)

**Exa MCP — введенные очки**:
- Количество звезд невозможно проверить: Вейль утверждает, что 3,1 тыс., поиск Perplexity нашел ~ 220 звезд.
- Никаких официальных выпусков GitHub — управление версиями только через npm, критерий новизны смягчен без четких доказательств.
- Встроенный веб-поиск в Claude Code охватывает базовый вариант использования поиска web/code без дополнительной зависимости от SaaS.
- Оценка скорректирована: 2/5 (отклонено)

**Граффити MCP — измененные точки**:
- 74 звезды едва переступают порог; зрелость проекта не определена
- Kairn (уже в разделе 8.2 руководства) описывает вариант использования постоянной памяти/графа знаний для рабочих процессов Claude Code.
- Neo4j + Docker + LLM API зависимость является тяжелой для большинства пользователей
- Оценка скорректирована: 2/5 (отклонено)

**Риски отсутствия интеграции (GitHub MCP)**:
- Руководство пользователя пропускает самое полезное для автоматизации GitHub MCP для Claude Code
- Нет различия между Git (локальный) и GitHub (облако) — распространенная точка путаницы.
- Оценка Git MCP была 5/5 КРИТИЧЕСКОЙ, но никогда не была интегрирована — недосмотр исправлен одновременно.
