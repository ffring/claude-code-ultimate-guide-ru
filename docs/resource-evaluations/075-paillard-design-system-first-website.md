## Краткое содержание

Рабочий процесс создания индивидуального веб-сайта примерно за 2 часа с использованием Claude Code, основанный на подходе «дизайн прежде всего». Основной тезис: Claude Code воплощает ваш дизайнерский вкус, а не заменяет его. Прежде чем предлагать подсказку, необходимо определить систему дизайна, иначе каждая сгенерированная страница будет смещаться.

Четырехшаговый метод с конкретными подсказками опубликован в статье:
1. **brand-book.html**: цветовая палитра с семантическими ролями, шрифтами, переменными CSS.
2. **ui-kit.html**: базовые компоненты, документированные с помощью Tailwind CSS.
3. **Полная разработка сайта**: анимация прокрутки, прикрепленные изображения, нижние колонтитулы.
4. **Условные формы** (бонус) — многошаговые формы на основе JSON со скриптом Google Apps.

Конкретный проект: mixt.care (персонализированная дерматология). Стек: Tailwind CSS + vanilla JS (Intersection Observer).

## Обоснование оценки

**3/5 — актуально, интегрируйте как полевой пример.**

Четырехэтапная методология структурно обоснована, а четыре подсказки являются конкретными и пригодными для использования. Основная идея (справочные файлы HTML как постоянный контекст Claude Code) не документирована в руководстве и действительно может использоваться повторно.

Однако: нет покрытия WCAG/accessibility, нет отличий от Cursor/Copilot, нет репозитория GitHub для проверки результатов и нет обсуждения ремонтопригодности после MVP. Технические разделы руководства нуждаются в более точных источниках.

## Выявлен пробел → приняты меры

**Gap**: в руководстве не было документации по шаблону «Справочный файл проекта» — `brand-book.html` и `ui-kit.html` сохранялись в корне проекта в качестве постоянных контекстных файлов для Claude Code. Этот шаблон обеспечивает согласованность дизайна на всех сгенерированных страницах без повторных запросов.

**Action**: Добавлен `examples/claude-md/design-reference-file.md` — отдельный шаблон для паттерна, содержащий:
- Рекомендуемая структура проекта
- Фрагмент CLAUDE.md для активации справки по системе автоматического проектирования
- Запрос brand-book.html со встроенным аудитом WCAG
- Запрос документации ui-kit.html
- Подсказка по аудиту цвета (соответствие WCAG 2.1, моделирование цветовой слепоты, предложения по исправлению)

Никаких изменений в `ultimate-guide.md` — шаблон задокументирован в качестве примера, а не помещен в раздел руководства. Оценка не оправдывает размещение в центре.
