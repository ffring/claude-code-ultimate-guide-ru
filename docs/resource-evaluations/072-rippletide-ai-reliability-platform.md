**Источник:** [Документация Rippletide](https://rippletide.com) / [llms-full.txt](https://rippletide.com/llms-full.txt)
**Type:** Официальная документация — в форме SaaS (оценка, постоянная память, определённый смысл)
**Оценено:** 28 февраля 2026 г.

---

## 📄 Резюме содержания

Rippletide — это гибкая пластинчатая форма IA articulée autour de trois piliers:

1. **Eval**: обнаружение галлюцинаций, CLI, устанавливаемый через `npx rippletide`, интеграция CI/CD, источники знаний (местные фичи, сосновая шишка, PostgreSQL)
2. **Context Graph**: постоянная межсессионная память, доступная через сервер MCP (7 инструментов, 4 ресурса), совместимый Claude Code, Claude Desktop, Cursor и VS Code.
3. **Decision Runtime**: Обоснование определяется с помощью гиперграфа (структуры вопросов и ответов, теги, действия, предикаты состояния), внутреннее заявление: «<1% галлюцинаций»

**Точки интеграции с Claude Code:**
- Документированная конфигурация `.mcp.json` для ответвления сервера MCP Rippletide
- Возможно самостоятельное размещение (Node.js >= 18, развертывание на железной дороге в один клик)
- Интеграция LangChain (вставка LLM)
- Доступен разъем Amazon Bedrock

**Финальный счет: 2/5**

**Обоснование:** Rippletide может создать сценарий использования (постоянная запись перекрестного сеанса через MCP), но остальные уровни продукта SaaS без видимого внедрения в сообществе. Подробное руководство по серверам MCP и список шаблонов интеграции. Rippletide был среди всех, кого упомянули в списке серверов MCP на доступных уровнях, но тема была частью всего. Заявления о эффективности, не поддающиеся проверке («галлюцинации <1%», «степень разрешения 85% → 96%)», без опубликованной методологии. Цены недокументированные. ## 🔥 Челлендж (технический писатель)

**Первоначальное предложение:** 2/5
**Оценка после соревнования:** 2/5 (обслуживание)

**Аргументы для увеличения счета:**

1. Сервер **MCP natif**: Rippletide раскрывает виртуальный сервер MCP с 7 документальными функциями, совместимыми с Claude Code. Это конкретно, это просто маркетинг
2. **Eval CLI unique**: `npx rippletide` для обнаружения галлюцинаций в CI/CD — это вариант использования, отсутствующий в руководстве. Гэп катушка
3. **llms.txt exemplaire**: Структурная документация по потреблению LLM, значения для машиночитаемого раздела

**Pourquoi оставшийся счет 2/5:**

- Угол MCP доступен: руководство по документированию шаблонов MCP для отдельных пользователей. Lister Rippletide в списке уровней серверов, доступных для назначаемого контента
- Угол оценки CI/CD является потенциально интересным, но источником является маркетинг коммерческого продукта без внешней проверки. Утверждение «<1% галлюцинаций» без опубликованной методологии является фактической ошибкой по ассоциации.
- Le llms.txt может быть примечанием как хороший практический пример, но это упоминание на полях в существующем разделе, па новом содержании.

**Критика конструктивная:**
> «Угловая оценка CLI — это один из разрывов. Более базовый раздел руководства по маркетингу претензий SaaS без видимой тяги может быть ошибкой. Если Rippletide публикует тесты или стремится к измеримому внедрению, оно оценивается».
