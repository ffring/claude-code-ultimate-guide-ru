## 📄 Резюме содержания

- **Прорывной метод для гибкой разработки на основе искусственного интеллекта**: оркестратор фреймворка, более 19 специализированных агентов (аналитик, проектировщик, архитектор, разработчик, контроль качества...) в цикле логической жизни
- **Principe Central**: «никакого кода до тех пор, пока план не будет проверен человеком» (aucune ligne de code n'est écrite avant qu'un PRD + Architecture Doc + UX spec aient été validés par un humain)
- **Trois Pistes de Planification**: Quick Flow Track (быстрое исправление), BMad Method Track (PRD + архитектура + UX-комплекс), Enterprise Method Track (согласовано)
- **Два композитора-любителя**: Агентическое планирование и контекстно-инженерная разработка
- **Modularité**: пакеты расширения, устанавливаемые по требованию (`bmad install expansion-packs/healthcare`)

Происхождение этой оценки: поиск альтернатив с открытым исходным кодом или шаблон, представленный для WeScale/Maleus во время встречи GenAI во Франции (июль 2026 г.), поэтому разложение PRD → уроки → сборка → ворота со строгим управлением. BMAD-METHOD - это независимый ремонт в двух проходах различных исследований (прямой веб-поиск + поиск в кратчайшие сроки для пользователя), который обеспечивает уверенность в актуальности.

## 🔥 Вызов

**Тестируемое возражение**: "BMAD-METHOD не является просто переформулировкой режима планирования + CLAUDE.md?"

**Réponse**: Нет, разница в структуре - это количество одинаковых ролей (19+ против одного агента, который планирует) и факт, что каждая роль производит отдельную версию артефакта (PRD, Архитектурная документация, UX-спецификация) перед тем, как разработка не будет рассмотрена. Режим планирования продукта Claude Code — уникальный план; BMAD создает цепочку документов, подписанных разными людьми. Это образец организации труда, это просто быстро и долго.

**Риск отсутствия интеграции**: пользователи используют «комментарий к структуратору цикла PRD → архитектура → разработка с агентами», чтобы BMAD работал без комментариев к комбайнеру с Claude Code.
