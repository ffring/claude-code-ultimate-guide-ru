## Управляющее резюме

Google Antigravity — это **agent, первый IDE** (форк VS Code), выпущенный в конце 2025 года, который переносит разработку с традиционного редактирования кода на автономные рабочие процессы, управляемые агентом. Он представляет собой фундаментально отличную от Claude Code философию: максимальная автономия агента против явного контроля разработчика.

**Почему 3/5**: Это не прямая интеграция с Claude Code, но важный игрок экосистемы, о котором следует отметить наше руководство. Философский контраст (сначала терминал и агент) является поучительным для читателей, выбирающих свой рабочий процесс. Мост антигравитация-Клод-Прокси создает конкретную связь.

## Контент-анализ

### Ключевые факты (проверенные)

1. **Архитектура**: IDE с приоритетом агента (вилка VS Code) с тремя поверхностями — редактор, менеджер агентов, интеграция с браузером.
2. **Мультимодель**: одновременно использует Gemini 3 Pro, Claude 4.5, Liquid AI для различных задач.
3. Экосистема **Skills**: репозитории сообщества с от 58 до 856+ навыков (проверенные репозитории GitHub: rmyndharis/antigravity-skills, sickn33/antigravity-awesome-skills)
4. **Цены**: $20/month (в комплекте) или $80-90/month
5. **Claude мост**: пакет `antigravity-claude-proxy` npm — прокси-сервер, предоставляющий Anthropic-совместимый API, поддерживаемый облачным кодом Antigravity

### Сравнение философии

| Измерение | Claude Code | Гугл Антигравитация |
|-----------|-------------|-------------------|
| **Парадигма** | Сначала терминал, родной CLI | Агент-первый, IDE-родной |
| **Контроль разработчика** | Явное одобрение каждого редактирования | Более высокая автономия, агенты действуют независимо |
| **Контекстная модель** | Уровень кодовой базы через CLAUDE.md | Мультиповерхность (редактор + браузер + терминал) |
| **CI/CD** | Родной (безголовый, конвейеры) | Не зрелый |
| **Профиль риска** | Предсказуемый, консервативный | Более высокая автономность = более высокий риск превышения полномочий |
| **Multi-agent** | Команды агентов (v2.1+) | Встроенная многоагентная оркестровка |
| **Навыки** | `.claude/skills/` (фронтовая часть YAML) | На основе каталога, другой формат |
| **Цены** | Подписка на максимальный план | $20-90/month |

## Рекомендации по интеграции

### Где

**Раздел 6.1**: Новый подраздел после Раздела 6 (Инструменты на основе IDE) перед Разделом 7.

Название: `## 6.1 Google Antigravity (Agent-First IDE)`

### Что включить

1. **Что это такое** (3 строки): сначала агент IDE, форк VS Code, многоагентная оркестровка
2. **Сравнение философий**: «Сначала терминал» или «Сначала агент» (таблица)
3. **Bridge Tool**: npm-пакет antigravity-claude-proxy
4. **Компромиссы**: автономность против предсказуемости, зрелость CI/CD, когнитивные издержки
5. **Когда стоит рассмотреть**: кодирование Vibe, быстрое прототипирование, рабочие процессы, отличные от CLI

### Что НЕ включать

- Никакого руководства (выходит за рамки — мы документируем Claude Code, а не конкурентов)
- Нет руководства по миграции навыков (различные экосистемы)
- Нет подробного анализа цен (изменяются слишком быстро)

### Приоритет

**Medium**: Не срочно, но это реальный пробел в охвате экосистемы.

## Челлендж (технический писатель)

- **Оценка оправдана**: 3/5 верна. Не 4/5, потому что Антигравитация — это отдельный инструмент, а не интеграция с Claude Code. Не 2/5, потому что философский контраст действительно поучителен.
- **Риск неинтеграции**: Читатели, сравнивающие инструменты, не найдут Антигравитацию в нашем руководстве. Матрица агентов кодирования ИИ (раздел 11) частично охватывает это, но в ней нет детального сравнения, которое мы можем предоставить.
- **Оценка скорректирована**: 3/5 (без изменений)
