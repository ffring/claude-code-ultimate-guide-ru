## 📄 Резюме содержания

Straude - это социальная панель для отслеживания и участия в сообществе Claude Code. L'Util Pousse les Stats d'Usage Locales (токены, токены, модели) и разделенная платформа с таблицей лидеров, полосами и глобальным статусом.

**Техника флюса**:
1. Аутентификация OAuth через навигатор → наличие токена в `~/.straude/config.json`
2. Собирайте через `ccusage daily --json` (официальный Claude Code) и `@ccusage/codex`.
3. Собранные сообщения о `https://straude.com/api/usage/submit`

**Добавлены посланники на сервере** (в течение дня):
- Курс в долларах США
- Токены: ввод, вывод, создание кэша, чтение кэша, итого.
- Используемые модели (например: `claude-sonnet-4-6`, `claude-opus-4-6`)
- Разбивка по номинальной модели
- Хэш SHA256 для обвинений в адрес брутальных животных
- `device_id` : UUID, созданный для первого использования.
- `device_name` : имя хоста машины (например: `prenom-macbook.local`)

**Это тот, кто послан PAS**: описания, исходный код, диалоги, ключ API.

### Обоснование

Не используйте документацию `ccusage` (справочная информация) и `ccburn`. Шаг может быть под другим углом — отслеживание социальных сетей — который не является документальным. Уместность больше всего ограничена: это выход из ниши (таблица лидеров), выход на бис в третий раз (13 дней до даты анализа), без истории доверия и политики конфиденциальности.

## 🔍 Подробный анализ безопасности

### Проверка исходного кода

Пакет проверен по указанию регистрации npm (`npm pack straude@0.1.9`) и файлы компилируются для интеграции. Обнаружена обфускация.

**Architecture** (20 описаний, 35 КБ без сжатия):

```
dist/
├── index.js              # CLI entry point
├── config.js             # DEFAULT_API_URL = "https://straude.com"
├── commands/
│   ├── login.js          # OAuth browser-based (poll + token save)
│   ├── push.js           # Collecte ccusage + POST /api/usage/submit
│   └── status.js         # GET /api/users/me/status
└── lib/
    ├── auth.js           # Lecture/écriture ~/.straude/config.json
    ├── api.js            # fetch() avec Bearer token
    ├── ccusage.js        # exec("ccusage daily --json")
    └── codex.js          # exec("npx @ccusage/codex daily --json")
```

### Положительные баллы

- Наличие токена с разрешениями `0600` (уникальная собственность лекций)
- Доступ к файловой системе из `~/.straude/config.json`
- Действия демона или системы персистентности (pas de crontab, launchd, systemd)
- Ограничение полезной нагрузки в соответствии с общими метриками, согласованное с описанием
- Опция `--dry-run` Pour Inspector без посланника
