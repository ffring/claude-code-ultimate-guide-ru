## Краткое содержание

AgentOS — это виртуализированные виртуальные машины Linux, которые работают внутри вашего собственного процесса Node и позиционируются как замена облачным песочницам выполнения кода (E2B, Daytona, Modal) для рабочих нагрузок агентов, которым не требуется настоящее ядро ​​Linux. `npm install @rivet-dev/agentos` предоставляет вам виртуальную машину без микроВМ для загрузки, без контейнера для извлечения и без учетной записи провайдера.

Архитектура: доверенный дополнительный процесс Rust владеет ядром (`crates/kernel`, `crates/vfs`, `crates/execution`) с многоуровневой виртуальной файловой системой (оверлей плюс монтирования для S3, Google Drive, каталогами хостов), таблицей виртуальных процессов с `fork`/`exec`/`wait` и реальными сигналами, таблицей сокетов, каналами, PTY, DNS. Ни один гостевой системный вызов не касается хоста напрямую; гость запрашивает, ядро ​​решает, ядро ​​выполняет. Недоверенный исполнитель запускает гостевой JavaScript на собственном V8 с полным JIT (не интерпретатором), а скомпилированные инструменты запускаются в WASM.

`software/` (42 пакета) компилирует настоящие исходные инструменты Linux (GNU coreutils, grep, sed, gawk, Curl, sqlite3, Duckdb, Vim, git, ripgrep) в `wasm32-wasip1` с системным корнем, полностью принадлежащим команде, с исправленными Rust std и libc. Это не стандартный WASI; это Linux-in-WASM, с отсутствующими вызовами POSIX, реализованными на уровне libc или в виде импорта хоста.

Отличитель: хост **bindings**. Определенная хостом функция JS со схемой Zod отображается внутри виртуальной машины в виде команды оболочки (`/usr/local/bin/agentos-weather forecast --city Paris`). Агент вызывает его, как и любой другой инструмент CLI. Ключи API никогда не входят в виртуальную машину; агент видит вход и выход, а не секрет. Агенты (Pi, Claude Code, Codex, OpenCode) запускаются как гостевые процессы, использующие ACP, с длительными сеансами (завершенные события ACP попадают в SQLite, виртуальная машина переходит в режим сна после 15 минут бездействия и просыпается при подключении или cron; каждая виртуальная машина является Rivet Actor). Шесть областей разрешений (`fs`, `network`, `childProcess`, `process`, `env`, `binding`), сеть запрещена по умолчанию, все остальное разрешено, поскольку она уже виртуализирована; отказ возвращает `EACCES` до того, как будет затронут какой-либо ресурс хоста.

Команда указывает на E2B/Daytona с холодным стартом 440 мс и минимум 1 ГБ ОЗУ. Это цифры, сообщенные поставщиком для одной машины, которые не воспроизводятся независимо в ходе этой оценки или, насколько это удалось выяснить, какой-либо третьей стороной. В заголовке «Сравнение холодного запуска 92x» также сравниваются два разных типа вещей: запуск изолированной V8 и загрузка полной микроVM Linux. Оба факта имеют место при любом упоминании этих цифр.

## Предостережение о честности, и это важно

«ВМ» — это маркетинговый выбор. В этом стеке нет ни KVM, ни Firecracker, ни аппаратной виртуализации. Изоляция полностью опирается на изоляты V8 и песочницу WASM, поддерживаемую сайдкаром Rust. Собственная заявленная модель угроз проекта устанавливает границу безопасности на уровне sidecar/executor, а не на гипервизоре. Это хорошо для обычного кода ненадежного агента и существенно слабее, чем аппаратная изоляция от мотивированного злоумышленника, охотящегося за побегом из V8. Намеренно за пределами рассмотрения: браузер, собственный двоичный файл x86, тяжелый сервер разработки, собственная компиляция. Для них сама документация указывает на запуск настоящей песочницы поверх.

## Где он находится относительно существующего покрытия руководства

В `guide/security/sandbox-isolation.md` §5, озаглавленном словами «облачные песочницы» (Fly.io Sprites, Cloudflare Sandbox SDK, Vercel Sandboxes, E2B), перечислены четыре поставщика, и каждый из них выставляет счета через облачного провайдера. AgentOS является недостающим противоположным примером: ни один поставщик, ни одна учетная запись не запускаются внутри собственного процесса Node хоста. Это настоящий пробел в разделе в его нынешнем виде, а не постепенное дополнение к существующему списку.

Технически это также глубже, чем то, что в настоящее время охватывает `sandbox-isolation.md` §7b («Песочница для инструментов MCP на основе WebAssembly, экспериментальная»). Этот раздел предназначен для изоляции отдельных вызовов инструментов MCP на уровне доступа к ОС (таких инструментов, как Wassette). Системный корень WASM агента компилирует значительную часть пользовательского пространства Linux (42 пакета, включая git, ripgrep, sqlite3, Duckdb) с принадлежащей ему libc, что существенно превышает возможности, предоставляемые для каждого инструмента.

Один независимый, несвязанный источник данных из собственного исследовательского корпуса транскриптов YouTube, содержащегося в руководстве (`yt-insights`, 29 июля 2026 г.): Рене Брандель «Как мы взломали ИИ-агенты пакета YC Spring 2025» (DevCon Fall 2025, 21 ноября 2025 г.) рекомендует использовать противоположный вариант по умолчанию, используя существующего поставщика песочницы (E2B, Daytona), а не создавать свой собственный. AgentOS — это именно тот проект, против создания которого обычно советуют предостерегать команда, которая, похоже, все равно его создала. Стоит назвать живой контрпример, когда цитируется этот совет.

## Решение

**Интегрироваться в `guide/security/sandbox-isolation.md` §5 в качестве явного внутрипроцессного контрпримера к четырем поставщикам облачных услуг из раздела, плюс одна новая строка TL;DR.**

Опишите каждый эталонный показатель как указанный поставщиком, датированный и относящийся к одной машине, в соответствии с собственными выводами этой оценки. Прямо сформулируйте предостережение об отсутствии гипервизора, а не позволяйте слову «VM» подразумевать аппаратную изоляцию, которой у нее нет. Перекрестная ссылка на §7b, чтобы читатель, сравнивающий AgentOS с песочницей инструмента MCP в стиле Wassette, понял, что они решают частично перекрывающиеся, но разномасштабные проблемы.

**Триггер повторного посещения**: отмеченный выпуск `1.0.0`, независимо воспроизведенный тест или второй сопровождающий, пересекающий 20 % коммитов за скользящий квартал.
