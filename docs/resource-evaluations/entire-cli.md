## Управляющее резюме

Entire CLI — это платформа **agent**, которая записывает сеансы агента ИИ (Claude Code, Gemini CLI) в качестве контрольных точек с контролем версий в репозиториях Git. Запущенный 10–12 февраля 2026 года с финансированием в размере 60 миллионов долларов США бывшим генеральным директором GitHub Томасом Домке, он обеспечивает:

- **Перематываемые контрольные точки** сохранение подсказок + рассуждения + использование инструментов + состояния файлов
- **Уровень управления** со шлюзами утверждения, областями разрешений и журналами аудита
- **Передача агентов** с сохранением контекста (Claude → Gemini → пользовательские агенты)
- **Хранилище на базе Git** в отдельной ветке (без загрязнения основной истории)

**Ключевые отличия:**
- Единственный инструмент, обеспечивающий воспроизведение сеанса (заполняет задокументированный пробел в third-party-tools.md)
- Функции управления, специально созданные для обеспечения соответствия требованиям (SOC2, HIPAA, FedRAMP)
- Заменяет устаревший git-ai (репозиторий 404), описанный в руководстве.
