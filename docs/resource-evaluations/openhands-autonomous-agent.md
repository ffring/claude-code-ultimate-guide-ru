## 📄 Резюме содержания

- **Anciennement OpenDevin**, платформа с открытым исходным кодом для агентов облачного кода, поддерживающая All Hands AI
- **Делегирование су-агентов**: главный планирующий агент создает график зависимостей (уровень 0 выполняется параллельно, уровень 1 демаршируется по разрешению конкретной зависимости, внимание к завершению уровня 0)
- **Объедините элементы "интегратора"**: объедините файлы, выполните операции импорта, подключите приложения API к внешнему интерфейсу и выполните полный набор тестов
- **Изолированная песочница**: выполнение в защищенной среде, интегрированная возможность аудита
- **OpenHands Cloud/Enterprise**: «Плоскость управления агентами» для управления в школе (защитные ограждения, бюджеты, внутренний рынок плагинов), функциональные резервы для бесплатных выплат, для использования с открытым исходным кодом

## 🔥 Вызов

**Проверяемое возражение**: «OpenHands не является просто SWE-агентом со звездами?»

**Réponse**: Нет, разница в структуре - это параллельное выполнение по графику зависимостей (SWE-агент является последовательным, выполняется для отдельной задачи GitHub по назначению) и существует механизм автоматической интеграции/слияния. Это кандидат на OSS, а также процедура шаблона «построить изолированное параллельное + слияние» в разговоре WeScale/Maleus, с Девином, который одновременно работает с прямым владельцем.

**Риск неинтеграции**: лектор, читающий эквивалент OSS, автоматически подготавливаемый к Девину, не находит его в руководствах, которые существуют и которые есть, плюс зрелые, которые представляют собой множество альтернатив в городах.
