### Критические проблемы

**1. Заявление о емкости контекста**: Блог объединяет две разные концепции:
- **Полезная емкость** (70–75%): максимальная рекомендуемая скорость заполнения для обеспечения производительности.
- **Снижение качества**: разрыв в производительности, который проявляется при высокой скорости заполнения.

В руководстве обе концепции рассматриваются отдельно и правильно. Цифра 50–60 % слишком упрощает ситуацию и рискует ввести пользователей в заблуждение.

### Исправление применено к руководству

**Ctrl+R Привязка клавиш**: Блог правильно определяет Ctrl+R как «поиск по истории». Наш гид неправильно задокументировал это как «Повторить попытку» в 5 местах. Проверка официальных сочетаний клавиш (действие `history:search`) подтверждает, что блог был прав. Исправлен гайд (cheatsheet.md + ultimate-guide.md).
