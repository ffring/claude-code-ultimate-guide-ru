## 📄 Резюме

- Двухуровневая структура CLAUDE.md: `~/.claude/CLAUDE.md` (глобальный, ~30 строк) + `./CLAUDE.md` на каждое репо (~40 строк). Глобальный = кодирование philosophy/conventions. Проект = то, что агент не может обнаружить только из кода.
- Ссылки: Документ ETH Zurich arXiv 2602.11988: Контекстные файлы, сгенерированные ИИ, дают -3% шанс успеха агента и +20% стоимость вывода. Минимальные файлы, написанные человеком, дают ~+4%.
- Основное правило: пишите только то, что агент не может обнаружить независимо от базы кода.
- Репозиторий GitHub (https://github.com/reizam/claude-md-templates): 2 готовых к разветвлению шаблона + 3 слэш-команды, устанавливаемые через `npx skills add reizam/claude-md-templates` (генерация глобального, создание проекта, аудит существующего CLAUDE.md), 8 звезд при оценке (теперь 12 по состоянию на 28 июля 2026 г.).

## 📍Рекомендации

**Не стоит использовать отдельную интеграцию**, поскольку статья уже оценена.

Стоит рассмотреть одно целевое дополнение:

**Where**: `guide/core/context-engineering.md`, существующий раздел на CLAUDE.md size/quality.

**What**: Добавьте тест принятия решения в одну строку: «Пишите только то, что агент не может обнаружить из самого кода». Это более четкая формулировка, чем нынешнее руководство («essentiels au projet»), и она считается практической эвристикой.

**Priority**: Низкий. Интеграция бумажных документов (уже запланированная после оценки 19 февраля 2026 г.) является приоритетом. В лучшем случае это улучшение формулировки.

Концепция команды `/claude-md-audit` из репозитория GitHub стоит отслеживать в каталоге examples/commands/, если репозиторий получит распространение (сейчас 8 звезд — слишком рано).
