## Краткое содержание

CLI-компаньон для сервера Context7 MCP (Upstash). Охватывает три функции: получение документов библиотеки в терминале, управление навыками (install/search/suggest/generate), настройку Context7 для Claude Code.

Ключевые команды:
- `npx ctx7 skills suggest` — автоматически определяет параметры проекта, рекомендует соответствующие навыки
- `npx ctx7 skills install owner/repo` — установить из любого репозитория GitHub.
- `npx ctx7 setup --claude` — мастер настройки режима MCP или CLI+Skills.
- `npx ctx7 library [name]` / `ctx7 docs [id] [query]` — поиск документов без браузера
