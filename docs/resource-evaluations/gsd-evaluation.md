## 📄 Резюме содержания

- **Система мета-подсказок** для Claude Code, решающая "контекстную гниль" (ухудшение качества с накоплением контекста)
- **Рабочий процесс, состоящий из 6 этапов**: Инициализация → Обсуждение → Планирование → Выполнение → Проверка → Завершение.
- **Многоагентная оркестровка**: специальные параллельные агенты (исследователи, планировщики, исполнители, отладчики)
- **Структуры документов**: PROJECT.md, REQUIREMENTS.md, ROADMAP.md, STATE.md, PLAN.md
- **Новые контексты исполнителя**: выполнение плана в изолированном контексте из 200 тыс. токенов
- **Быстрый режим**: ускоренное выполнение специальных операций без полного планирования.
