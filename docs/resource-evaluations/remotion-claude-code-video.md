### Упомянутые технологии

- **Remotion**: Framework React для создания программного обеспечения видео (JSX → кадры → FFmpeg → MP4)

- **MCP Server**: Remotion предлагает сервер MCP для прямого доступа к LLM в документации
- **Документация**: Удаление документов с функцией «Копировать как Markdown»
