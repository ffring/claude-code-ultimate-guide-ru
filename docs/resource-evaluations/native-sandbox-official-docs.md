## Ключевые моменты извлечены

1. **OS Примитивы**:
   - macOS: Ремень безопасности (встроенный)
   - Linux/WSL2: bubblewrap + socat (необходимо установить)
   - WSL1: не поддерживается (функции ядра недоступны)

2. **Модель изоляции**:
   - Файловая система: чтение всего (настраивается), запись только в рабочую область.
   - Сеть: прокси SOCKS5 с доменом allowlist/denylist.

3. **Режимы песочницы**:
   - Автоматическое разрешение: команды Bash автоматически одобряются, если они находятся в песочнице.
   - Обычные разрешения: все команды требуют одобрения.

4. **Escape Hatch**: параметр `dangerouslyDisableSandbox` для несовместимых инструментов (докер, сторож)

5. **Ограничения безопасности**:
   - Фронтирование домена (обход CDN)
   - Повышение привилегий сокетов Unix
   - Повышение разрешений файловой системы
   - Слабость вложенной песочницы (Linux)

6. **Открытый исходный код**: `@anthropic-ai/sandbox-runtime` npm-пакет

7. **Поддержка платформы**: macOS ✅ | Linux ✅ | WSL2 ✅ | WSL1 ❌ | Windows (планируется)

## Риски НЕ интеграции

1. **Инциденты безопасности** (Высокий)
   - Пользователи запускают `--dangerously-skip-permissions` в встроенной песочнице, полагая, что они полностью защищены.
   - Обход доменного фронта → утечка учетных данных
   - Повышение привилегий сокетов Unix → компрометация системы
   - **Оценочное влияние**: более 80 % пользователей не понимают компромиссы Docker microVM и Native на уровне процессов.

2. **Принятие трения** (Высокое)
   - Пользователи не решаются использовать автономный режим (необходимый для повышения производительности), поскольку не понимают гарантий песочницы.
   - **Оценочное влияние**: более 50% потенциальных автономных рабочих процессов не внедрены

3. **Ошибки конфигурации** (средний)
   - Белый список пользователей `*.amazonaws.com` (включает созданные пользователем корзины S3) → ложное чувство безопасности
   - Пользователи разрешают запись в каталоги `$PATH` → возможно повышение привилегий.
   - **Оценочное влияние**: более 30% пользовательских конфигураций песочницы имеют проблемы с безопасностью.

4. **Несовместимость платформы** (средний)
   - Пользователи Windows/WSL1 пытаются использовать встроенную песочницу (не поддерживается) → разочарование, отчеты об ошибках
   - **Оценочное влияние**: более 20% пользователей Windows в замешательстве

5. **Пропущенные вклады сообщества** (Низкий)
   - Среда выполнения с открытым исходным кодом (`@anthropic-ai/sandbox-runtime`) не упоминается → сообщество не может audit/contribute
   - **Оценочное воздействие**: 0 проверок безопасности сообщества, 0 вкладов

6. **Доверие руководства** (средний)
   - Официальный, последний, критически важный для безопасности документ не интегрируется быстро → руководство по сигналам не соответствует важным функциям
   - **Оценочное воздействие**: подрыв доверия среди пользователей, заботящихся о безопасности.
