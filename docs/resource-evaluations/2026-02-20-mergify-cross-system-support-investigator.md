## Краткое содержание

Компания Mergify создала систему расследования обращений в службу поддержки, объединив Claude Code в качестве оркестратора с 5 пользовательскими серверами MCP (Datadog, Sentry, PostgreSQL, Linear, GitHub). Система выполняет параллельные запросы во всех системах и создает структурированный отчет для проверки человеком.

Ключевые результаты (самооценки): время сортировки сократилось с ~15 минут → <5 минут; Точность первого прохода 75%.
