## 1. Краткое содержание

Дистанционное управление позволяет продолжить локальный сеанс Claude Code с телефона, планшета или веб-браузера (мобильное приложение claude.ai/code или Claude на iOS/Android).

**Два режима активации:**
- `claude remote-control` — новая подкоманда CLI
- `/remote-control` или `/rc` — команда косой черты из активного сеанса.

**Ключевая архитектура:**
- Исполнение 100% локальное — всю работу выполняет терминал.
- Интерфейс Mobile/web — это удаленное окно в локальный сеанс.
- HTTPS только исходящий трафик, ноль входящих портов, кратковременные учетные данные с ограниченной областью действия

**Доступность:** Research Preview для планов Pro и Max. НЕдоступно для ключей Team, Enterprise или API.

**Особенности: QR-код** + URL-адрес сеанса для быстрого подключения, автоматическое включение через `/config`, команда `/mobile` для ссылок для загрузки приложений.

**Ограничения:** 1 удаленный сеанс за раз, терминал должен оставаться открытым, тайм-аут сети ~10 минут.

## 5. Задача (техническая экспертиза)

**Оценка изменена: 4/5** (снижен с 5)

**Причины понижения версии:**
- Предварительный просмотр исследования, а не GA → риск документирования изменяющегося контента
- Ограниченная область действия Pro/Max → большинство профессиональных пользователей (Team/Enterprise) не имеют доступа
- Официальная документация Anthropic уже доступна → руководство не является первым источником для ранних пользователей.

**Очки, пропущенные при первоначальной оценке:**
- Различие между рабочим процессом CLI (`claude remote-control` с флагами `--verbose`, `--sandbox`) и командой косой черты (`/rc` без флагов)
- Влияние на корпоративные среды с брандмауэром proxy/VPN/restrictive
- Команда `/mobile` для загрузки приложения Claude (упоминается в документе, а не в нашем руководстве)
- Сравнение с существующими альтернативами (SSH + мобильный терминал, tmux, удаленный VS Code)

**Неинтеграционные риски:**
- Краткосрочная перспектива (1–2 недели): низкая, ранние пользователи читают документацию Anthropic.
- Среднесрочная перспектива (1 месяц): умеренная, если функция станет общедоступной.
- Долгосрочная перспектива: высокая, если дистанционное управление станет стандартным режимом взаимодействия.

**Основной риск: чрезмерное документирование нестабильной предварительной версии** → решение: документ с четким отказом от ответственности «Research Preview».

1. Ограничение команд **Slash в удаленном** (`/new`, `/compact` обрабатываются как текст) — недокументировано
2. Многосессионный шаблон **tmux** для обхода ограничения на один сеанс
3. **Постоянная серверная архитектура**: tmux + удаленная виртуальная машина + удаленное управление

5. **Сравнение альтернатив**: Happy.engineering, OpenClaw, SSH-туннели, настройки VPS
