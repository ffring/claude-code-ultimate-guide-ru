## Стратегия позиционирования

### Ценностное предложение

Awesome-Claude-Skills служит **специализированная таксономия** для пользователей, которые хотят:
- Фильтрация только по навыкам (не смешивается с agents/commands/hooks)
- 12-категорийная организация для открытий
- Коллекция, созданная сообществом и активно поддерживаемая

### Отличие от существующих ресурсов

| Ресурс | Область применения | Лучшее для |
|----------|-------|----------|
| **awesome-claude-code** | Полная экосистема | Открытие всех типов ресурсов |
| **awesome-claude-skills (BehiSecc)** | Skills-only | Поиск навыков по категориям |
| **awesome-claude-skills (ComposioHQ)** | Общие навыки | Альтернативное лечение |
| **skills.sh торговая площадка** | Installation-focused | Установка через CLI |
| **Примеры полного руководства/** | Образовательный | Обучение с помощью документации |

### Риски неинтеграции

**Риск от низкого до умеренного**:
- Частичное перекрытие с существующими ресурсами (~30-40%)
- Существуют альтернативные пути обнаружения (awesome-claude-code, skills.sh).
- Пробел Scientific/research существует, но BehiSecc не полностью его устраняет (только 4 навыка)

**Цена возможности**:
- Отсутствие специализированного подхода к таксономии (12 категорий)
- Не признание активности сообщества (5,5 тысяч звезд за 3 месяца)
- Потенциальная путаница пользователей (существуют 2 навыка Awesome-Claude)

## Отложенные действия

### Оцените K-dense-AI отдельно

**Rationale**: Заявление «125+ научных навыков» относится к внешнему репозиторию. Если аудитория research/science является приоритетом, K-Dense-AI должен получить собственную оценку.

**Предлагаемые критерии оценки**:
- Качество навыков (документация, тесты, примеры)
- Статус обслуживания (последнее обновление, количество проблем)
- Перекрытие с существующими научными инструментами
- Возможность интеграции (зависимости, предпосылки)

### Раздел Research/science (в будущем)

Если K-Dense-AI набрал 4/5 или выше, рассмотрите:
- `guide/workflows/research-science.md` (500-1000 строк)
- Задокументированы 10–15 лучших научных навыков
- Варианты использования: биоинформатика, машинное обучение, анализ данных.
- Интеграция MCP (Context7 для научных документов, Sequential для рабочих процессов)

1. **Проверьте количество навыков вручную** — описания репозитория могут вводить в заблуждение (125+ против 62)
