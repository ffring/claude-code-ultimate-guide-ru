## 1. Конституция Claude – непреодолимая редакция

**Дата:** 21 января 2026 г.
**Type :** Объявление/Управляющий документ

### Основные моменты

- Публикация новой конституции для Claude, переименованная в правительственный документ для руководства по модели поведения, проходящей через все будущие версии

- Документ опубликован в свободном доступе (лицензия CC0 1.0), предназначен для использования в будущих моделях и в течение нескольких дней.
- Разделы: «Полезность», «Этика Claude», «Руководство Anthropic», «Быть ​​в целом безопасным», «Природа Claude» (включая размышления о потенциальной совести Claude).

## 2. Claude Code – Mises à jour produit

**Даты:** 9–22 января 2026 г.
**Type :** Выпуск продукта
**Доступные версии:** 2.1.9 — 2.1.17.

### Особенности стандартной версии

**Версия 2.1.17 (22 января)**
- Исправление сбоев процессоров без поддержки AVX

**Версия 2.1.16 (22 января)**
- Система управления движениями с учетом зависимостей
- Нативные плагины Gestion VSCode
- Реприза удаленных сессий OAuth

**Версия 2.1.15 (21 января)**
- Улучшение производительности пользовательского интерфейса с помощью React Compiler
- Уведомления об амортизации при установке npm

**Версия 2.1.14 (20 января)**
- Автозаполнение bash historique с синтаксисом bang
- Поиск в плагинах
- Проверьте дополнительные версии git spécifiques

**Версия 2.1.9 (16 января)**
- Автоматическая настройка MCP с синтаксисом auto:N
- Поддержка хуков PreToolUse
- Переменная среды CLAUDE_SESSION_ID

**Версии 2.1.6-2.1.7 (13-14 января)**
- Улучшенная конфигурация Recherche
- Статистика Фильтры Статистика 7/30 Jours
- URL-адрес сеанса атрибутов для фиксации и PR

### Критические изменения

- **Устарение npm install** → Рекомендованный переход на версии `claude install` или собственные установки
- **URL-адреса миграции OAuth** → console.anthropic.com devient Platform.claude.com
- **Подавление @-упоминания MCP** → Утилизатор `/mcp enable <name>` по месту

### Улучшения безопасности/стабилизации

- Исправление уязвимости, допускающей использование подстановочных знаков в правилах командной оболочки
- Исправление ошибок в памяти и накопление WASM за длинные сеансы.
- Риск внедрения команды исправления при разборе bash
- Тайм-аут увеличения хуков: 60 с → 10 минут.

- https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- https://www.gradually.ai/en/changelogs/claude-code/
- https://releasebot.io/updates/anthropic/claude-code
