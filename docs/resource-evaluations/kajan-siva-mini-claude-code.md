## 1. Краткое содержание

Полная статья (около 9 минут чтения), описывающая создание минимального Claude Code-подобного агента в четыре этапа: базовый вызов API, контекстное окно (история сообщений), вызов инструмента и агентный цикл, связывающий их вместе. JavaScript/Node.js, Anthropic API (Claude Sonnet 5). Для каждого шага предоставляется код, включая схему инструмента `searchCode` и упрощенный цикл агента. Охватывает связывание `stop_reason`, `tool_use_id` и помечает риск внедрения подсказки, когда выходные данные инструмента повторно входят в контекст без фильтрации.

**Key утверждает**: агент = LLM + контекст + инструменты + цикл + условие остановки; вызов инструмента — это запрос, а не прямое выполнение, приложение решает, запускать ли его; цикл повторяется до тех пор, пока `stop_reason` не станет `tool_use`.

### Обоснование

**Очки для**: содержание техники (для пост-продвижения), исполняемый код, репозиторий GitHub, возможность быстрого внедрения, что представляет собой множество эквивалентов учебных пособий на английском языке.

**Очки**:
- **Aucun Gap Comblé** : `guide/core/architecture.md` §1 «The Master Loop» (линия 109) — документ, посвященный механизму (boucle, `tool_use`, `stop_reason`), официальный источник Tier 1 Anthropic. Статья не является заменой педагогической деятельности, поскольку руководство объясняет, что есть источник плюс солид.
- **Согласно правилам языка репозитория**: содержание на 100% французском языке, кроме того, что репозиторий интегрирован на английском языке (запомните, закрытый правила). Французский источник не может быть указан как ссылка в руководстве без перевода, то есть то, что не имеет смысла для обучения, не является интересом - это оправдание того, что есть.
- **Неоригинальный педагогический образец**: формула «агент = LLM + контекст + инструменты + букле + условие задержания» и демонстрация в 4-х этапах круассанов - это жанр, установленный в 2025 году, популяризированный Торстеном Боллом (экипировка). Amp), «Как создать агента» (https://ampcode.com/blog/how-to-build-an-agent), большая ссылка на жанр. Recherche Web (05.08.2026) — это исправление из 6 эквивалентных учебных пособий, опубликованных в мае и июле 2026 года в соответствии со структурой мема.
- **Auteur был оценен на 2/5**: ранее опубликованное в LinkedIn сообщение автора (команда `/insights`, оценка от 06 февраля 2026 г., до [kajan-siva-insights-command.md](./kajan-siva-insights-command.md)) уже доступно Техника без содержания, которую можно использовать. Celui-ci - это сплошная сеть, но больше всего подтверждается шаблон: доступный контент, как источник, плюс плотный текст.

## 4. Интеграционное решение

### Решение: **НЕ ИНТЕГРИРОВАТЬ** ❌

**Rationale**:
1. Комбинация с нулевым разрывом, механизм - это документация с источником плюс твердость.
2. Французский контент несовместим с правилами языка репо (уникальный английский язык).
3. Жанр «создать собственный агент для понимания» заслуживает внимания в `guide/roles/learning-with-ai.md` § Внешние ресурсы, но больше с каноническим англоязычным источником жанра, который является целым.

### Альтернативное действие

В разделе **Торстен Болл, «Как создать агента»** (https://ampcode.com/blog/how-to-build-an-agent) на `guide/roles/learning-with-ai.md` § Внешние ресурсы, в месте этой статьи: педагогический жанр (comprendre l'agent Loop en le Construisant), на английском языке, ссылка на плюс цитату жанра.
