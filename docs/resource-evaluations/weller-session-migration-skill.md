## Что он делает

**Проблема решена**: Собственная команда `--resume` ограничена текущим рабочим каталогом. Когда вы перемещаете проект или хотите перенести сеанс в новую папку, сеанс становится недоступным.

**Решение предоставлено**:
1. **Глобальный поиск**: находит сеансы во всех проектах с фильтрацией по ключевым словам.
2. **Интерактивный выбор**: фильтрует результаты, исключает текущие сеансы каталога.
3. **Автоматическая миграция**: копирует каталог `.jsonl` + субагенты, генерирует новый UUID
4. **Команда возобновления**: предоставляет `claude --resume <new-id>` для немедленного использования.

**Техническая реализация**:
- Использует ripgrep для повышения производительности
- Поддержка фильтрации (`cleanupPeriodDays: 90` для больших историй)
- Bash-скрипты: `search.sh` + `migrate.sh`.
- Синтаксис команды: `/claude-migrate-session <source> <target>`
