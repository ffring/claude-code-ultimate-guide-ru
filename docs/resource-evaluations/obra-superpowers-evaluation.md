## 1. Краткое содержание

Superpowers — это комплексная методология разработки программного обеспечения, упакованная в виде плагина Claude Code — набора компонуемых навыков, который обеспечивает структурированные рабочие процессы от идеи до объединенной ветки. Навыки активируются автоматически в зависимости от контекста (ручной вызов не требуется).

**Содержимое ключа**:
- **Ворота первого мозгового штурма**: Перед написанием кода агент извлекает спецификацию посредством сократовских вопросов и представляет ее в проверяемых разделах.
- **Планирование внедрения**: разбивает работу на 2–5-минутные задачи с точными путями к файлам, полными блоками кода и этапами проверки.
- **Разработка на основе субагентов**: отправляет новый субагент для каждой задачи с двухэтапной проверкой (соответствие спецификациям, затем качество кода); рассчитан на многочасовую автономную работу
- **Обязательный TDD**: КРАСНЫЙ → ЗЕЛЕНЫЙ → РЕФАКТОР включен; код, написанный до того, как тест будет удален и переделан
- **Полный жизненный цикл ветки**: `using-git-worktrees` + `finishing-a-development-branch` охватывают всю дугу от создания рабочего пространства до решения merge/PR

**Философия**: Разработка через тестирование не подлежит обсуждению, систематическая, а не разовая, снижение сложности как основная цель, доказательства важнее утверждений.

## 5. Вызов (агент технического писателя)

**Основные проблемы, поднятые и решенные**:

**Задание 1: «Проверьте количество звезд в 95 тысяч, прежде чем назначать 5/5»**
→ Проверено через GitHub API. 95 299 звезд, 7 546 вилок, созданы в октябре 2025 года. Это ворота для подсчета очков — ворота пройдены. Счет стоит на 5/5..

**Задание 2: «Руководство уже описывает каждый компонент отдельно (TDD, спецификации в первую очередь, рабочие деревья). Действительно ли сверхспособности суммируются?»**
→ Да: значение *упаковка* и *автоматический запуск*. Пользователи, устанавливающие один плагин, получают структурированную методологию без необходимости вручную составлять пять страниц рабочего процесса. В руководстве нет ни одной записи «установите это, чтобы автоматически внедрять хорошие привычки в рабочем процессе». В этом и есть пробел.

**Задача 3: «Является ли third-party-tools.md + экосистема плагинов подходящей точкой интеграции?»**
→ Частично согласен с вызовом. Лучший подход: (a) обновить строку obra в строке 8104 в ultimate-guide.md, чтобы указать на полный пакет Superpowers со ссылкой, (b) добавить специальную запись Notable Workflow Suites в раздел «Экосистема плагинов» third-party-tools.md рядом с gstack, (c) ссылку на tdd-with-claude.md и spec-first.md как «методологию сообщества, которая объединяет этот рабочий процесс».

**Задача 4: «А как насчет рабочего процесса субагента — действительно ли он отличается от собственного инструмента задач?»**
→ `subagent-driven-development` от Superpowers обеспечивает двухэтапную проверку (соответствие спецификациям, а затем качество кода), которую встроенный инструмент Task не обеспечивает «из коробки». Стоит отметить и настоящую дифференциацию рабочего процесса.

**Корректировка очков**: Вызов подтвержден 5/5 после проверки количества звезд.
