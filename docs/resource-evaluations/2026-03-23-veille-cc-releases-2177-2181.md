## Детали интеграции

### Хук `StopFailure` (v2.1.78)

Добавлена ​​в таблицу «Типы событий» (ultimate-guide.md). Срабатывает, когда тур завершается из-за ошибки API (ограничение скорости, сбой аутентификации). Вариант использования: оповещение о наблюдаемом исчерпании квоты.

### Поле строки состояния `rate_limits` (v2.1.80)

Добавлен в раздел «Пользовательская настройка строки состояния». Чемпион JSON раскрывает использование Claude.ai (5h и 7j) с `used_percentage` и `resets_at`. Разрешите отслеживать токены без выхода на панель управления.

### `${CLAUDE_PLUGIN_DATA}` (v2.1.78)

Добавлено в выноске в разделе «Команды плагина». Env var pointant vers un repertoire de stockage Permanent Preservé lors des Mises à Jour de Plugin. Дополнительная уникальность для `/plugin uninstall` с подтверждением.

### Режим `--bare` (v2.1.81)

Добавляемся после примера GitHub Actions `claude -p`. Деактивированные перехватчики, LSP, синхронизация плагинов, сканирование навыков. Запросите `ANTHROPIC_API_KEY` (pas d'OAuth). Создавайте рабочие места CI, определяемые тем, что локальная конфигурация разработки загрязняет среду CI.

### Настройки `sandbox.filesystem` (v2.1.77/2.1.78)

Прочтите раздел «Настройка ограничений файловой системы» в sandbox-native.md. Документированные три чемпиона: `allowWrite` (расширить запись за пределы CWD), `denyRead` (блокировать пути чтения), `allowRead` (повторно разрешить чтение в регионе, запрещенном на чтение). Исправление неверного подтверждения «Ограничения файловой системы настраиваются только с помощью правил разрешений» — настройки sandbox.filesystem существуют и есть исправления в версии 2.1.78.
