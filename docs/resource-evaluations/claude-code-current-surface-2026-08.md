# Claude Code текущая поверхность: использование компьютера, подсказки плагинов, шлюз приложений и артефакты.

## Вердикт

Текущая официальная документация Claude Code подтверждает четыре направления продукта, которые влияют на приоритеты обучения в руководстве: использование компьютера из macOS CLI, подсказки по рекомендациям плагинов, шлюз приложений Claude и публикация артефактов. В этой оценке сообщается о задокументированном поведении, прочитанном 31 августа 2026 г. Он не претендует на проверку локальной среды выполнения, права на план помимо указанной документации или совместимость за пределами источников, перечисленных ниже.

## Текущие последствия продукта

### Использование компьютера

Использование компьютера отличается от Bash, автоматизации браузера и MCP. В официальном порядке предпочтение отдается серверу MCP, Bash или Claude в Chrome перед управлением экраном. Его работа на реальном рабочем столе создает отдельную границу доверия: одобрение каждого приложения и остановка `Esc` снижают риск, но они не помещают в изолированную среду одобренное приложение или его видимые данные. Специальная страница руководства — [Компьютерное использование в Claude Code](../../guide/core/computer-use.md).

### Подсказки по плагинам

Маркер `<claude-code-hint />` представляет собой однострочный протокол вывода CLI, а не приглашение модели. Claude Code удаляет его перед вводом модели, принимает только подходящий целевой плагин из официального магазина и запрашивает у пользователя перед установкой. Протокол идентифицирует отправляющую команду в командной строке, но не документирует подтверждение личности издателя между этой командой и плагином. Специальная страница руководства — [Plugin Distribution andрекомендации](../../guide/ecosystem/plugin-distribution.md).

### Claude шлюз приложений

Шлюз приложений Claude — это самостоятельная служба, включенная в двоичный файл `claude`. В документации описывается корпоративный единый вход, групповая политика IdP, обработка учетных данных восходящего потока, телеметрия OTLP и маршрутизация восходящего потока. Он должен использовать частный адрес, поскольку он может доставлять настройки клиента. Вход в поток устройств не имеет пути к токену службы для автоматического CI. Раздел шлюза в [API Gateway for Enterprise Claude Code](../../guide/ops/api-gateway.md) документирует подтвержденную область и границу проверки.

### Публикация артефактов

Публикация артефакта — **CONFIRMED**, а не `UNKNOWN`. На текущей официальной странице артефакта говорится, что Claude Code может публиковать результаты сеанса в виде активной страницы на claude.ai; новый артефакт изначально является частным, и общий доступ может осуществляться внутри организации или через общедоступную ссылку в зависимости от плана и настроенных элементов управления. Публикация зависит от режима разрешений сеанса, и артефакт, поддерживаемый соединителем, не может быть общедоступным. Эта оценка не оценивает пригодность конфиденциальных данных, сохранение в конкретной организации или локальную доступность. Для этих вопросов необходимы применимый план, настройки и доказательства управления данными.
