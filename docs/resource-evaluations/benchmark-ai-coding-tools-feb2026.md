## Резюме содержания

- **5 сравниваемых возможностей**: Claude Code (CLI-first + субагенты + перехватчики), Cursor (IDE fork VS Code, Tab, Composer), Windsurf (каскадные мультиагенты, Wave 13), Zed (Rust natif, Ollama local), Copilot Workspace (GitHub-центр, выпуск → PR)
- **Последние новости** : Sonnet 4.6 версия "15 февраля 2026 года" с контекстом 1M (бета), модель по умолчанию Pro/Free; расширение VS Code GA ; nouveaux docs Hooks (26 февраля)
- **Quotas Claude Code** : Pro ≈ 10-40 prompts/5h, Макс 5x = 50-200/5h, Макс 20x = 200-800/5h, ограничение ~50 фенетров/месяцев
- **Différenciation Claude Code** : точки фортов = CLI + Git + субагенты + контрольные точки + CLAUDE.md/init ; баллы faibles = встроенные действия по автозаполнению, квоты Pro serrés sur интенсивные сеансы
- **6 документальных рекомендаций**: (1) кадровые модели/контекст, (2) разработчики квот страниц, (3) агент стека, (4) сравнение IDE, (5) педагогика CLAUDE.md, (6) потоки кода VS

## Рекомендации по интеграции

### Приложение № 1 — Краткие квоты по плану (PRIORITÉ HAUTE)

- **Пробел в**: различия существуют в руководстве, которое больше всего похоже на `ultimate-guide.md` и `guide/core/known-issues.md`. Синтетические таблицы «Pro / Max 5x / Max 20x» с интервалами в 5 часов.
- **Où** : `guide/ultimate-guide.md` секция pricing/limits (~ линия 1951-2013) + потенциал `guide/core/architecture.md`
- **Comment** : уникальная таблица «План → подсказки Claude Code/5h → Sonnet heures/semaine → cap mensuel» с примечанием к субагентам и контексту 1M для мультипликаторного объединения.
- **Предупреждение**: Изменения эталонных значений (10-40 / 50-200 / 200-800) относятся к фуршетам сообщества, согласно официальным соглашениям об уровне обслуживания Anthropic. Источник от GitHub выпускает anthropics/claude-code или официальную предварительную документацию.

### Приложение №2 — Раздел «Виндсерфинг + Сравнение упражнений» (PRIORITÉ MOYENNE)

- **Gap réel**: Таблица сравнения строк 885 с кодом Copilot/Cursor/Claude. Windsurf et Zed отсутствует в сравнении с основным круассаном.
- **Où** : Раздел Migration/Comparison (~ линия 881), сохранить существующую таблицу.
- **Комментарий**: Дополнительные 2 колонны (Виндсерфинг + Зед) + линия «Рабочее пространство второго пилота» с позиционным кортом (50–100 слов за каждую минуту). Используйте базовый эталонный тест для проверки официальной документации.
- **Внимание**: Windsurf Wave 13 + SWE-1.5 и цена токена Zed (+10%) в соответствии с конкретными утверждениями для проверки windsurf.com/changelog и zed.dev/blog перед интеграцией.

### Я не интегрирован

- Рекомендации 3, 5, 6 (агент стека, CLAUDE.md, потоки кода VS): ожидание в руководстве, интеграция = дублирование без дополнительных изменений.
