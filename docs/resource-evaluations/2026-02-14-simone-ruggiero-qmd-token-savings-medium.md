## Краткое содержание

Симоне Руджеро (1 февраля 2026 г.) продвигает **qmd** (github.com/tobi/qmd), локальный индексатор документов, представленный как сервер MCP для Claude Code. Основное утверждение: «Экономия токенов 95%» за счет замены Glob/Grep/Read на индексированный семантический поиск. Инструмент индексирует кодовые базы локально и передает результаты через MCP, позволяя Claude Code запрашивать индекс вместо чтения необработанных файлов.

Заявление **Key**: замените собственные файловые операции Claude Code индексированным поиском, чтобы сократить потребление токенов примерно на 95%.

**Источник**: [Medium Article](https://medium.com/@simone.ruggiero92) (точный URL-адрес по состоянию на февраль 2026 г.)

## Краткое содержание

**Основные моменты**:
- **qmd** — локальный индексатор документов, созданный Тоби Лутке (генеральным директором Shopify)
- Предоставляет сервер Model Context Protocol (MCP) для Claude Code.
- Заявляет о 95 % экономии токенов при операциях по исследованию файлов.
- Математический сценарий токена: файл из 500 строк = ~ 10 000 токенов через Read → qmd возвращает ~ 500 токенов (summary/chunks)
- Позиционирует qmd как замену рабочего процесса Glob + Grep + Read.
- Настройка: `qmd index .`, затем настройте как сервер MCP в настройках Claude Code.

### Фактические исправления

**Основная проблема**: Заявление о 95% предполагает наихудший базовый уровень (чтение целых файлов в необработанном виде) и сравнивается с индексированным поиском в лучшем случае. Реальная экономия зависит от:
1. Будет ли Claude Code в любом случае читать весь файл (часто он читает определенные диапазоны строк)
2. Возвращает ли семантический индекс правильные фрагменты (точность имеет значение)
3. Требуется ли запрос точного соответствия (где Grep лучше)

**Отсутствует контекст**: в статье не упоминается, что Claude Code уже оптимизирует использование токенов посредством:
- Чтение линейного диапазона (смещение + предельные параметры)
- Целенаправленный поиск Grep (возвращает только совпадающие строки)
- Шаблон reference.yaml (машиночитаемый индекс, ~2 тыс. токенов)
