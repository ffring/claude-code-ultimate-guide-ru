Ничего не устанавливалось и не запускалось, поэтому каждое приведенное ниже поведение — это то, что говорится в коде или документации, а не наблюдаемый результат.

## Что делает каждый инструмент

**diffo (4/5).** Агент записывает свое собственное обоснование через CLI (`diffo comment`, `diffo layers`, `diffo reply`) и публикует упорядоченный список слоев (заголовок, резюме, файлы, решения). Комментарии привязываются к идентификатору фрагмента, адресуемому содержимым (усеченный SHA-256 пути, измененные строки и вхождение), возвращаясь к фрагменту, охватывающему ту же строку, файл, а затем все изменение. `diffo poll` возвращает агенту темы рецензента, каждое из которых содержит изменение или вопрос, с различным контрактом на ответ. Только GitHub через `gh`. Анонимная телеметрия PostHog включена по умолчанию. Хранилище представляет собой одну базу данных SQLite с помощью экспериментальной версии Node `node:sqlite`. Это единственный инструмент, который замыкает цикл с помощью печатной обратной связи.

**glassbox (3/5).** Агент записывает примечания с помощью `glassbox note add`, следуя инструкциям `glassbox note instructions`, которые вводит сеанс оркестрации; никакой хук не заставляет его. Примечания имеют тип (обоснование, доказательство, предположение, рассматриваемая альтернатива, риск и другие) и хранятся как SARIF 2.1.0, по одному файлу на каждый исходный файл под `.pr-notes/`, с версией кода. Привязка осуществляется по строкам: заметка повторно привязывается путем сопоставления первой строки сохраненного фрагмента в пределах 50 строк. Записанный хэш отпечатка пальца не используется для повторной привязки. Примечания отображаются под привязанной линией. Человеческие аннотации экспортируются в файл обзора, который читает агент. В `src/` интеграции forge не обнаружено; `plugins/` и `scripts/` не были прочитаны.

**hunk (3/5).** Терминальный просмотрщик различий. Агент комментирует в прямом эфире (`hunk session comment add`) или через боковую панель JSON с `oldRange`, `newRange`, `summary`, `rationale`, `confidence`. Привязки разрешительно разрешаются для текущего фрагмента, поэтому заметка никогда не теряется; отслеживания смещения строки нет. Агент может читать человеческие записи и отвечать, но не редактировать их. Читает различия GitHub; ничего не отправляет в кузницу. Расширения, передаваемые по флагу или пользовательской конфигурации, запускаются без запроса доверия.

**drift (3/5).** Пользовательский интерфейс терминала Rust, который вообще не содержит объяснений ИИ; текст рядом с различиями - это обсуждение подделки. Это единственный прочитанный инструмент, поддерживающий GitLab через `glab api`: он перестраивает обсуждение `position` из `diff_refs` мерж-реквеста (добавлена ​​строка `new_line`, удалена строка `old_line`, контекст и то, и другое) и помечает обсуждение, `position.head_sha` которого отличается от текущей главы, как устаревшее, а не удаляет его. Он отправляет выбранный диапазон кода плюс инструкцию агенту, работающему в другой панели tmux, herdr или cmux.

**ai-pr-review (2/5).** Модель пишет структурированное пошаговое руководство постфактум, на основе различий, коммитов, описания и комментариев; рассуждения агента-автора ему недоступны. Код проверяет выходные данные: диапазоны строк по различиям, цитаты `path:line` по дереву в головном коммите, до 3 раундов восстановления. При чтении SHA проверка советов по проверке запускала Codex в одноразовом рабочем дереве с `workspace-write`, `network_access=true` и политикой утверждения `never` в коде запроса на включение, поэтому на компьютере проверяющего мог выполняться ненадежный код.

**guidedreview (2/5).** Из README: расширение Chrome для запросов на извлечение GitHub и локальный CLI, который группирует связанные фрагменты в упорядоченные блоки обзора с короткими комментариями LLM по запросу. Комментарии прикрепляются к реальным строкам различий. «Создать подсказку» создает подсказку для агента кодирования на основе заметок рецензента и копирует ее; инструмент не отправляет его.

## Что общего у шестерых

- Ни один из пяти прочитанных кодов не помещает объяснение агента в столбец рядом с diff: glassbox и hunk вставляют его под привязанную строку, потоки diffo располагаются под строкой, ai-pr-review вставляет строки аннотаций под код. README руководства Guidereview не уточняет, где находится комментарий.
- В прочитанных версиях был обнаружен только дрейф чтения и записи обсуждений мерж-реквестов GitLab; стороннее расширение `hunk-glab` для мерж-реквестов GitLab появилось позже и не было прочитано. diffo, ai-pr-review иguidereview доступны только для GitHub; Стеклянный ящик не имеет ковочного слоя.
- Только diffo печатает отзывы рецензента, поэтому агент может отличить вопрос от запрошенного изменения.
- Ни один из них не сообщает об измерении качества проверки, времени или обнаруженных дефектов.
