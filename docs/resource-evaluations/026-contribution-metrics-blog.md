## Краткое содержание

Anthropic объявляет о выпуске «Метрики вклада» для Claude Code — интегрированной с GitHub аналитической панели в публичной бета-версии для планов Team и Enterprise. Пост включает обновленные внутренние данные о производительности:

- **+67% объединенных PR** на инженера в день в Anthropic
- **70–90% кода** написано с помощью Claude Code всеми командами.
- Панель мониторинга отслеживает PR и строки кода, зафиксированные with/without Claude Code атрибуция
- Консервативное измерение: учитывается только участие Claude Code с высокой степенью достоверности.
- Позиционируется как дополнение к показателям DORA и скорости спринта, а не как замена.

## Интеграционное решение

**Обоснование оценки (4/5):**
- Официальный сторонний источник с более строгими показателями, чем существующие руководства.
- Заменяет август 2025 г., +50% по самооценке +67% на основе PR.
- Новая функция продукта (панель мониторинга), которую стоит задокументировать
- Оценка не 5/5, потому что: методология расплывчата, только внутренние данные, объем Team/Enterprise ограничивает аудиторию.

**Challenge (агент технического писателя):**
- Рекомендуемое увеличение балла с 3 до 4 (принято)
- Выявлены 3 «слепых пятна»: сравнение методологий, «консервативное» рассмотрение заявлений, конкурентный контекст.
- Исправленный план интеграции: отдельный подраздел (не объединен с исследованием от августа 2025 г.)

1. **Новый подраздел** в `guide/ultimate-guide.md` после внутреннего исследования Anthropic (август 2025 г.) — отдельный раздел с собственным источником, методологическими примечаниями и предостережениями.
