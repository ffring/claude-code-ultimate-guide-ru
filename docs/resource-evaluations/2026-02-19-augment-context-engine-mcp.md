# Оценка: код расширения — механизм контекста MCP

**Дата**: 19 февраля 2026 г.
**Evaluator**: Claude Sonnet 4.6
**Тип источника**: страница продукта (коммерческий инструмент)
**URL**: https://www.augmentcode.com/product/context-engine-mcp
**Вердикт**: АКТУАЛЬНО (Оценка: 3/5)

## Краткое содержание

6 февраля 2026 года компания Augment Code запустила свой Context Engine в качестве автономного сервера MCP. Он обеспечивает семантический поиск кода для любого MCP-совместимого агента кодирования (Claude Code, Cursor, Zed, Kilo Code, Roo Code, GitHub Copilot).

**Ключевые моменты**:

1. **Что он делает**: Облачный семантический поиск MCP, который индексирует кодовые базы (в репозиториях, документах, вики) и предоставляет контекст агентам ИИ через протокол MCP. Индексирует до 400 000-500 000 файлов, используя графы семантических зависимостей.

2. **Заявления Benchmark**: Протестировано на 300 пул-запросах Elasticsearch (900 попыток по 3 запроса в каждой). Результаты:
   - Claude Code + Opus 4.5: улучшение качества +80%.
   - Курсор + Opus 4.5: улучшение +71% (полнота +60%, правильность +5x)
   - Курсор + Композитор-1: улучшение +30%.

3. **Efficiency**: требует меньше вызовов инструментов и разговоров; уменьшает использование токенов по сравнению с базовым уровнем без контекстного механизма.

4. **Architecture**: размещение в облаке (не локально), индексирование в реальном времени, соединители с несколькими источниками (GitHub, GitLab, Bitbucket).

5. **Pricing**: на основе кредитов ($20/month Indie = 40 000 кредитов, $50/month Developer = 600 сообщений). 1000 бесплатных запросов в период запуска (до февраля 2026 г., срок действия истек).

### Фактические исправления

**Несоответствие версии модели**: на странице продукта упоминается «Claude Opus 4.6», но в исходном сообщении блога об тестировании производительности (6 февраля 2026 г.) и во всех вторичных источниках упоминается «Claude Opus 4.5». Страница продукта, вероятно, была обновлена, чтобы отразить текущую модель после запуска теста. Это небольшое, но заметное несоответствие — цифра 80% получена в результате тестирования Opus 4.5.

**Заявление о «в 2 раза быстрее».**: это конкретное число появляется в маркетинговом тексте на странице продукта, но не подтверждается напрямую данными тестирования Elasticsearch. Тест измеряет параметры качества (правильность, полнота, лучшие практики, повторное использование кода, документация), а не скорость выполнения задач. Считать непроверенным.

## Анализ пробелов: что уже описано в руководстве

Руководство подробно охватывает пространство поиска семантического кода MCP:

| Аспект | Руководство по охвату | Расширение контекстного механизма |
|--------|---------------|----------------------|
| **Семантический поиск MCP** | grepai (полностью документирован, раздел: Поиск и анализ кода) | Тот же вариант использования, размещение в облаке |
| **Выбор локальной и облачной версии** | grepai = local/private явно задокументировано | Augment = размещение в облаке, локальная опция отсутствует. |
| **Анализ графа вызовов** | grepai: инструменты callers/callees/graph | Не упомянуто в продукте Augment |
| **Установка и конфигурация** | Полное руководство по установке grepai | Установить через конфиг MCP |
| **Эффективность токена** | grepai: ~4 тыс. токенов против 15 тыс. брутфорса | Дополнение: «меньше вызовов инструментов» (неопределенно) |
| **Эталонные данные** | Нет для грепаи | 300 PR, 3 измерения, конкретный % прироста |
| **Поддержка нескольких репозиториев** | Не в грепае | Да — GitHub, GitLab, соединители Bitbucket |
| **Pricing/cost** | grepai = бесплатно, локально | Дополнение = подписка $20+/month |
| **Конфиденциальность** | grepai = полностью локально («никакие данные не покидают ваш компьютер») | Augment = размещение в облаке, данные отправляются в Augment. |

**Обнаружен пробел**: В разделе руководства «Поиск и анализ кода» документируется только grepai (1 сервер). Во введении к разделу не обсуждается компромисс между облаком и локальным поиском для MCP семантического поиска, а также не упоминаются альтернативы commercial/cloud, такие как Augment. Пользователи, которым нужно управляемое решение с несколькими репозиториями и проверенными результатами тестов, не имеют никаких рекомендаций.

**Вторичный разрыв**: эталонный тест Augment представляет собой наиболее конкретные опубликованные данные, сравнивающие предоставление семантического контекста с агентами кодирования AI. В руководстве не приводятся эквивалентные критерии улучшения качества для grepai.

## Сравнительный анализ: Augment vs grepai vs текущее покрытие руководства

| Измерение | Грепай (в руководстве) | Расширение контекстного механизма | Победитель для гида |
|-----------|-------------------|----------------------|-----------------|
| **Конфиденциальность** | Только локально, ноль облаков | Cloud-hosted | Grepai для пользователей, заботящихся о конфиденциальности |
| **Настройка трения** | Высокий (Ollama + nomic-embed-text + grepai init) | Низкий (конфигурация MCP + регистрация учетной записи) | Дополнение для удобства |
| **Multi-repo** | Один проект за раз | Кросс-репо, кросс-вики | Дополнение для крупных организаций |
| **Стоимость** | Бесплатно | $20+/month | Грепай |
| **График вызовов** | Полный (callers/callees/graph) | Не задокументировано | Грепай |
| **Эталонное свидетельство** | Ничего не опубликовано | Улучшение качества на 80 % (самостоятельная публикация) | Дополнить |
| **Независимость** | Открытый исходный код (MIT) | Собственный, привязка к поставщику | Грепай |

**Ключевой вывод**: Это действительно разные инструменты, предназначенные для разных пользователей. Grepai = конфиденциальность, бесплатная, локальная, с графами вызовов. Augment = управляемый, платный, облачный, с несколькими репозиториями, с контрольными данными. В настоящее время в руководстве grepai представлен как единственный вариант в этой категории — это неполная картина.

## Рекомендации по интеграции

Оценка 3/5 — интеграция как документированная альтернатива.

**Рекомендуемое действие**: Добавьте механизм контекста расширения MCP в качестве дополнительной записи в раздел «Поиск и анализ кода `mcp-servers-ecosystem.md`», явно позиционируемый как «альтернатива cloud/managed для grepai».

**Что включить**:
1. Краткое описание инструмента и его дифференциация (облачный, мультирепозиторий, управляемый)
2. Ссылка на тест Elasticsearch (с оговоркой: самостоятельная публикация, Opus 4.5)
3. Предупреждение о конфиденциальности: данные отправляются в облако Augment
4. Примечание о цене: требуется подписка на основе кредита.
5. Ссылка: https://www.augmentcode.com/product/context-engine-mcp

**Чего НЕ следует делать**:
- Не представляйте без оговорок маркетинговые показатели «80%» или «в 2 раза быстрее» как факты.
- Не заменяйте grepai в качестве основной рекомендации (grepai остается лучшим с точки зрения конфиденциальности, затрат и анализа графа вызовов).
- Не расширяйте этот раздел до полного — это альтернативное упоминание, а не основная рекомендация.

**Предлагаемое размещение** в `mcp-servers-ecosystem.md` после существующего раздела grepai:

**Commercial alternative** for users who prefer a managed cloud service over local Ollama setup.

- Pro: No local setup, multi-repo support, managed indexing
- Con: Cloud-hosted (data leaves your machine), paid subscription ($20+/month), no call graph analysis

**Benchmark**: Augment reports 80% quality improvement on a 300-PR Elasticsearch test dataset
(self-published benchmark, Claude Opus 4.5, Feb 2026).

**Setup**: https://app.augmentcode.com/mcp/configuration
**Docs**: https://www.augmentcode.com/product/context-engine-mcp

- Основная аудитория руководства (разработчики, использующие Claude Code CLI), вероятно, предпочитает инструменты local/free управляемым подпискам.
