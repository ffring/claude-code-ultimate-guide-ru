## 📄 Резюме содержания

- **fp.dev** — это инструмент отслеживания проблем, ориентированный на локальный уровень, для Claude Code
- Проблемы, возникающие в `.md` и `/.claude/` — git-committables (отличие от Tasks API)
- Рабочий процесс с помощью пользовательских навыков (`/fp-plan`, `/fp-implement`, `/fp-review`) + CLI (`fp tree`, `fp issue list`, `fp issue show`, `fp review`)
- Результат «контекстной гнили»: разрешает `/clear` сеанс без потери государственного проекта
- Приложение для настольного компьютера Mac (уникальная разработка Apple Silicon) + проверка кода пользовательского интерфейса со встроенной программой просмотра различий
- Нулевая внешняя зависимость, нулевой сервер MCP
- Установка: `curl -fsSL https://setup.fp.dev/install.sh | sh -s && fp setup claude && fp init`

## 🔥 Челлендж (технический писатель)

Аргументы для потомков 2/5:

1. **Redondance** : `/clear` + Задачи API для устранения основной проблемы
2. **Ограничительная пластина**: Apple Silicon только для настольного компьютера = нарушение правил Linux/Windows
3. **Признаки усыновления** : Звезды GitHub, документальная периодичность выпуска → риск отказа
4. **Модная категоризация** : Ne va pas aux Côtés de Gas Town/multiclaude (многоагентная оркестровка) — fp.dev предназначен для отслеживания задач
5. **Un vrai différentiateur** : Проблемы `.md` git-committables → больше не хватает одного для 3/5

**Измененный балл** : 2/5
**Риски неинтеграции**: Ошибки. Руководство по решению проблемы. Значение имеет документирование GAP (отслеживание проблем на основе уценки) без необходимости в fp.dev.
