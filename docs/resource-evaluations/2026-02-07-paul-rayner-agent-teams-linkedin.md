## Краткое содержание

Пол Рейнер (генеральный директор Virtual Genius, автор справочника EventStorming, основатель Explore DDD) делится производственным опытом с командами агентов Claude Code (Opus 4.6), выполняющими 3 одновременных рабочих процесса терминала. Обеспечивает реальную проверку экспериментальной функции (v2.1.32) с конкретными сценариями использования и поднимает законный технический вопрос о инфраструктуре бисера и руководстве командами агентов.

**Ключевое значение**: Свидетельство практикующего специалиста из первых рук из надежного источника, проверяет команды агентов в производственном контексте, выявляет пробелы в документации (руководства по сравнению с рекомендациями для команд).

### Ключевая информация извлечена

- **Навигация**: Shift+Up/Down, переключение tmux

**Настройка (2 метода)**:
```json

{
  "experimental": {
```

```bash
export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=true
```

2. **Отладка параллельных гипотез**: Каждый агент проверяет разные теории

4. **Масштабный рефакторинг**: разделяй и властвуй между модулями
5. **Анализ базы кода**: задачи, требующие большого объема чтения (отслеживание ошибок, понимание архитектуры).

**Таблица влияния рабочего процесса** (из dev.to):

| Задача | Одиночный агент (раньше) | Команды агентов (После) |
|------|-----------------------|---------------------|
| **Отслеживание ошибок** | Подавайте файлы по одному, объясняйте заново | Просматривайте всю кодовую базу, отслеживайте полный поток данных |
| **Просмотр кода** | Обобщение PR вручную | Подать весь diff + окружающий код |
| **Новая функция** | Опишите кодовую базу в командной строке | Агенты читают кодовую базу напрямую |
| **Рефакторинг** | Потерять контекст после ~ 15 файлов | Все более 47 файлов живут в сеансе |

**Критические ограничения** ⚠️:
- **Тяжелое чтение > Тяжелая запись**: объединение рисков конфликта, если несколько агентов изменяют одни и те же файлы.
- **Токен-интенсивный**: несколько одновременных вызовов модели = высокая стоимость
- **Экспериментальный статус**: Никаких гарантий стабильности
- **Изоляция контекста**: 1M tokens/agent, но общение только через руководителя группы

**Технические возможности**:
- **Контекстное окно**: 1 млн токенов → ~30 000 строк кода за сеанс
- **Coordination**: блокировка задач на основе Git, автоматическое объединение
- **Разрешение конфликтов**: автоматически (но ограничено при интенсивной записи)
- **Полное понимание кодовой базы**: Никаких фрагментов, полный анализ
