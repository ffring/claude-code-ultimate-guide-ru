## Критика ошибок: выявление и исправление

**Fichier**: линии `guide/ultimate-guide.md` ~5738-5741

**Проблема**: Индикация `ctrl+c ctrl+c` / `ESC ESC` для ваших агентов фонда. Faux depuis v2.1.47.

**Риск**: Utilisateurs croyant leurs Agents tues alors qu'ils Tournent en Fond (жетоны консомации молчат, параллельные конфликты).

**Исправить аппликацию**: исправление от 23 февраля 2026 г. ESC не отменяет плюс que le участник потока. `Ctrl+F` = seul moyen de gerer les Agents de Fond (оверлей).

## План интеграции Прогрессивный

### Фаза 1 — Хуки (P1, 1 сеанс)

**`ConfigChange` Хук**: Добавление в таблицу вечерних хуков (автор существующего раздела WorktreeCreate/WorktreeRemove):

```markdown
| `ConfigChange` | When config files change during session | Enterprise: audit + block live config changes |
```

Пример Авека:
```json
{
  "hooks": {
    "ConfigChange": [
      {
        "matcher": "",
        "hooks": [{ "type": "command", "command": "scripts/audit-config-change.sh" }]
      }
    ]
  }
}
```

**`disableAllHooks` управляемая иерархия**: Примечание в разделе «Настройки предприятия»:
> `disableAllHooks` (v2.1.49+) не может быть отключен, а также деактивировать перехватчики, управляемые в рамках политического предприятия. Перехватчики уровня `managed` переопределяют настройки пользователя.

**`last_assistant_message` в Stop/SubagentStop**: Добавление в раздел хуков Stop/SubagentStop:
> Чемпион `last_assistant_message` предназначен для обслуживания входных данных `Stop` и `SubagentStop` (v2.1.47+). Утилита для доступа к финальному ответу без синтаксического анализа стенограмм.

### Фаза 2 — CLI и LSP (P2, 1 сеанс)

**`--from-pr` flag**: В разделе рабочие процессы GitHub/DevOps:
```bash
# Resume session linked to a specific PR
claude --from-pr 123
# Sessions created via gh pr create are auto-linked
```

**`startupTimeout` LSP**: В конфигурации раздела LSP:
```json
{
  "lsp": {
    "servers": {
      "tsserver": { "startupTimeout": 15000 }
    }
  }
}
```

**`enabledPlugins` через `--add-dir`**: В разделе Плагины:
> `enabledPlugins` и `extraKnownMarketplaces` могут быть определены в настройках репертуара `--add-dir`, что позволяет использовать политику плагинов в новом репозитории.
