## Уникальные знания для извлечения

### 1. Метрики pass@k и pass^k
- Формальный подход к проверке:
  - pass@k: хотя бы одна из k попыток успешна.
  - pass^k: все k попыток должны быть успешными.
  - Пример: k=3 → 91% проход@k, 34% проход^k
- Применение: Эмпирически измерить эффективность навыков.

### 2. Рабочий процесс плагина Hookify
- Создание разговорного хука (опишите необходимость → создан JSON)
- Снижает барьер по сравнению с ручной записью JSON
- Шаблон: Естественный язык → структурированная конфигурация.

### 3. Изолированные субагенты
- Ограничение инструментов для каждого агента (проверяющий безопасность не может редактировать)
- Предотвращает случайные разрушительные действия
- Реализация: Определить `tools: [Read, Grep]` в конфигурации агента.

### 4. Каскадный метод (многоэкземплярный)
- Управление несколькими экземплярами Claude: «Проводить слева направо, от самого старого к самому новому».
- Сосредоточьтесь максимум на 3-4 задачах.
- Предотвращает накладные расходы на переключение контекста

### 5. Стоп-хук
