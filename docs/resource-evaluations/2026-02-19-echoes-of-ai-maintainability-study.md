## Краткое содержание

Двухэтапный контролируемый эксперимент по изучению того, влияет ли создание кода с помощью ИИ на удобство сопровождения для последующих разработчиков:

- **Фаза 1**: 151 участник добавляет функции в веб-приложение Java (с искусственным интеллектом или без него: GitHub Copilot/Курсор)
- **Фаза 2**: группа разработчиков *различные* развивает эти решения **без AI** (слепая проверка — рецензенты не знают, был ли код создан с помощью искусственного интеллекта)

**Основные выводы:**
1. Пользователи ИИ выполняли задачи на **на 30,7 % быстрее** (медиана), чем пользователи, не использующие ИИ.
2. Обычные пользователи ИИ показали примерное ускорение **на 55,9 %.**
3. **Нет существенных различий** во времени последующей эволюции или качестве кода — миф о том, что код ИИ не поддается поддержке, не подтверждается эмпирически
4. Исследователи рекомендуют провести дальнейшее расследование рисков чрезмерной генерации кода и когнитивного долга.
5. Явный вывод Дэйва Фарли: разработчики должны управлять ИИ (а не автопилотом), думать о бизнес-проблеме и разлагать сложность

## Краткое описание задачи (агент технического писателя)

**Первоначальный счет:** 4/5
**Основной балл:** 3,5 → 4/5 подтвержден с исправлениями

**Ключевые моменты испытания:**

1. **Оценка оправдана**: но «рецензирование» было завышено. Исправлено на «препринт arXiv».
2. **Проект слепой проверки** (рецензенты фазы 2 не знают, поддерживается ли код искусственным интеллектом) = наиболее важная методологическая деталь, отсутствующая в первоначальной оценке. Добавлен.
3. **55,9% постоянных пользователей** более действенны, чем медиана 30,7% — подтверждает раздел кривой обучения.
4. **Ограничения, не отмеченные в сообщении**: tâchesbornées en labo ≠ 12-месячное изменение рабочей базы кода; потенциальная предвзятость отбора (участники-добровольцы, скорее всего, выступают за ИИ); долг знаний не измеряется.
5. **Риск неинтеграции**: Руководство сохранит предвзятость в пользу METR (ИИ медленнее выполняет сложные задачи) без эмпирического противовеса ремонтопригодности.
