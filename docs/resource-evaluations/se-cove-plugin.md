## Краткое содержание

### Что такое SE-CoVe?

Программная адаптация цепочки проверки Meta для Claude Code.

**Pipeline**:
1. Базовый уровень: создание первоначального решения
2. Планировщик: создание проверочных вопросов на основе претензий
3. Исполнитель: отвечает на вопросы самостоятельно (никогда не видит базовый уровень)
4. Синтезатор: сравнение результатов, выявление расхождений.
5. Результат: создать проверенное решение.

**Критическая инновация**: Верификатор работает без доступа к черновому коду (предотвращает предвзятость подтверждения).
