# Оценка ресурса №080: Goose (блок): агент кодирования искусственного интеллекта с открытым исходным кодом.

**Источник:** [block.github.io/goose](https://block.github.io/goose) / [github.com/block/goose](https://github.com/block/goose)
**Type:** Инструмент с открытым исходным кодом (Apache 2.0) — агент кодирования искусственного интеллекта на компьютере.
**Автор:** Block (ранее Square) — поддерживается командой инженеров Block.
**Оценено:** 17 марта 2026 г.
**Зрелость на момент оценки:** Официально запущен в январе 2025 г., 33 166 звезд (теперь 51 819 по состоянию на 28 июля 2026 г.), 3 058 форков.

---

## Краткое содержание

- **Агент кодирования искусственного интеллекта на компьютере**: CLI для локального использования + настольное приложение, а не облако. Комплексная автоматизация сложных инженерных задач
- **Model-agnostic**: работает с Claude (рекомендуется для вызова инструментов), GPT-4o, Gemini, Groq, локальными моделями (Ollama) — более 20 поставщиков
- **Recipes**: возможность создания версий, совместного использования и параметризации многоэтапных рабочих процессов. В отличие от «файлов правил» — рецепты определяют, что делают агенты, а не как они себя ведут.
- **Оркестровка субагентов**: создание специализированных агентов автономно или с помощью подрецептов с динамическим переключением моделей согласно task/cost
- Поддерживается более 1700 серверов **MCP** (первый агент с открытым исходным кодом, поддерживающий MCP, январь 2025 г.)
- **Программа грантов Goose**: блокирование средств разработчиков, создающих расширения Goose (запущено в июле 2025 г.)
- **Пользовательские дистрибутивы**: команды могут создавать фирменные дистрибутивы Goose с предварительно настроенными поставщиками, расширениями и брендингом.
- **При поддержке Block** (Square, Cash App) — институциональные инженерные ресурсы, а не индивидуальный проект

| Релизы | 100+ | ~175+ (оценка, быстрая частота выпуска) |

**Fix**: обновите таблицу метрик и устраните несоответствие 3000 и 1700 MCP.

### 2. Рецепты — отсутствуют

Рецепты представляют собой эквивалент комбинации Claude Code косых команд + навыков в Goose. Они есть:
- Возможность создания версий и совместного использования как автономных рабочих процессов.
- Импортируется через глубокие ссылки
- Параметризованный (многократное использование в разных контекстах)
- Можно использовать в разных командах

Это имеет прямое отношение к разделу руководства, в котором подробно описаны команды и навыки. Обязателен один абзац с перекрестной ссылкой на §3 (команды) и §4 (навыки).

### 3. Оркестровка субагентов — отсутствует.

Дорожная карта Goose на июль 2025 года представила оркестровку субагентов: создание специализированных субагентов (Planner, Architect, Frontend Dev, Backend Dev) с динамическим переключением моделей для каждого агента. Пример с саммита Agentic AI Summit в Беркли: 7 агентов совместно создали полнофункциональное приложение менее чем за час.

Это частично совпадает с собственными многоагентными шаблонами Claude Code (§9). Выноска в один абзац со сравнением с инструментом «Агент» Claude Code поможет читателям понять архитектурную разницу (Claude Code: один агент + порождение инструмента против Goose: многоагентные подпотоки, определяемые рецептом).

### 4. Agentskills.io — проверьте текущий статус

Параграф «Переносимость навыков» ссылается на сайт Agentskills.io. **Подтвержден live** (17 марта 2026 г.). Никаких изменений не требуется.
