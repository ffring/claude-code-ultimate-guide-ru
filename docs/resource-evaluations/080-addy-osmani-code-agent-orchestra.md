## Краткое содержание

Адди Османи представляет сдвиг парадигмы от синхронного взаимодействия одного агента к асинхронной оркестровке нескольких специализированных агентов. Охватывает субагентов, команды агентов (экспериментальные), ограждения циклов, шаблон специального рецензента, бюджетирование токенов, многомодельную маршрутизацию и исследование ландшафта инструментов 2026 года. Создан на основе «фабричной модели» для производственных многоагентных рабочих процессов.

**Ключевые моменты**:
- Три смены ментальной модели: Дирижер → Оркестратор, потолок одного агента (контекст, специализация, координация), асинхронные команды с общим списком задач + обмен сообщениями между коллегами
- `MAX_ITERATIONS=8` ограждение цикла + обязательный запрос на отражение перед повторными попытками
- Выделенный товарищ по команде `@reviewer`: Opus 4.6, только чтение, автоматический запуск при выполнении задачи, 1 на 3–4 строителя.
- Исследование эффективности AGENTS.md (Gloaguen et al., ETH Zurich, arXiv 2602.11988): Сгенерировано LLM = -3% успеха, +20% затрат; написанный человеком = улучшение +4%
- Бюджетирование токенов на агента: жесткие ограничения, автоматическая пауза на уровне 85%, уничтожение при 3+ зависших итерациях
- Инструментальная среда 2026 г.: 3 уровня (в процессе, локальные оркестраторы, облачная асинхронизация)
- Центральное узкое место: «Генерация больше не является узким местом. Верификация — есть».

## Примечания к испытаниям

Проверка вызова (агент технического писателя) подняла следующие вопросы, и все они подтверждены:

1. **Ralph Конфликт именования циклов**: подтверждено через Grep. У Гида есть выкройка Джеффри Хантли по адресу UG:1899; Османи использует тот же термин для обозначения другой модели. Требуется устранение неоднозначности.
2. **AGENTS.md риск дублирования статистики**: Gloaguen et al. уже упоминается в руководстве (UG:16924) для данных о стоимости; статистика успеха (-3%/+4%) отсутствует. Частичная интеграция уместна.
3. **8-уровневое резервирование структуры**: Руководство уже интегрирует 6-уровневую структуру зрелости агентов Martignole. Восьмиуровневая структура Османи концептуально перекрывается. Не добавляйте в качестве конкурирующей структуры.
4. **Нестабильность инструментов**: Подтверждено: несколько перечисленных инструментов являются предварительными версиями или имеют неопределенные планы развития. Обозначено «только монитор».
5. **Флаг конфликта интересов**: Османи — руководитель Google Cloud AI. Его подход к экосистеме Claude Code не является нейтральным. Содержимое основано на фактах, но не должно позиционироваться как архитектура, рекомендованная Anthropic, без подтверждения.
