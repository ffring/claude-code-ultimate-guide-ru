# Оценка ресурсов

Этот досье содержит оценки внешних ресурсов (статьи, видео, обсуждения) для определения актуальности для окончательного руководства Claude Code.

## Методология

Этот ресурс ценен как стандартизированная и сложная система подсчета очков, гарантирующая объективность.

### Решетка для очков (сюр 5)

| Счет | Значение | Действие |
|-------|---------------|--------|
| 5 | **Critical** — Прорыв, необходимо немедленно интегрировать | Интегратор су 24 часа |
| 4 | **High Value** — новые возможности или значительные улучшения. | Интегральный су 1 сезон |
| 3 | **Moderate** — Полезное дополнение, но не срочное. | Интегратор в любое время доступен |
| 2 | **Marginal** – дополнительная информация или нишевый вариант использования. | Ne pas intégrer (вы упоминаете минимальный) |
| 1 | **Low** – избыточно, неверно или не по теме. | Реджетер |

### Процесс

1. **Первоначальный анализ**: извлечение фактов, проверка источников
2. **Scoring**: присвоение оценки с обоснованием
3. **Challenge**: Агент, технический писатель, задает вопрос о счете
4. **Окончательное решение**: интеграция или отказ от отслеживания

### Номенклатура фишеров

Формат: `[topic-slug].md` (установленная дата для стабилизации залоговых обязательств)

Пример: `remotion-claude-code-video.md`
