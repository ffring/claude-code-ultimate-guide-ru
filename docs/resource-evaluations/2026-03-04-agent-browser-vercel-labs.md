## Управляющее резюме

**Окончательный результат**: **5/5 (КРИТИЧНЫЙ)**

Agent-browser — это безголовый браузер CLI, созданный специально для ИИ-агентов. Запущенный Vercel Labs в январе 2026 года, он использует Playwright под капотом, но абстрагирует все сложности для рабочих процессов, родных для LLM. Ключевое отличие: на 82,5 % меньше потребляемых токенов по сравнению с Playwright MCP для идентичных сценариев тестирования благодаря компактным ссылкам на элементы (`@e1`, `@e2`) и минимальному количеству практических результатов. Написан на Rust для запуска за доли миллисекунды. Имеет прямое отношение к разделам руководства по тестированию и агентам — заполняет задокументированный пробел в строке 10510, где Playwright MCP — единственный указанный инструмент автоматизации браузера.

## Обзор ресурса

### Ключевые особенности

| Особенность | Подробности |
|---------|---------|
| **Реализация** | Rust (основной, запуск менее миллисекунды) + резервный вариант Node.js |
| **Протокол** | Протокол Chrome DevTools (CDP) через Playwright |
| **Браузеры** | Хром, Фаерфокс, ВебКит |
| **Сокращение токенов** | -82,5% по сравнению с Playwright MCP (документированный тест, блог Pulumi от 3 марта 2026 г.) |
| **Ссылка на элемент** | Стабильный формат `@e1`, `@e2` (по сравнению с селекторами XPath/CSS) |
| **Security (v0.15.0)** | Хранилища аутентификации, белые списки доменов, политики действий, ограничения длины вывода |
| **Multi-session** | Изолированные экземпляры браузера с отдельным cookies/storage/auth |
| **Сохранение сеанса** | Состояние Save/restore с шифрованием AES-256-GCM (`--session-name`) |
| **Потоковая передача через браузер** | Предварительный просмотр WebSocket для «парного просмотра» (человек + агент) |
| Интеграции **AI** | Встроенная поддержка Claude, Gemini, Cursor, GitHub Copilot |

### Основные возможности

- Навигация, щелчок, ввод текста, прокрутка, снимок экрана, создание PDF-файла
- Снимки дерева доступности (оптимизированы для обработки LLM)
- Визуальные различия пикселей по сравнению с базовыми показателями
- Различия в дереве доступности с настраиваемой глубиной и селекторами
- Сетевой перехват и издевательство
- Управление файлами cookie и хранилищем
- Эмуляция устройства, симуляция геолокации
- Управление Keyboard/mouse, обработка диалогов
- Оценка JavaScript, захват консоли
- Отслеживание и профилирование производительности

### Скорость выпуска

v0.10.0 → v0.15.0 с середины февраля до конца февраля 2026 г. Новое в последних выпусках: расширенное профилирование, файлы конфигурации, улучшенная эмуляция устройств, хранилища аутентификации, списки разрешенных доменов.

## <a name="evaluation"></a>Оценка

### Оценка: 5/5 (КРИТИЧЕСКИЙ)

**Justification**:

1. **Прямой разрыв**: Справочные документы Драматурга MCP в строке 10510 только с 4 инструментами и 3 вариантами использования. Agent-browser — это специально созданный преемник агентских рабочих процессов.

2. **Эффективность токенов является основным драйвером.**: Основная задача руководства включает оптимизацию токенов. -82,5% по сравнению с драматургом MCP в идентичных сценариях — это конкретный, документированный показатель (не маркетинговый).

3. **Шаблон цикла Ральфа Виггама**: В блоге Pulumi (03.03.2026) документирован шаблон самопроверяющегося агента, который идеально соответствует разделам руководства по агентным рабочим процессам. Сборка → Развертывание → Проверка → Итерация, все автономно.

4. **12 100+ звезд менее чем за 3 месяца**: сигнал о внедрении на уровне самых быстрорастущих инструментов разработки в 2025–2026 годах.

5. **RPA смещение**: Консенсус сообщества (обсуждения в Slack, «10 лучших агентных браузеров», Bright Data, 2026-02-04) позиционирует агент-браузер как инструмент, убивающий традиционный RPA для рабочих веб-процессов.

### Предостережения

- **Не является заменой традиционных пакетов E2E для Playwright.**: по-прежнему предназначен для агентских рабочих процессов, а не для участников тестов Playwright (шут-драматург и т. д.).
- **Стена защиты от ботов без изменений**: репутация IP, поведение сеанса, шаблоны прокрутки, пользовательские агенты — ничего из этого не меняется. Службы типа «база браузера» по-прежнему необходимы для парсинга внешних сайтов.
- **Ранняя стадия**: функции безопасности (v0.15.0) являются новыми. Производственная закалка продолжается.

| Контроль безопасности | Никто | Хранилища аутентификации, белые списки |
| Потоковая передача через браузер | Нет | Да (экспериментальный) |
| Самопроверяющиеся агенты | Неуклюжий | **Родной шаблон** |

## Петля Ральфа Виггама

Базовый шаблон агента-браузера позволяет использовать агентские рабочие процессы:

```
Build → Deploy → [agent-browser verifies] → Fix → Repeat
```

1. Агент пишет код (функция, компонент, исправление)
2. Развертывает (Версель, Пулуми или любую цель)
3. Автономно запускает агент-браузер
4. Переход к развернутому URL-адресу, тестирование сценариев
5. В случае сбоя: агент читает снимок, исправляет код, повторно развертывает
6. Ни одного человека в курсе, пока проверка не пройдет

Задокументировано в производстве в Пулуми (03.03.2026) по 6 сценариям тестирования: загрузка домашней страницы, сокращение URL-адресов, просмотр информационной панели, навигация по аналитике, обзор аналитики, фильтр по дате.

## Варианты использования руководства Claude Code

1. **E2E тестирование в циклах агентного кодирования** (основной: заменяет ручные сценарии драматурга)
2. **Развертывания с самопроверкой** (Петля Ральфа Виггама)
3. **Цепы обратной связи по наблюдаемости** (скриншот + различия в доступности при каждом развертывании)
4. **Автоматизация форм** для агентов ИИ, которым необходимо взаимодействовать с веб-интерфейсами
5. **Визуальное регрессионное тестирование** с различиями пикселей относительно базовых показателей
