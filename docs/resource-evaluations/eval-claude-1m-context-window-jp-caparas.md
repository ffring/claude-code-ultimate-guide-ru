## Краткое содержание

Объяснение простым языком: что такое токены и что могут содержать токены 1M (кодовые базы, юридические документы, научные статьи), утверждается, что 1M context стал общедоступным 13 марта для Opus 4.6, сравнение цен с OpenAI GPT-5.4 / Google Gemini 3.1 Pro / Meta Llama 4, влияние Claude Code на рабочий процесс (сжатие) сокращение, сеансы с полной кодовой базой), варианты корпоративного использования (проверка соответствия, миграция кодовой базы, реагирование на инциденты), эффект «потерянного посередине» в виде постоянного ограничения, оценка MRCR v2 (78,3% Opus 4.6) и цитаты Джона Белла (CPO Codeium) и Антона Бирюкова (Ramp).

**Критический вывод**: Отличительная черта статьи заключается в том, что «ставка Anthropic — фиксированная цена — без надбавки независимо от длины». Это на самом деле неправильно. Anthropic взимает 2-кратную плату за ввод и 1,5-кратную плату за вывод при количестве токенов более 200 000. Весь анализ конкурентного ценообразования, построенный на этой предпосылке, ненадежен.

## Примечания к испытаниям

По мнению технического писателя, оценка 2/5 оправдана. Первоначальное предложение 3/5 было пересмотрено в сторону понижения, поскольку проверка фактов разрушает основное ценностное предложение статьи — неправильные данные о ценах не могут дополнить руководство, нацеленное на точность. Анекдот Повиласа Коропа (83% использования контекста в проекте Laravel) — хороший пример реальных данных, но он анекдотичен и недостаточен, чтобы изменить оценку.

Ключевой вывод из обзора: «Исправить устаревшую информацию в руководстве» — это реальное действие, независимое от этого ресурса. Если контекст 1M на самом деле является общедоступным, в нашем руководстве по-прежнему указано «бета» в строках 2028–2070 — это требует исправления независимо от этой статьи.

## Решение

**Не интегрировать.**

### Конкретные исключения

- Таблица сравнения цен (основное утверждение о фиксированных ценах неверно)
- Варианты корпоративного использования (гипотетические, без измеренных данных)
- Непроверяемые цитаты (Джон Белл, Антон Бирюков)

### Независимые действия, вызванные этой проверкой

1. **Проверьте статус 1M GA** через официальную документацию Anthropic / журнал изменений API
2. **Если подтверждено GA**: обновите строки `guide/ultimate-guide.md` 2028-2070 (в настоящее время написано «бета»)
3. **Если подтверждено GA**: проверьте, изменилась ли вообще структура надбавки в размере 200 тыс.
4. **Рассмотрите возможность добавления**: одна строка об эффекте «затерянности посередине» в `guide/core/context-engineering.md` (хорошо документированное ограничение, arxiv:2307.03172 — независимо от этой статьи)

### Стоит независимой проверки

Шаблон рабочего процесса Ramp (поиск Datadog + Braintrust + DB + source = 100 000 токенов перед написанием одного исправления) — полезная иллюстрация того, почему большие контекстные окна важны для реальных рабочих процессов проектирования — стоит добавить, если это подтвердит независимый источник.
