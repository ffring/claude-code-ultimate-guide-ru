## Краткое резюме

**Score**: **4/5** (высокое значение — интеграция в течение 1 недели)

Claude-mem — это плагин Claude Code, обеспечивающий **автоматическую память сеансов** посредством сжатого AI захвата использования инструментов, наблюдений и решений. Это заполняет пробел в руководстве: хотя Serena (память символов) и grepai (семантический поиск) документированы, **автоматический захват сеанса** — нет.

**Основная статистика** (обновлено 30 марта 2026 г.):

- 46 участников
- Последняя версия: v10.6.3 (по сравнению с версией 9.1.1 при первоначальной оценке)
- Лицензия: AGPL-3.0 + PolyForm Некоммерческая

## Краткое содержание

**Что делает Клод-Мем**:

1. **Автоматический захват**: подключается к жизненному циклу Claude Code (SessionStart, PostToolUse, Stop, SessionEnd) для записи всех операций с инструментом.
2. **AI Compression**: использует Claude для создания семантических сводок наблюдений (сокращение токенов примерно в 10 раз).
3. **Гибридный поиск**: полнотекстовый + векторный поиск (цветность) + запросы на естественном языке
4. **Progressive Disclosure**: трехуровневое извлечение (поиск → временная шкала → get_observations) экономит 95% токенов.
5. **Веб-панель**: пользовательский интерфейс `http://localhost:37777` в режиме реального времени для просмотра истории сеансов.
6. **Автоматическое внедрение**: Соответствующий контекст автоматически добавляется в начале сеанса.

**Architecture**:
```
Lifecycle Hooks → Observation capture → AI compression (Claude)
                                             ↓
                                    SQLite storage
                                             ↓
                              Chroma vector indexation
                                             ↓
                              Session start injection
```

**Заявления о производительности** (из статей, не проверенных независимыми экспертами):
- Прогрессивное раскрытие информации: сокращение количества токенов в 10 раз
- Бесконечный режим (бета): сокращение контекста на 95 % → в 20 раз больше вызовов инструментов без ограничений.
- Стоимость: ~$0,15 за 100 обработанных наблюдений.

## Оценка релевантности: 4/5

### Почему 4/5 (высокое значение)?

**✅ Сильные стороны**:

1. **Gap Identified**: Руководящие документы Serena (память символов, руководство) и grepai (семантический поиск), но **не автоматический захват сеанса**
2. **Массовое внедрение**: 26,5 тыс. звезд, 181 выпуск, 46 активных участников.
3. **Production-Ready**: лицензия AGPL-3.0, стабильная версия API, активное обслуживание
4. **Complementary**: не заменяет существующие инструменты, а расширяет их.
5. **Token Efficiency**: шаблон прогрессивного раскрытия информации, ценный для управления контекстом.

**⚠️ Почему не 5/5?**:

1. **Паттерн частично покрыт**: Серена `write_memory()` существует для ручной памяти, поэтому пробел является «автоматическим», а не «памятью».
2. Ограничения **AGPL-3.0**: ограничения коммерческого использования, требования к раскрытию источника.
3. **Скрытые затраты**: наблюдения $0.15/100, не задокументированные в официальном README
4. **CLI Только**: нет веб-интерфейса, нет облачной синхронизации, нет поддержки нескольких компьютеров.
5. **Нишевый вариант использования**: дает преимущества пользователям с >10 sessions/week, менее ценен для случайных пользователей

### Шаблон стека памяти (предлагается)

```
┌─────────────────────────────────────────────────────────┐
│           Memory Stack (4 layers)                       │
├─────────────────────────────────────────────────────────┤
│ Layer 4: Session Capture   → claude-mem (automatic)    │
│ Layer 3: Symbol Memory     → Serena (manual decisions) │
│ Layer 2: Semantic Search   → grepai (discovery)        │
│ Layer 1: Exact Search      → rg (native, fast)         │
└─────────────────────────────────────────────────────────┘
```

**Пример интегрированного рабочего процесса**:

```bash
# Scenario: Refactoring auth module after 3 days

# 1. AUTO CONTEXT (claude-mem)
# At session start, Claude injects:
# "3 previous sessions explored auth module.
#  Decision: Migrate to JWT.
#  Files modified: auth.service.ts, session.middleware.ts"

# 2. ARCH DECISIONS (Serena)
serena list_memories
# → "auth_decision: Use JWT for stateless API (2026-02-07)"

serena read_memory("auth_decision")

# 3. SEMANTIC DISCOVERY (grepai)
grepai search "JWT token validation"
# → Finds validateJWT() in auth.service.ts

# 4. DEPENDENCIES (grepai trace)
grepai trace callers "validateJWT"
# → Called by: ApiGateway, AdminPanel, UserController

# 5. EXACT SEARCH (rg)
rg "validateJWT" --type ts -A 5
```

**Result**: Полный контекст без повторного чтения всех файлов, безопасный рефакторинг.

## Ограничения и соображения

### Ограничения claude-mem

1. Лицензия **AGPL-3.0**
   - Изменения требуют раскрытия источника.
   - Для развертывания сети требуется AGPL
   - Ограничения на коммерческое использование

2. **Скрытые расходы**
   - 0,15 доллара США за 100 наблюдений (сжатие API)
   - Не описано в официальном README.
   - Может накапливаться в крупных проектах

3. Только **CLI**
   - Нет поддержки веб-интерфейса
   - Нет облачной синхронизации между компьютерами
   - Нет интеграции с VS Code

4. **Теги конфиденциальности вручную**
   - Теги `<private>` необходимы для конфиденциального контента.
   - Забыть теги → конфиденциальные данные в БД
   - Нет автоматического обнаружения секрета
