**URL**: https://github.com/NahumLitvin/prismantis
**Type**: репозиторий GitHub, плагин Claude Code, распространяемый через собственный магазин (`prismantis@prismantis`), мод (перехватчики функций TypeScript)

**Evaluator**: Claude Code Ultimate Guide Team
**Версия руководства**: 3.44.1
**Method**: README читается в ветке по умолчанию (`main`) через GitHub API; список выпусков и примечания к версии 0.38.0; выпуски №209 и №319 с их временными метками; подсчет участников и выпусков через GitHub API; сообщение сопровождающего прочитано полностью; `claude plugin validate` запускается на клоне при фиксации `dc51f35` (v0.38.2); текстовый поиск по поставляемому коду `hooks/` для сетевых API. ## Краткое содержание

prismantis перерисовывает то, что Claude Code показывает в терминале. Ответы получают цветные таблицы, подсветку синтаксиса Prism на 24 языках, блок-схемы «русалка», диаграммы последовательностей, состояний, классов и ER, диаграммы `xychart-beta`, круговые диаграммы и блоки `figure`, нарисованные в том виде, в каком они написаны. Строки инструментов становятся однострочными сводками, а изменения — карточками различий. Вывод косой черты команды и собственные подсказки пользователя также были изменены. Каждый блок имеет кнопки копирования, а `/prismantis copy` предназначен для использования только с клавиатуры.

Он построен на основе мода API, поставляемого в Claude Code 2.1.287 (1 октября 2026 г.): перехватчик `ui.render` получает каждую часть транскрипта перед его отрисовкой и вместо этого возвращает то, что нужно отрисовать. В сообщении сопровождающего (https://www.catchkill9.dev/posts/prismantis.html) первый выпуск датируется 2 октября 2026 года.

Единственное, что он отправляет модели, — это необязательная заметка `diagramHints`, прикрепленная к каждому приглашению, которая сообщает Claude, что терминал может рисовать. README выдает около 630 токенов за одно приглашение (около 275 для основной части, около 360 для фигурной части) и еще около 80 при включенном `latex`, подсчитанные с помощью токенизатора Claude.

## Вывод валидатора (фиксация `dc51f35`, v0.38.2)

`claude plugin validate` прошел с одним предупреждением о каталоге плагина (без значка). Соответствующие строки:

- `hooks:` включает `ui.render` в сообщениях помощника, сообщениях пользователя, строках инструментов и выводе команд, а также `tool.call`, `prompt.submit`, `turn.complete`, `session.start` и `command.run{command=prismantis}`.
- `calls:` включает `$.process.run` (через помощник буфера обмена и набор текста LaTeX), `$.ui.copy`, `$.fs.read`, `$.fs.stat`, `$.config.set` и `$.session.messages`.
- `env writes: nothing`; Чтения env — это переменные обнаружения терминала (`TERM_PROGRAM`, `SSH_CONNECTION`, `TMUX`, `KITTY_WINDOW_ID` и аналогичные)
- Пять хуков без `.catch` (`tool.call`, `prompt.submit`, `ui.focus`, `ui.scroll` на панели настройки, `prismantis.markdown`). Это уведомление валидатора, а не наблюдаемый сбой.

`tool.call`, являющийся хуком-затвором, означает, что мод находится на пути вызова инструмента. Ничто в этой оценке не указывает на изменение вызовов инструментов; README описывает только рисунок. Это своего рода декларация, которую нужно перечитывать при каждом обновлении.

## Где он находится относительно существующего покрытия руководства

В руководстве объясняются моды в `guide/ultimate-guide.md` (Claude Mods v2.1.287+) с примерами Anthropic, но без примеров сообщества. `guide/ecosystem/third-party-tools.md` перечисляет заменяемые интерфейсы в разделе «Альтернативные пользовательские интерфейсы» (Claude chic, Toad, Conductor). prismantis не является ни тем, ни другим: он сохраняет собственный интерфейс Claude Code и меняет способ его отрисовки. Ни одна существующая запись не охватывает рендеринг терминала, точность копирования в Slack или стоимость токена мода, который внедряет контекст модели.

Примечание `diagramHints` также представляет собой конкретный, задокументированный случай, когда плагин добавляет контекст к каждому приглашению, который соединяется с материалами по разработке контекста руководства: стоимость указана за каждое приглашение, на уровне пользователя и невидима в расшифровке.

## Решение

**Integrated** в `guide/ecosystem/third-party-tools.md`, новый раздел "Терминальный рендеринг (моды)", со строкой персоны в "Рекомендации по персонам". В записи указывается стоимость `diagramHints` как цифра README, объясняется, когда отключать подсказки, показана проверка валидатора и ее предел, а также датирован ответ сопровождающего на проблему №319.

**Не выполнено**: перекрестная ссылка из раздела модов `guide/ultimate-guide.md`. Перехватчик анти-ИИ репозитория оценивает весь файл после редактирования, и этот файл уже содержит длинные тире в прозе, поэтому в редактировании было отказано. Добавьте перекрестную ссылку, как только она будет очищена.

**Откройте пробелы в доказательствах**: измерьте фактическую стоимость токена на каждое приглашение (`/context` с `diagramHints` и без него) и проверьте рендеринг в приложении для ПК и VS Code.
