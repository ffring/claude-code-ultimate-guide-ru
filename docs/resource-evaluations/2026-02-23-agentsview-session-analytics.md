## 📄 Резюме ресурса

**Type**: локальное веб-приложение (Go + Svelte 5 + SQLite FTS5).

**Ключевые моменты**:
1. **Полнотекстовый поиск** по месяцам сеансов с помощью SQLite FTS5 — мгновенно находите конкретные обсуждения
2. **Аналитика использования**: тепловые карты активности, показатели скорости, разбивка использования инструментов, статистика по проектам
3. **Мониторинг в реальном времени**: отслеживает каталоги сеансов через события, отправленные сервером, передает потоковые сообщения в реальном времени.
4. Поддержка **Multi-CLI**: Claude Code + Codex + Gemini CLI (уникальный в космосе)
5. **Local-first**: один двоичный файл Go, лицензия MIT, без учетных записей, без облака; экспорт сеанса в формате HTML или GitHub Gist

**Технический стек**:
- Бэкенд: Go (56,8% кодовой базы)
- Фронтенд: Svelte 5 + Vite + TypeScript
- Хранилище: SQLite с полнотекстовым поиском FTS5.
- В режиме реального времени: события, отправленные сервером (встроенный веб-сервер)

## 🎯 Оценка: 3/5

**Justification**: Реальный пробел в руководстве — ни один существующий документированный инструмент не сочетает в себе полнотекстовый поиск + визуальную аналитику (тепловые карты, скорость) в локальном веб-интерфейсе.

- `claude-code-viewer`: базовый просмотр сеансов, без поиска и аналитики.
- `session-search.sh`: CLI только поиск, нулевой пользовательский интерфейс, никакой аналитики.
- `ccboard`: панель управления, ориентированная на затраты, полнотекстовый поиск не подтвержден

AgentsView восполняет этот пробел. Однако репозиторий был создан 19 февраля 2026 г. (за 4 дня до этой оценки), имеет 49 звезд (теперь 4581 по состоянию на 28 июля 2026 г., после переименования в kenn-io/agentsview) и только 2 участника. Слишком недавно для 4/5 (высокая стоимость), не получившего широкого распространения. Авторитет Уэса МакКинни (создателя панд) является сильным позитивным сигналом.

## 🔥 Челлендж (технический писатель)

Агент по вызову рекомендовал **3/5** (вместо первоначального 4/5) по следующим причинам:

1. **Score**: 4/5 требует проверяемых сигналов внедрения. Репо 4 дня, 49 звезд → 3/5 правильно.
2. **Размещение исправлено**: правильное местоположение - `observability.md` (analytics/monitoring), а не `third-party-tools.md`. В руководстве прямо указано, что third-party-tools.md «не является самодельным скриптом мониторинга (см. «Наблюдаемость»)». AgentsView — это панель аналитики.
3. **ccперекрытие щитов**: более значительное, чем первоначально предполагалось. Необходимо явно задокументировать различие: ccboard = стоимость + просмотр сеанса; AgentsView = поиск FTS + аналитика поведения.
4. **Отсутствует в первоначальной оценке.**: тип модели (теперь подтвержденный MIT с открытым исходным кодом), точный стек (подтвержденный Go, а не Rust), утверждение «ничего не покидает вашу машину» является маркетинговым (не проверено с помощью анализа трафика).

**Adopted**: Оценка изменена на 3/5.. Место изменено на `observability.md`.
