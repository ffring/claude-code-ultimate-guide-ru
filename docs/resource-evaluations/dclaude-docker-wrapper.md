## Краткое содержание

1. **dclaude** — это однофайловый сценарий bash, который упаковывает Claude Code CLI в стандартный контейнер Docker для изоляции файловой системы. Прямая замена: перенаправлены все флаги Claude CLI.
2. **Основная мотивация**: Claude Code может перемещаться по целым файловым системам, включая другие ветки рабочего дерева git, рискуя случайно внести изменения в рабочий код. dclaude ограничивает видимость только смонтированными каталогами.
3. **Features**: пересылка агента SSH, подпись GPG, Docker-in-Docker (через хост-сокет), автоматическое сопоставление портов с перезаписью URL-адресов, постоянные именованные контейнеры, пересылка токенов GitHub, автозагрузка `.env`.
4. **Installation**: однократная загрузка `curl`, автоматически создает образ Docker при первом запуске. Требуется только Docker Engine (без Docker Desktop).
5. **Модель безопасности**: стандартная изоляция контейнера (не microVM). Монтирует сокет хоста Docker (`/var/run/docker.sock`), `~/.ssh`, `~/.gnupg` в контейнер — расширяет поверхность атаки по сравнению с подходом частного демона песочницы Docker.

## Обоснование оценки

**2/5 (Маргинальный)**, потому что:

- Руководство уже охватывает песочницы Docker (официальная, изоляция microVM) плюс 5 альтернатив — никаких существенных пробелов.
- dclaude использует стандартные контейнеры, а не микроВМ — более слабая изоляция, чем песочницы Docker. Собственные антишаблоны руководства (строка 377) предупреждают: «Предполагая, что контейнеры = виртуальные машины».
- Монтирование сокета хоста Docker означает, что контейнерный Claude может управлять демоном хоста Docker — в отличие от частного демона Docker Sandboxes.
- Bash-скрипт с одним сопровождающим без гарантий жизненного цикла
- Однако: работает над Linux с движком Docker (реальный пробел), а положение Патрика Дебуа в сообществе DevOps придает авторитет.

**Почему бы и нет 3/5**: Более слабая модель безопасности и узкий дифференциатор (разрыв только для Linux) не требуют специального раздела. В руководстве уже документировано ограничение Linux.

**Почему бы и нет 1/5**: Заполняет законный пробел для пользователей Linux Docker Engine. Вклад Дебуа заслуживает признания.
