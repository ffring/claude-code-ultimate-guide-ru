## Вердикт

logseq-wiki — это собственный порт obsidian-wiki для Logseq, который сам по себе является реализацией шаблона Wiki LLM Андрея Карпати: агент компилирует источники один раз во взаимосвязанные страницы и поддерживает их актуальность, вместо повторного получения ответов через RAG на каждый вопрос. Порт меняет формат (свойства Logseq `key:: value` вместо заголовка YAML, ссылки пространства имен `[[wiki/...]]`) и сохраняет конвейер: прием, извлечение, разрешение, схема.

Как инструмент он не занимает места в руководстве. Это порт, созданный одним автором и требующий минимального внедрения, а реализуемый им шаблон уже описан в разделе OKF основного руководства. Что он действительно зарабатывает, так это место в качестве тематического исследования. Его автономное задание по приему данных объединяет в одном запланированном запуске все факторы, которые превращают личную базу знаний в хранилище для быстрого внедрения. Раздел руководства, посвященный отравлению памяти, касался только случая, общего для всей команды.

## Что делает код с исходниками

1. **Автономный запуск со всеми предоставленными разрешениями, подпитываемый сторонним контентом.** [`run_auto.sh`, строка 79](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/run_auto.sh#L79) запускает `claude -p "$PROMPT" --dangerously-skip-permissions`. В заголовке сценария указано «Нет человека в цикле». В качестве входных данных используется история просмотра YouTube, полученная пользователем, а затем сеанс получает расшифровки сторонних видео. [prompt](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/auto-prompt.md) инструктирует сеанс записать страницы, зафиксировать и отправить их на удаленное хранилище хранилища.
2. **Авторство агента намеренно удалено.** Тот же запрос запрещает трейлер `Co-Authored-By: Claude` в коммитах хранилища. Происхождение страниц, написанных агентом, теряется на уровне git.
3. **A конечная точка отладки браузера, открытая для любого источника.** [`run_auto.sh`, строка 47](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/run_auto.sh#L47) запускает Chrome с `--remote-debugging-port=9222 --remote-allow-origins='*'` в выделенном профиле, который поддерживает сеанс YouTube с входом в систему. Подстановочный знак отключает проверку происхождения, которую Chrome применяет к соединениям DevTools WebSocket. Возможность использования веб-страницы здесь не проверялась.
4. Средство устранения **A, которое существует, но не находится на открытом пути.** `wiki-ingest` поддерживает промежуточный режим (`WIKI_STAGED_WRITES=true`), который отправляет написанные LLM страницы и исправления в `wiki/_staging/` для проверки через `wiki-stage-commit`. Эта переменная отсутствует в `.env.example`, поэтому по умолчанию стадирование отключено, а автономная подсказка записывает данные непосредственно в `wiki/<theme>/`.
5. **Документация, противоречащая коду.** Комментарий [launchd plist](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/com.logseq-wiki.yt-history.plist#L7) описывает задание как «полуавтоматическое, без загрузки». Скрипт, который он запускает, выполняет полную загрузку, фиксацию и отправку.
6. **Фильтрация секретов только по подсказке.** [`claude-history-ingest`, строка 254](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/claude-history-ingest/SKILL.md#L254) считывает транскрипты Claude Code (`~/.claude/projects/*/*.jsonl`) и опирается на инструкцию «Пропускать все, что похоже на секреты». Ни один детерминированный сканер не запускается до записи страниц в хранилище.

## Идеи, достойные внимания, но не интегрированные

- **Происхождение разных инструментов diff** (`memory-bridge`): страницы помечены историей агента, из которой они получены, а режим сравнения перечисляет то, что известно истории одного инструмента, а история другого нет. Новый, но один репозиторий без доказательств использования.
- **Контекстные пакеты, ограниченные токенами** (`wiki-context-pack`): страницы с ранжированием по релевантности, упакованные в рамках бюджета токенов для нижестоящего агента. В принципе уже охвачено прогрессивным раскрытием информации в `memory-systems.md`.
