## 📄 Резюме содержания

**Классические очки** (5 предметов):

1. **Парадигма удаленной разработки**: Серверное кодирование с помощью mosh/tmux/Tailscale для доступа к нескольким устройствам и обеспечения устойчивости
2. **Среда автоматизации**: категоризация по 4 квадрантам (на ходу, запланированные задания, расширенные задачи, параллельная обработка)
3. **Автономные рабочие процессы**: плагин Ralph Wiggum с `--max-iterations 50`, автономные циклы заливки на несколько часов
4. **Мобильная настройка**: Termius + Wispr Flow для разработки мобильных устройств и голосового ввода
5. **Модель безопасности**: Ограничитель производительности на сервере для языкового стандарта доступа к учетным данным (частная сетка Tailscale)

**Упоминания об утилитах**:
- **Подключение**: Tailscale (VPN), mosh (мобильная оболочка), tmux (терминальный мультиплексор)
- **Голосовой ввод**: Wispr Flow (транскрипция для настольных компьютеров и мобильных устройств)
- **Мобильный терминал**: Termius (поддержка mosh)
- **Scheduling**: плагин планировщика claude-code (на основе cron)
- **Длительно работающий**: плагин Ralph Wiggum (`--max-iterations N`)
- **Распараллеливание**: рабочие деревья Git + окна tmux
