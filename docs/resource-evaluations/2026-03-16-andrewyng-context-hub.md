**Score**: 2/5

## Краткое содержание

- **Что это такое**: инструмент CLI (`chub`), предоставляющий агентам кодирования курируемую версионную документацию API в виде файлов уценки.
- **Основные команды**: `chub get openai/chat --lang py` для получения документов API; `chub annotate <id> "note"` для постоянных межсеансовых аннотаций
- **Corpus**: более 602 записей документации (по состоянию на 16 марта 2026 г.), охватывающих OpenAI, Anthropic, Stripe, AWS и другие.
- **Сообщество**: пользователи голосуют за качество документа (`chub feedback`), предлагая улучшения для сопровождающих
- Интеграция **Claude Code**: поддержка SKILL.md для перехода в `~/.claude/skills/`
- **License**: MIT, 6342 звезды (сейчас 13861 по состоянию на 28 июля 2026 г.)

---

## Оценка: 2/5

**Justification**: одна действительно новая функция (постоянные межсессионные аннотации во внешних документах API), которую Context7 не может воспроизвести. Все остальное частично совпадает с существующими руководствами: Context7 уже обрабатывает версионные документы библиотеки, `@url` изначально втягивает живую документацию в контекст Claude Code, а шаблоны борьбы с галлюцинациями уже задокументированы. Вариант использования аннотации реален, но решает узкую проблему. Никаких производственных тестов, никакой независимой проверки.

## Заметки о вызовах (агент технического писателя)

**Отказы по клавишам:**

1. **Stars ≠ принятие**: 6342 звезды благодаря социальной поддержке Эндрю Нга, а не проверке производства
2. Перекрытие **Context7 не продемонстрировано**: `chub get openai/chat --lang py` против `query-docs` Context7 — оценка не доказывает конкретный разрыв
3. **Аннотация — единственный новый ракурс**: и он был похоронен — это единственная особенность, которую Context7 не может воспроизвести.
4. **Формирование галлюцинаций — это натяжка**: документы, поддерживаемые сообществом, создают проблему доверия, которую Context7 избегает (официальные источники)
5. **Missing: встроенная альтернатива `@url`**: Claude Code уже изначально извлекает живые документы, что ослабляет случай «пробела».
6. **Missing: риск обслуживания.**: задержка обновления при изменении API по сравнению с разрешением в реальном времени Context7.
7. **Риск неинтеграции**: Низкий — существующие руководства (Context7, `@url`, grepai) подходят для большинства случаев использования
