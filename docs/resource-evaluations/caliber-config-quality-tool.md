## 📄 Резюме содержания

- **Caliber** — это инструмент CLI, который оценивает, генерирует и постоянно синхронизирует конфигурации агентов ИИ (серверы CLAUDE.md, MCP) с базой кода. Нулевая установка: `npx @rely-ai/caliber score`
- Подсчет очков является 100% локальным и детерминированным: 6 категорий (Существование 25 + Качество 25 + Заземление 20 + Точность 15 + Свежесть 10 + Бонус 7), 61 проверка, нет вызовов LLM, нет сетевых запросов.
- Обнаружение дрейфа основано на git: SHA256 (дерево файлов + грязные файлы) + кеш указателя git HEAD, поддерживает `caliber refresh` для автоматического обновления документов после изменений кода.
- Модуль обучения фиксирует события инструмента с помощью перехватчиков → JSONL → инкрементный анализ LLM → `CALIBER_LEARNINGS.md` с дедупликацией сходства 70 %.
- **GitHub: 65 звезд (сейчас 1223 по состоянию на 28 июля 2026 г.), 12 форков, созданы 10 марта 2026 г. (13 дней назад), MIT, TypeScript/Node.js ≥20**

## 🔬 Техника анализа (полный исходный код после аудита)

Полный аудит исходного кода проведен на клоне [Caliber](https://github.com/rely-ai-org/caliber). Основные выводы:

### Система подсчета очков

**6 категорий, 61 проверка, ~102 балла, нормализованных до 100:**

| Категория | Макс | Метод |
|----------|-----|--------|
| Существование | 25 | `existsSync()` проверяет CLAUDE.md, навыки, MCP, правила |
| Качество | 25 | Парсинг контента: блоки кода, бюджет токена, коэффициент конкретности, обнаружение дубликатов |
| Заземление | 20 | % проекта dirs/files, упомянутого в конфиге (2-уровневое сканирование) |
| Точность | 15 | Проверка пути + git коммиты с момента последнего обновления конфигурации |
| Свежесть | 10 | Устаревание на основе Git + обнаружение секретов (13 шаблонов регулярных выражений) |
| Бонус | 7 | Зацепки, AGENTS.md, изученный контент, внешние источники |

Оценка является гибридной: наличие файла (40%), контент-анализ (50%), эвристика git (10%). Вся логика в `src/scoring/checks/*.ts`. Извлекается как отдельная библиотека.

### Обнаружение дрейфа

Три независимых сигнала:
1. Подпись **Tree:** `SHA256(sorted file tree + git dirty files)` — любой add/remove/rename вызывает аннулирование
2. **Git Указатель HEAD: кеш** действителен только при одном и том же коммите
3. **Git diff:** `git diff <lastSha>..HEAD` (только код, исключая CLAUDE.md/skills из рассмотрения дрейфа)

Кэш хранится по адресу `.caliber/cache/fingerprint.json`. Устарело, если версия не соответствует, изменение HEAD или несоответствие подписи.

### Учебный модуль

События, зафиксированные с помощью перехватчиков в `.caliber/learning/session.jsonl` → инкрементальный анализ LLM каждые 50 событий → `CALIBER_LEARNINGS.md` (формат маркера: `**[pattern|gotcha|fix|correction]** text`). Дедупликация при 70 % нормализованном сходстве текста. Отслеживание рентабельности инвестиций позволяет сравнивать показатели неудач с обучением и без него в ходе разных сеансов.

### GitHub Действие

`github-action/action.yml` + `index.js` (всего 266 строк). Входы: `agent`, `fail-below`, `comment`, `auto-refresh`. Публикует PR-комментарий с оценкой, оценкой, дельтой и базовой ветвью. Не проходит CI, если оценка < `fail-below`. Детерминированный — LLM не вызывает самого действия.

### Примечание по безопасности

Caliber имеет доступ на запись к CLAUDE.md в режиме непрерывной синхронизации (`caliber watch`, `caliber refresh`). Тот же класс риска, что и у Packmind: скомпрометированная конфигурация или вредоносный источник могут передавать инструкции сеансам ИИ. Относитесь к выходным данным `caliber init` с той же дисциплиной проверки, что и к обновлению сборника инструкций Packmind.

## 🔥 Челлендж (технический писатель)

Оценка 3/5 подтверждена. Ключевые поднятые вопросы:

- **Непрозрачность рубрики оценки**: 100-балльная шкала является детерминированной, но недокументированной с точки зрения пользователя (нет SCORING.md). Оценка 74 говорит вам меньше, чем следовало бы, не зная рубрики.
- **Проблема глубины нескольких инструментов**: Поддержка 4 инструментов (Claude Code + Курсор + Codex + Copilot) рискует создать адекватные в целом конфигурации, а не глубоко специфичные для Claude Code.
- **Риск доступа к записи недооценен в README**: Поверхность безопасности `caliber watch` (непрерывная запись в CLAUDE.md) заслуживает явного упоминания.
- **Размещение в руководстве**: НЕ должно располагаться рядом с AIBlueprint (строительными лесами) — другая рабочая категория. Относится к отдельному подразделу «Качество конфигурации», объединяющему «дрейф одного проекта» (Caliber) и «распределение в масштабе организации» (Packmind).
- **Риск неинтеграции**: от низкого до умеренного. Пробел в обнаружении дрейфа реален, но не критичен для большинства пользователей, начинающих с нуля.
