## Краткое содержание

Сообщение в социальной сети, в котором утверждается, что Claude Code имеет «скрытую функцию» для параллельного выполнения агентов, использования агрессивного маркетингового языка и создания искусственного FOMO. В сообщении отсутствуют цитаты, а публично задокументированные функции представлены как «секреты».

---

## Краткое содержание

- **Основное утверждение**: «Скрытая функция» позволяет автоматически создавать параллельные агенты, например «команду».
- **Описание механизма**: Флаг функции, автоматически создающий агентов для каждой задачи.
- **Tone**: Маркетинговая гипербола («вернуть интернет», «tu pass à côté d'un truc énorme»)
- **Призыв к действию**: «Найди флаг с недоумением»
- **Цитированные источники**: Нет

## Подсчет очков и решение

### Оценка: 1/5 ❌ - ОТКЛОНИТЬ

**Rationale:**

1. **Фундаментальная нечестность**: общедоступные функции представлены как «скрытые».
2. **FOMO создание**: Манипулятивный язык, созданный для создания срочности
3. **Нет источников**: Нет официальных цитат = огромный красный флаг
4. **Противоречит руководящим принципам**: «Точность важнее маркетинга» (строка RULES.md ~350)
5. **Нулевая документальная ценность**: Все правдивые факты уже в CHANGELOG

**Почему отказ важен:**

В этом руководстве содержится более 15 тысяч строк и более 66 шаблонов, созданных на основе тщательного отбора источников. **Один некачественный источник может подорвать доверие.** Читатели должны доверять 100% цитируемых источников.
