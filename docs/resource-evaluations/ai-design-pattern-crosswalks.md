# Переходы по шаблонам проектирования ИИ (от классических шаблонов к шаблонам агентов)

**Отзыв**: 27 октября 2026 г. **Общая оценка**: 3/5. Выборочное использование: укажите лучшие переходы в качестве источников для страницы, на которой классические шаблоны программного обеспечения сочетаются с функциями Claude Code, и пометьте каждую пару Claude Code, которая ни в одном источнике не указана как собственное прочтение руководства.

## Ограничения метода и доказательств

- Каждый источник был открыт в его источнике (выгрузка страницы, клонирование репозитория или чтение страницы arXiv), если в таблице не указано иное.
- Две записи arXiv были проверены только с помощью фрагмента поиска. Их оценка является предварительной.
- Только AgentPatterns.ai называет механизмы Claude Code в соответствии с классическим шаблоном сопоставления: Observer для перехватчиков и Facade для CLAUDE.md. Ни один открытый исходный код не сопоставляет шаблоны GoF или EIP с субагентами, навыками или MCP, поэтому эти строки представляют собой синтез, поддерживаемый только там, где совпадают два или более независимых перекрестных перехода.
- Репозитории, полученные из утечек по этой теме, были исключены и не цитируются. Один репозиторий, в котором цитируются внутренние исходные файлы Claude Code без публичного происхождения, был удален из этой таблицы 28 октября 2026 г.
- Подсчет звезд не проверялся повторно и не используется для подсчета очков.

## Где сходятся пешеходные переходы

Каждую строку поддерживают как минимум два независимых источника. Это строки-кандидаты для руководства:

| Классический узор | Аналог агента | Источники |
|---|---|---|
| наблюдатель | Перехватывает вызовы инструментов | Agentpatterns.ai, aicodingpatterns.com |
| Цепочка ответственности | Крюк и разрешительные конвейеры | Agentpatterns.ai, AHEP |
| сувенир | Контрольные точки и перемотка назад | Agentpatterns.ai, AHEP |
| Композитный, Медиатор | Оркестратор и субагенты | Agentpatterns.ai, aicodingpatterns.com |
| Фабрика | Создание субагента | Agentpatterns.ai, aicodingpatterns.com |
| Стратегия | Маршрутизация и выбор модели | Agentpatterns.ai, aicodingpatterns.com |
| Автоматический выключатель | Ограничения на повороты и петли | Agentpatterns.ai, aicodingpatterns.com |
| Сага | Компенсирующие действия | Agentpatterns.ai, aicodingpatterns.com, arXiv 2605.20173 |
| Адаптер | Инструмент и адаптеры MCP | aicodingpatterns.com, arXiv 2601.19752 |

Фасад CLAUDE.md опирается на один источник и остается предложением. Observer для хуков и других якорей Claude Code — это чтение руководства по этим сопоставлениям, поскольку ни в одном из открытых источников они не указаны для Claude Code.

## Где они не согласны

Разногласия стоит продемонстрировать следующим образом:

- Декоратор: ограждения в одном источнике, промежуточное ПО внедрения контекста в другом.
- Шаблонный метод: системное приглашение в одном источнике, фиксированный скелет агентского цикла в другом.
- Цепочка ответственности: конвейер перехватчиков в одном источнике, связанные агенты в другом.
- Синглтон: реестр инструментов в одном источнике, собственный шаблон в AHEP.

## Решение

Используйте пешеходные переходы в качестве цитируемых источников и не копируйте никакие карточки. Создайте таблицу руководства на основе согласованных выше строк, отметьте как таковые строки с одним источником и собственным чтением и добавьте привязку Claude Code из официальной документации. Используйте таблицу EIP roanbrasil и карты распределенных шаблонов kage-ai в качестве надежных источников для строк EIP и устойчивости. Относитесь к репозиторию go4 как к словарю, а не как к пешеходному переходу.

Прочтите Барбаста и др. документ, прежде чем цитировать какой-либо из его шаблонов, и тело arXiv 2601.19752, прежде чем полагаться на ссылки GoF. Общий балл 3/5 отражает полезную, но молодую тему: большинство источников датированы 2026 годом, и ни один из них не был проверен на предмет поведения Claude Code. Эта оценка не устанавливает, что какое-либо сочетание является правильным, а только то, что источники предлагают его.
