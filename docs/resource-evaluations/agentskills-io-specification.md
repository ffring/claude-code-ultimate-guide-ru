# Оценка: Agentskills.io — открытая спецификация навыков агента.

**Дата**: 2026-02-01
**Источник**: [agentskills.io](https://agentskills.io/home) | [GitHub: agentskills/agentskills](https://github.com/agentskills/agentskills) (8,2 тыс. звезд, изменено 23 547 или 28/07/2026) | [GitHub: anthropics/skills](https://github.com/anthropics/skills) (60,1 тыс. звезд, отключено 164 580 или 28/07/2026)
**Maintainer**: Anthropic (открытая разработка, вклад сообщества)
**Type**: открытая спецификация + эталонная реализация + официальная библиотека навыков.
**License**: Apache 2.0 (спецификация + открытые навыки), доступный исходный код (навыки документирования)

## Резюме содержания

- **Форма спецификации** для навыков агента: формат SKILL.md, заголовок YAML, правила именования, структура каталогов, модель прогрессивного раскрытия
- **26+ поддерживаемых платформ**: Claude Code, Claude.ai, GitHub, Cursor, VS Code, OpenAI Codex, Gemini CLI, Goose, Roo Code, Amp, Spring AI, Databricks, Factory, Mistral Vibe, TRAE, Маг огня, Летта и т. д.
- **anthropics/skills** (60,1 тыс. звезд): официальное хранилище Anthropic с примерами навыков (документы DOCX/PDF/PPTX/XLSX, Creative, dev, Enterprise) + плагин интеграции Claude Code
- **skills-ref CLI**: официальный документ проверки и генерации XML-запросов (`skills-ref validate`, `skills-ref to-prompt`)
- **Руководство по интеграции**: документация, позволяющая расширить навыки поддержки без импорта агента (на основе файловой системы или инструмента)

## Оценка соответствия: 4/5

**Justification**:

1. **Большой пробел подтверждает**: Руководство документирует навыки, соответствующие функции Claude Code, без упоминания о том, что это **стандартная внешняя кросс-платформа**, обслуживаемая Anthropic. Это существенное упущение для руководства, которое является ссылкой.
2. **60.1K звезд**: `anthropics/skills` - это репозиторий Anthropic со звездой. Руководство по упоминанию на проходе (`npx add-skill anthropics/skills` на 2 линиях) без документов, содержания и расширения.
3. **agentskills.io отсутствует**: Форма спецификации (правила именования, постепенное раскрытие информации, руководство по интеграции) является нулевой частью данного руководства. Это настоящий источник информации, содержащий документальное руководство.
4. **Interoperabilite = аргумент poids**: Пользователь, «ваши навыки Claude Code, функционирующие в курсоре, VS Code, Codex, Gemini CLI», представляет собой ценную информацию.
5. **Pas un 5/5 car**: Документальное руководство, демонстрирующее лучшие навыки для повседневного использования Claude Code. Типичный пользователь не является формой использования навыков. Le Gap est Conceptuel (manque de contexte) плюс que pratique (manque de практические рекомендации).

## Вызов (автокритика)

### Аргументы для оценки +1 (5/5):
- Руководство притворяется, что ссылка на Лос-Анджелес Claude Code. Не упоминайте, что официальная функция, предназначенная для более чем 800 линий, вызывает смущение.
- 60,1 тыс. звезд = это не нишевый проект. Это репозиторий Anthropic более популярный.
- Функциональная совместимость (навыки портативных устройств для более чем 26 устройств) является главным аргументом в пользу завершения руководства по скорости.
- Документы Les champs `context` и `agent` в руководстве не являются PAS в официальной спецификации — потенциальный источник путаницы для лекторов.

### Аргументы для оценки -1 (3/5):
- Пользователю Claude Code больше не нужно ничего делать по форме. Он должен создать навык, который идет в поход.
- Документальное руководство по практическому рабочему процессу.
- Agentskills.io — это спецификация для разработчиков агентов, предназначенная для конечных пользователей.
- 60,1 тыс. звезд anthropics/skills с гонфами на начальном этапе — множество пассивных звездочетов.

### Вердикт по вызову:
Оценка 4/5 в обслуживании. Аргумент «Спецификация для разработчиков» действителен больше, чем руководство по внутренней архитектуре (guide/core/architecture.md), перехватчики, протокол MCP — он не ограничивается «инструкциями пользователя». Отсутствие официальной спецификации - это пробел, критика за повседневное использование больше всего значит для полноты. Функциональное взаимодействие и anthropics/skills заслуживают упоминания.

### Очки манки:
- Модель угроз **SafeDep** (safedep.io/agent-skills-threat-model) документирует уязвимости в соответствии со спецификациями (8–14 % от навыков). Установите соответствующий угол для заливки `guide/security/security-hardening.md`.
- Блог Anthropic [«Оснащение агентов для реального мира»](https://anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills) является основным источником ссылок.
- Claude.ai поддерживает все направления навыков (просто Claude Code) — потенциал совместной работы.

### Риски неинтеграции:
**Moderes.** Un lecteur decouvrant la spec Agentskills.io реализует то, что руководство описывает навыки, которые используются в Claude Code изолированно, а также те, что находятся в перекрестной форме. Perte de credabilite sur la completude.
