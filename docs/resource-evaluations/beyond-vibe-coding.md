## Краткое содержание

Комплексная книга, которая поможет разработчикам перейти от «вибрационного кодирования» (быстрого прототипирования с помощью ИИ без глубокого понимания) к профессиональным практикам проектирования с использованием ИИ. Опубликованное O'Reilly, оно охватывает несколько инструментов кодирования искусственного интеллекта (Claude Code, Cursor, GitHub Copilot, Gemini CLI) и практические стратегии для разработки, готовой к производству.

**Шестиглавая структура**:
1. **Intro и Spectrum**: определение Vibe-кодирования и разработки с помощью искусственного интеллекта
2. **Принципы и лучшие практики**: контекст, доверие, планирование, документация
3. **Продвинутые методы**: Быстрое проектирование, контекстное проектирование, MCP
4. **CLI Агенты и оркестраторы**: инструменты на базе терминалов и многоагентные системы
5. **Разработка, готовая к производству**: безопасность, тестирование, интеграция SDLC
6. **Будущие тенденции**: автономные агенты, визуальное развитие, модели рассуждения

**Ключевые рамки**:
- **Проблема 70%**: ИИ ускоряет 70% разработки, последние 30% требуют инженерной строгости
- **Контекстное проектирование как метафора ОС**: Контекстное окно = ОЗУ ЦП (динамическое управление loading/memory)
- **Разработка на основе критики**: преобразование отзывов о проверке кода в подсказки ИИ
- **MCP как «USB-C для AI».**: стандартизированный протокол для интеграции инструментов.
- **Двумерная структура**: Технические навыки × уровни абстракции ИИ

**Низкое воздействие**:
1. Уникальный технический контент не потерян (90% уже задокументировано)
2. Пробелы (разработка на основе критики, краткие подсказки) лучше устранять через первоисточники.
3. Книга = синтез, в руководстве уже есть более подробное первичное освещение.

**Среднее воздействие**:
1. Отсутствует внешняя проверка (О'Рейли = сигнал авторитета)
2. Пользователи, знакомые с книгой, могут не найти перекрестных ссылок.
3. Педагогические метафоры («Контекст как оперативная память») имеют обучающее значение.

**Decision**: минимальная интеграция (отслеживание упоминаний + перекрестные ссылки) = сохраняет ценность без дублирования.
