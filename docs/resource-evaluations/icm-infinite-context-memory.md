## Краткое содержание

ICM — это сервер постоянной памяти MCP, опубликованный организацией rtk-ai, той же организацией, что и RTK (Rust Token Killer), в создание которой вносит свой вклад автор руководства. Он обеспечивает двойную архитектуру памяти: «Воспоминания» (эпизодический, настраиваемый распад) и «Мемуары» (постоянный граф знаний с 9 типизированными типами отношений). Распространяется как один двоичный файл Rust без внешних зависимостей, устанавливается через Homebrew.

### Ключевые моменты

- Один двоичный файл Rust, SQLite, нулевая депс — установка Homebrew
- Двойная архитектура: эпизодический распад + постоянный граф знаний в одном инструменте
- Гибридный поиск: BM25 30% + сходство векторов 70%
- Автоматическая дедупликация (блокировано сходство >85%)
- Автоматическое извлечение: перехваты шаблонов, предварительное уплотнение, запуск сеанса.
- Поддерживает 14 editors/clients (Claude Code, Cursor, VS Code, Windsurf, Zed, Amp, Cline и т. д.)
- 52 звезды по состоянию на март 2026 г. (теперь 508 по состоянию на 28 июля 2026 г.), 55 коммитов.
- Лицензия: доступен исходный код (бесплатно для отдельных лиц и команд до 20 человек; выше требуется корпоративная лицензия)

## Тесты

Все приведенные ниже тесты **предоставлены поставщиком rtk-ai**: независимая проверка не подтверждена.

**Производительность хранилища (1000 операций, встраивания 384d)**:
- Сохранение (без вложений): 34,2 мкс/опер.
- Сохранение (с встраиваниями): 51,6 мкс/оп
- Полнотекстовый поиск FTS5: 46,6 мкс/оп
- Векторный поиск (KNN): 590,0 мкс/оп
- Гибридный поиск: 951,1 мкс/оп

**Эффективность агента (модель Haiku, многосессионная)**:
- Сеанс 2: на 29 % меньше поворотов, на 32 % меньше входного контекста, на 17 % меньше затрат.
- Сеанс 3: на 40 % меньше поворотов, на 44 % меньше контекста, на 22 % меньше затрат.

**Сохранение знаний (10 вопросов)**:
- Без ИКМ: 5%
- С ICM: 68%

Примечание. В тесте на сохранение знаний используется выборка из 10 вопросов по Haiku — слишком узкая для обобщения.
