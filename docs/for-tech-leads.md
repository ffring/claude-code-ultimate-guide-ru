# Claude Code: Для технических руководителей и технических менеджеров.

> Вы, наверное, слышали, как ваши разработчики говорили о Claude Code. Возможно, кто-то уже использует его. Эта страница предназначена для вас — человека, ответственного за обеспечение единообразия, безопасности и масштабируемости внедрения в рамках всей команды.

---

## Основная проблема

Предоставленный самому себе, каждый разработчик создает свою собственную установку Claude Code. Разные файлы CLAUDE.md, разные конфигурации разрешений, никаких общих перехватчиков, никакой наблюдаемости. Рост производительности реален, но хаотичен, а поверхность безопасности бесконтрольно растет.

Команда с общей конфигурацией в 3–5 раз эффективнее, чем те же разработчики, работающие с отдельными конфигурациями.

## 3 дела, которые нужно сделать на этой неделе

**1. Версия вашего CLAUDE.md в репозитории**
Создайте `CLAUDE.md` в корне вашего основного репозитория. Это автоматически распространяется на всех членов команды. Начните с соглашений по кодированию, архитектурных решений и правил «никогда не делайте X».

**2. Определите одного чемпиона**
Один инженер, который уже эффективно работает с Claude Code. Дайте им время задокументировать свою настройку и провести часовое командное занятие.

**3. Добавьте один хук безопасности**
Минимум: предварительный инструмент, который блокирует запись в файлы `.env` и пути `**/secrets/**`. Настройка занимает 10 минут, охватывает реальный вектор угроз.

```bash
# Example: hooks/block-sensitive-files.sh
if [[ "$TOOL_INPUT_PATH" =~ \.env$|secrets/ ]]; then
  echo "BLOCKED: sensitive file path"
  exit 2
fi
```

Полный набор см. в [Guide Ch.7.4: Защитные хуки](../guide/ultimate-guide.md#74-security-hooks).

## Обзор состояния безопасности

В этом руководстве поддерживается общедоступная база данных угроз **only для Claude Code**: каталогизировано 15 уязвимостей и 655 вредоносных навыков. Ключевые риски для команд:

- **Быстрое внедрение** через ненадежное содержимое файла или серверы MCP
- **Чрезмерно разрешительные настройки**: `allowedTools: ["*"]` в производстве
- **Непроверенные серверы MCP**: относитесь к ним как к пакетам npm (риск цепочки поставок)
- **Отсутствует контрольный журнал**: кто, что сделал, когда

Полный охват в WP03: Безопасность и WP06: Конфиденциальность *(технические документы, скоро появятся)*.

## Обучение вашей команды

Если вы хотите структурированное обучение, а не самообучение:

- **Brown Bag Обед, беседа или панельная дискуссия (1–3 часа, бесплатно)**: вводная сессия, живая демонстрация или слот для докладчика. Сделано ради удовольствия: делимся, бросаем вызов, создаем сеть контактов.
- **Аудит конфигурации**: проверьте текущую настройку на соответствие передовым практикам безопасности и производительности.
- **Формирование команды (1-2 дня)**: практические занятия, ваша кодовая база, ваши рабочие процессы. Не то, что я активно ищу, но открыт для правильного разговора.
