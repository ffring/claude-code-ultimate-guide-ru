# Распределительные активы

Эти ресурсы превращают одну часть Ultimate Guide Claude Code в ограниченный формат обучения. Публикация остается отдельной от производства: готовый файл по-прежнему нуждается в утверждении, назначении и датированной записи канала.

| Объект | Состояние | Исходные страницы | Запись публикации |
| --- | --- | --- | --- |
| [Слайды с обучающими маршрутами](claude-code-learning-path-slides.pptx) | Готово, визуально проверено, тест на перелив пройден. | [Путь обучения](../../guide/learning-path/README.md), [Лучшее из N](../../guide/workflows/best-of-n.md), [Использование компьютера](../../guide/core/computer-use.md) | [`slides-en`](../../machine-readable/distribution-channels.yaml) |
| [Быстровыигрышная видеосерия](quick-win-video-series.md) | Бюллетени готовы, видео не записано | [Указатель рабочего процесса](../../guide/workflows/README.md), [Навыки пути обучения](../../examples/skills/learning-path/SKILL.md) | [`youtube-fr`](../../machine-readable/distribution-channels.yaml) |

Слайды содержат блок `[Sources]` в примечаниях докладчика к каждому слайду. В обзорах видео указаны страница руководства, наблюдаемая проверка, указанное место назначения и источник исследования для каждого эпизода.

Для живого семинара или записи сопутствующий проект [Proofpack](../../examples/learning-project/README.md) обеспечивает непрерывные упражнения в рамках процесса обучения.

## До публикации

1. Восстановите или повторно откройте актив и проверьте окончательный результат.
2. Убедитесь, что ссылки руководства по-прежнему разрешаются в текущей версии.
3. Получите одобрение для указанного канала.
4. Измените статус канала в [`distribution-channels.yaml`](../../machine-readable/distribution-channels.yaml).
5. Запишите URL-адрес доказательства размещения и дату проверки.
6. Запустите 30-дневное окно измерения, определенное рабочим процессом распределения [](../workflows/guide-distribution.md).

Китайская публикация остается заблокированной до тех пор, пока квалифицированный рецензент не проверит локализованную копию. Реестр переводов [](../../machine-readable/translations.json) фиксирует право собственности и актуальность; он не дает полномочий на публикацию.
