# Claude Code: Для менеджеров по продуктам и дизайнеров продуктов.

> Вам не нужно становиться разработчиком, чтобы получить выгоду от Claude Code. Но понимание того, что он делает — и что он может сделать для вас напрямую — меняет то, как вы работаете со своей командой и что вы можете реализовать самостоятельно.

---

## Два разных варианта использования

**1. Вы работаете вместе с разработчиками, которые используют Claude Code**.
Понимание этого инструмента поможет вам лучше писать спецификации, быстрее разблокировать и вести более обоснованные разговоры о усилиях и компромиссах.

**2. Вы хотите использовать его самостоятельно**
«Кодирование Vibe» реально. Менеджеры по проектам все чаще создают прототипы функций, пишут сценарии и анализируют данные без участия разработчика. Claude Code делает это доступным, если вы хотите изучить основы.

---

## Если вы работаете с разработчиками, использующими Claude Code

### Что изменится в вашем рабочем процессе

**Specs становятся контекстом**: ваши PRD, критерии приемки и крайние случаи могут храниться в файле `CLAUDE.md` в корне ветки функций. Экземпляр разработчика Claude Code считывает его автоматически. Лучшие характеристики = меньше проблем.

**Вы можете просмотреть работу с помощью ИИ.**: Когда разработчик говорит: «Claude написал большую часть этого», вы можете попросить Claude Code объяснить, что было сгенерировано, почему и каковы компромиссы. Чтение кода не требуется.

**Сдвиг ожиданий скорости**: Шаблон, тесты, документация, миграции: при использовании Claude Code на это уходит гораздо меньше времени. Если ваши оценки спринта все еще отражают усилия до появления ИИ, они неверны.

### Единственное, что стоит прочитать

WP05: Развертывание с помощью команды *(технический документ, скоро появится)* — в частности, раздел этапов внедрения. Понимание схемы развертывания «Чемпион» → «Пилот» → «Команда» поможет вам планировать выпуски функций, которые зависят от продуктивности команды с инструментами ИИ.

## Если вы хотите использовать Claude Code самостоятельно

### Что можно сделать без опыта программирования

- **Прототипируйте функцию**: опишите, что вы хотите, Claude Code создаст рабочую демонстрацию
- **Запросите данные**: напишите сценарии SQL или Python, описав то, что вам нужно, простым языком.
- **Автоматизация повторяющихся задач**: Excel → CSV → отформатированный отчет без обращения к разработчику
- **Сгенерировать тестовые примеры**: вставить критерии приемки, получить набор тестов
- **Понять существующий код**: «Что делает эта функция?» работает лучше, чем Stack Overflow для вашей кодовой базы

### Что вам действительно нужно, чтобы начать

1. Установка Claude Code (5 мин) → [Руководство, гл.1.1](../guide/ultimate-guide.md#11-installation)
2. Изучите формулу одной подсказки → [Руководство, гл.2.8: Структурированные подсказки](../guide/ultimate-guide.md#28-structured-prompting-with-xml-tags)
3. Поймите, как придать ему контекст → [Руководство, гл.3.1: CLAUDE.md](../guide/ultimate-guide.md#31-memory-files-claudemd)

Это первая неделя.

### Управление кривой обучения

WP09: Обучение с помощью искусственного интеллекта (протокол UVAL) *(информационный документ, скоро появится)* был написан специально для этого. Структура UVAL (Понять/Проверить/Применить/Изучить) представляет собой структурированный подход к формированию реальной компетентности, а не копирование результатов, которые вы не понимаете.

Ключевая идея: **долг понимания** — это риск. Использование Claude Code для поставки функций, которые вы не понимаете, создает хрупкость. Протокол помогает вам сохранять контроль.

## Что НЕ для вас в этом руководстве

Это руководство предназначено в первую очередь для разработчиков. Большинство глав 4–9 («Агенты», «Навыки», «Хуки», MCP, «Продвинутые шаблоны») будут для вас неактуальны, если вы не углубитесь в них.

Для общей продуктивности Claude (письмо, исследования, анализ, подготовка к встречам):
→ **[Claude Cowork Руководство](https://github.com/FlorianBruniaux/claude-cowork-guide)**: создано специально для неразработчиков.
