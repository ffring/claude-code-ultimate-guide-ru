# Обновите отслеживание выпуска Claude Code руководства.

Канонический навык: `.claude/skills/source-command-update-infos-release/`. Копия Codex создается `scripts/sync-release-tracking-skill.py`; отредактируйте канонический источник и создайте его заново.

1. Устраните корень Claude Code Ultimate Guide и запрошенную пользователем область действия: только отслеживание CLI или явное изменение версии руководства. Выполняется, когда известен репозиторий и выбранный вариант.
2. Читать `.claude/commands/update-infos-release.md` из корня гайда полностью вместе с `docs/workflows/releases-tracking.md` и `docs/workflows/landing-sync.md`. Этим файлам принадлежит рабочий процесс и разделение исходного кода RSS. Сохраните имя продукта Claude Code и фактические пути к репозиторию на любом хосте. Готово, когда определены текущий рабочий процесс и разрешенные изменения.
3. Выполнять только авторизованную ветку. Подготовка или локальная проверка не разрешают фиксацию, отправку, публикацию или развертывание пакета; получить недостающее разрешение до наступления этих последствий. Сообщайте о точных изменениях, тестах и ​​неразрешенных проверках. Выполняется, когда результат проверки области действия проверен или условие блокировки является явным.
