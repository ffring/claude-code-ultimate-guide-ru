# Делегируйте обновления базы данных угроз AgentSec

Родной навык `update-threat-db` на Claude и Codex читает это делегирование.

AgentSec Triage — это канонический технический источник доказательств угроз, датированный
фишки, входы детекторов и канал общественной безопасности. Не исследуйте и не редактируйте

## Найдите АгентСек

Используйте `AGENTSEC_REPO`, если он уже установлен. В противном случае ищите брата или сестру
оформить заказ `../agentsec-triage` из корня этого репозитория. Остановитесь, если ни один путь не
доступен или если он не содержит все эти файлы:

- `AGENTS.md`
- `.claude/commands/update-threat-db.md`
- `data/intelligence/sources.yaml`
- `data/intelligence/events.yaml`
- `data/threat-db.yaml`

Не клонируйте, не извлекайте, не устанавливайте, не публикуйте и не отправляйте без явного разрешения.

## Выполните канонический рабочий процесс

Прочитайте `AGENTS.md` AgentSec, затем выполните его.
`.claude/commands/update-threat-db.md` из репозитория AgentSec. АгентСек
владеет обзором источников, неопределенностью, охватом детекторов, регрессионными тестами, сгенерированными
артефакты и граница публикации.

После того как AgentSec пройдет локально, синхронизируйте созданный канал с этим руководством.
и десант с `scripts/sync_security_feed.py --write`. Запустите то же самое
команду с `--check`, затем запустите:

```bash
python3 scripts/test-check-agentsec-security-feed.py
python3 scripts/check-agentsec-security-feed.py \
  --agentsec-feed "$AGENTSEC_REPO/exports/security-feed.v1.json"
```

Руководство временно сохраняет `examples/commands/resources/threat-db.yaml`, потому что
`/security-check` и `/security-audit` все еще потребляют его. Это совместимость
потребитель, а не место для начала нового обновления разведывательной информации.

После обновления базы данных совместимости обновите доступную для поиска целевую страницу.
каталог, а также его канал. От корневой площадки пройдите по фактическому руководству.
путь оформления заказа (особенно при проверке изолированных проверок):

```bash
node scripts/sync-security-catalog.mjs --write --guide-root /path/to/claude-code-ultimate-guide
node scripts/sync-security-catalog.mjs --check --guide-root /path/to/claude-code-ultimate-guide
node --test src/data/agentsec-security-feed.test.ts src/data/agentsec-feed-sync.test.ts
```

В каталоге хранятся записи исторических справочников, которых может еще не быть в AgentSec.
Сообщайте о его количестве отдельно от количества канонических фидов. Не продвигайте эти
исторические записи в AgentSec без проверки источника.

## Последующие действия руководства

Только после проверки записи AgentSec:

- добавить контекст, обращенный к читателю, в `guide/security/security-hardening.md`, когда
  обнаружение существенных изменений руководства;
- обновить базу данных совместимости, не заявляя о покрытии детекторов, которое
  AgentSec не реализуется;
- обновить `CHANGELOG.md` под `[Unreleased]`;
- сохраняйте зеркало канала AgentSec в байтах, идентичном его каноническому артефакту.

Сообщайте отдельно о проверке AgentSec, руководстве и посадке. Государство фиксирует, толкает,
тег и статус публикации явно.
