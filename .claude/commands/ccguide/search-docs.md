---
description: "Поиск в официальной документации Anthropic Claude Code по ключевому слову"
---

Используйте инструмент `search_official_docs` MCP с запросом: $ARGUMENTS.

Если запрос не задан, спросите пользователя, что он хочет найти.

Ограничение по умолчанию: 5 результатов.

Представьте каждый результат с помощью:
- Название раздела
- URL-адрес источника (воспроизвести дословно)
- Отрывок, показывающий соответствующий контент

Если моментальный снимок не существует, попросите пользователя сначала запустить /ccguide:init-docs.
