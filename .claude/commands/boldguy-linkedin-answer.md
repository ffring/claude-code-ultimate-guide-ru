# Ответ смелого парня на LinkedIn

Напишите комментарий в LinkedIn в ответ на сообщение со ссылкой на соответствующие разделы окончательного руководства Claude Code, написанный голосом Флориана «Flow» Брюньо без маркеров AI.

## Использование

```
/boldguy-linkedin-answer https://www.linkedin.com/posts/...
```

## Шаг 1. Прочтите публикацию в LinkedIn.

1. Разберите `$ARGUMENTS` на предмет URL-адреса LinkedIn. Если отсутствует, спросите: «Quel post LinkedIn?»
2. Получить содержимое сообщения через WebFetch
3. Выдержка: имя автора, основной аргумент, ключевые моменты, тон.

## Шаг 2. Определите соответствующие разделы руководства

Найдите в руководстве контент, связанный с темой публикации:

1. Найдите в `guide/ultimate-guide.md` и других файлах `guide/*.md` ключевые слова из сообщения.
2. Найдите соответствующие разделы в `machine-readable/reference.yaml`.
3. Проверьте, существует ли специальная целевая страница (например, `/learning`, `/quiz`).
4. Расставьте приоритеты разделов, в которых руководство представляет уникальную ценность (протоколы, инструменты, данные, методология).

**Результат этого шага**: список из 2–4 соответствующих элементов, на которые можно ссылаться (название раздела, ключевая концепция, целевой URL, если применимо).

## Шаг 3. Напишите комментарий

Напишите комментарий в LinkedIn, следуя этим правилам:

### Языковое правило (КРИТИЧЕСКОЕ)
- **Укажите язык публикации.**: если запись на английском языке, напишите комментарий на английском языке; если на французском, пишите по-французски.
- Никогда не смешивайте языки в одном комментарии.

### Голосовые правила (голос Флориана, а НЕ команды)
- Всегда «у меня» / «я» — никогда «у нас» / «мы» (Флориан работает над гидом один)
- Поза: «Я делюсь тем, что узнаю» — никогда «Я учу тебя».
- Практик, а не гуру
- По-французски: «j'ai» / «je» — никогда «on a» / «nous avons».

### Правила платформы (комментарий LinkedIn)
- **Имя** напрямую с автором сообщения (обучение на французском языке, имя на английском языке)
- Разговорный, как обсуждение в коридоре
- **Макс. 1200 символов** (жесткий предел)
- Ноль хэштегов
- Ноль смайлов (или максимум 1, если это действительно оправдано)
- Ссылка только в случае прямой добавленной стоимости (раздел руководства, целевая страница)

### Структура контента
```
[Validate/acknowledge the author's point — 1 sentence]

[Connect to guide content — what I've documented, what the data says]

[1-2 concrete elements: protocol, metric, tool, methodology]

[Closing: link to relevant guide/landing section OR conversational question]
```

### Что включить
- Конкретные элементы руководства: протоколы (UVAL и т. д.), инструменты (`--learn` и т. д.), методологии.
- Реальные данные, если они доступны (академические исследования, упомянутые в руководстве, измеренные показатели)
- Правильный URL-адрес landing/guide, чтобы читатель мог копнуть глубже.

### Связывающая стратегия

### Чего следует избегать
- Перечисление функций, таких как страница продукта
- Маркетинговый язык (см. vocabulary-rules.md)
- Приманка для помолвки, FOMO, загадочная коробка
- Изобретение показателей или продолжительности, не описанных в руководстве.
- Перепродажа руководства

## Шаг 4. Пропуск против ИИ

Запустите навык /boldguy-adapt на драфте, чтобы удалить маркеры ИИ.

В частности, проверьте:

### Контрольный список (каждый пункт должен пройти проверку)
- [ ] Ноль длинного тире (`—`) — используйте запятую, круглые скобки или реструктуризацию.
- [ ] Без стаккато (3+ предложения до 5 слов подряд)
- [ ] «C'est pas X. C'est Y». шаблон максимум 1 раз, с запятой, а не точкой
- [ ] Разная длина предложений в каждом абзаце
- [ ] Никакой чрезмерной заключительной фразы symmetric/perfect.
- [ ] Параграфы связывают идеи (не 1 идея = 1 изолированный абзац)
- [ ] Никакого жирного параллелизма маркеров (например, 4x «Un **X** qui...»)
- [ ] Нет стрелок `→` в списках (разговорный режим, а не слайд-панель)

### Проверка ритма
Комментарий должен читаться как разговор практикующих в кафе:
- Смешайте короткие и длинные предложения в одном абзаце
- Идеи перетекают друг в друга, а не складываются изолированно.
- Завершение – естественное (вопрос или простое утверждение), а не лозунг.

## Шаг 5: Подсчет символов и окончательная проверка

1. Подсчет символов (должно быть <= 1200)
2. Если превышен лимит: вырежьте наименее существенный элемент, объедините предложения, сократите формулировку.
3. Если значительно меньше (~800): хорошо, не дополняйте.

### Окончательный контрольный список
- [ ] «je» везде (никогда «on» для работы гидом)
- [ ] <= 1200 символов
- [ ] Обучение с автором
- [ ] Контрольный список по борьбе с искусственным интеллектом пройден
- [ ] Как минимум 1 конкретная ссылка на руководство (протокол, инструмент, данные)
- [ ] Макс. 1 ссылка (гид или площадка)
- [ ] Никакого маркетингового языка
- [ ] Читается как человек-практик, а не как презентация

## Обработка ошибок

- **URL не указан** → Спросите об этом
- **Сообщение недоступно** → Попросить пользователя вставить содержимое сообщения
- **Нет соответствующего раздела руководства.** → Составьте комментарий на основе общего опыта, отметьте, что не было ссылки на конкретный раздел руководства.
- **Более 1200 символов после затяжки** → Представлять как полную, так и обрезанную версию, пользователь может выбрать
