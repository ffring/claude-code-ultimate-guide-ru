# Технические документы

Используйте версии электронных книг независимо от версии руководства.

**Условное обозначение версии**: `MAJOR.MINOR.PATCH`
- `MAJOR` : структура ответа (новый периметр, новая аудитория, изменение названия)
- `MINOR` : значительное обогащение (новые секции, новые углы, интеграция ландшафта с обратной связью)
- `PATCH` : исправления, уточнения, недавние ошибки.

**Связь с руководством**: запись в журнале изменений, указывающая версию руководства, которая соответствует месту в электронной книге (заголовок `version` в начале статьи).

## Комментарий в журнале изменений

Когда вы изменяете электронную книгу:

1. Бампер `wp-version` на передней панели документа `.qmd`, вызывающего беспокойство
2. Доступ к этой книге, связанной с электронной книгой
3. Формат входа:

```markdown
#### vX.Y.Z — YYYY-MM-DD (guide vX.Y.Z)

Description des changements (bullets si plusieurs).
```

4. Восстановитель файла PDF: `cd whitepapers/fr && quarto render XX-nom.qmd --to whitepaper-typst`
