# Политика безопасности

## Область применения

Этот репозиторий содержит документацию **и образовательные шаблоны** для Claude Code. Он не включает исполняемый код, который обрабатывает ввод пользователя или запускается в производственных средах.

**Проблемы безопасности, характерные для этого репозитория:**
- Точность документации для обеспечения безопасности
- Качество кода шаблона и шаблоны безопасности
- Целостность базы данных угроз ([`examples/commands/resources/threat-db.yaml`](./examples/commands/resources/threat-db.yaml))

**Вне области действия:**
- Уязвимости безопасности в самом Claude Code CLI → Сообщите [Anthropic](https://github.com/anthropics/claude-code/security)
- Проблемы безопасности на серверах MCP → Сообщите соответствующим специалистам по обслуживанию серверов.

## Сообщение о проблеме безопасности

Если вы обнаружите проблему безопасности, связанную с данным руководством (примеры: вредоносный шаблон, неправильные рекомендации по безопасности, неточности в базе данных угроз), пожалуйста:

1. **Электронная почта**: florian.bruniaux@methode-aristote.fr
   - Тема: `[SECURITY] Claude Code Guide - Brief Description`
   - Включите: Затронутый file/section, описание, оценку воздействия.

2. **GitHub Раскрытие конфиденциальной информации**: используйте [Рекомендации по безопасности](../../security/advisories/new) для решения деликатных вопросов

**Ответ SLA**: Мы стремимся ответить в течение 48 часов и исправить критические проблемы в течение 7 дней.

## Обеспечение безопасности

**Обновления базы данных угроз**: База данных анализа угроз обновляется на основе:
- Объявления о CVE и рекомендации по безопасности
- Сообщения сообщества о вредоносных серверах skills/MCP
- Anthropic бюллетени по безопасности
- Академические исследования (например, статьи о быстрых инъекциях)

**Расписание аудита**:
- Еженедельный обзор новых серверов и навыков MCP
- Ежемесячный аудит достоверности охранной документации
- Ежеквартальное полное обновление базы данных угроз

**Последнее обновление**: 11 февраля 2026 г. (v3.26.0)

## Скоординированное раскрытие информации

Если вы исследователь безопасности и обнаружили проблемы, затрагивающие несколько репозиториев в экосистеме Claude Code:

1. Сначала напишите нам (желательно скоординированное раскрытие информации)
2. При необходимости мы будем координировать свои действия с другими сопровождающими.
3. Срок публичного раскрытия: 90 дней или после исправления, в зависимости от того, что наступит раньше.
