# Экспортированные форматы

## Статус: Устаревший

Экспорт PDF в `deprecated/` был создан на основе более ранней версии руководства (~9 тыс. строк, эпоха v1.x). С тех пор руководство выросло до **~19 тыс. строк в 10 разделах** — эти экспорты больше не отражают текущее содержимое.

**Источник истины**: [`guide/ultimate-guide.md`](../guide/ultimate-guide.md)

## Устаревшие файлы

| Файл | Описание | Статус |
|------|-------------|--------|
| [notebooklm.pdf](deprecated/notebooklm.pdf) | Визуальный обзор, созданный NotebookLM | Устарело (v1.x) |
| [kimi.pdf](deprecated/kimi.pdf) | Полнотекстовый экспорт PDF через Kimi | Устарело (v1.x) |

## Планируется

Необходим свежий экспорт, соответствующий текущему руководству (v3.27.0+):

- **PDF** — экспорт полного руководства (конвейер Quarto/Typst через [`pdf-generator` навык](../examples/skills/pdf-generator.md))
- **NotebookLM** — Обновлен визуальный обзор
- **EPUB** — Для чтения электронных книг (по запросу)

Вклады приветствуются. См. [CONTRIBUTING.md](../CONTRIBUTING.md).
