# Педагогическое примечание: объединение навыков и команд (CC 2.1.3)

Версия для изменения: Claude Code 2.1.3, выпущена 11 января 2026 г.
Применимо ко всему содержанию, опубликованному после этой даты.

---

## 1. Что изменилось

**Avant 2.1.3**: два различных механизма.
- `.claude/commands/` — шаблоны Markdown, вызываемые через `/nom-command` пользователем.
- `.claude/skills/` — модули разведки для конкретной модели в контексте

**Depuis 2.1.3**: собственный механизм.
- `.claude/skills/` — реклама. Навыки использования двух режимов вызова:
  1. **User-invocable** : лента пользователя `/nom-skill` (точная поддержка старых команд)
  2. **Model-invocable**: модель заряжает автоматический навык, если описание соответствует контексту
  3. **Les deux**: один навык может быть сокращен из двух фасадов (по умолчанию, без специальной вставки)

Чтобы ограничить навык использования уникального вызова (эквивалент старой команды), добавьте его в начало:
```yaml
disable-model-invocation: true
```

Репертуар `.claude/commands/` устарел. Существующие фичи функционируют на бис (ретросовместимость), но все новые разработки делаются в `.claude/skills/`.

## 2. Объяснение комментария la fusion au lecteur

**Ne pas dire**: «команды и навыки слияния» (техника trop, pédagogique).

**Dire** : "Навыки в двух режимах вызова. Когда пользователь ленты `/nom`, это то, что он может вызвать autrefois une команда. Когда модель заряжает автоматический навык в определенном контексте, это старый навык поведения. Les deux vivent maintenant dans `.claude/skills/` с моей главной темой YAML».

**Сохранение термина "косая черта"** : комментарий пользователя, вызывающий навык (через `/`), как отдельный тип механизма. «Команда косой черты» = навык, используемый пользователем вызова. Остальные термины применимы в справочных таблицах встроенных команд (`/clear`, `/compact` и т. д.) и в пояснениях по использованию.

**Не содержит "команды"** встроенной терминологии: `/clear`, `/compact`, `/help` остаются "встроенные команды". La fusion не касается привычных механизмов.

## 3. Новая таблица сравнения «Агент» и «Навык»

Таблица Agent/Skill/Command (3 столбца) отличается от Agent/Skill (2 столбца) с примечанием к режимам вызова навыка.

| Механизм | Сжатие | Порте | Идеальное использование |
|-----------|--------------|--------|-------------------|
| **Агент** | Инструмент задачи/вызов Claude | Изолированная сессия | Однократный аудит, параллельный аудит |
| **Навык** | `/nom` (пользователь) или авто (модель) | Партаж среди агентов | Повторное использование Connaissance, кодирование рабочего процесса |

**Примечание к навыку вызова** :
- Вызываемый пользователем (`disable-model-invocation: true`): `/tech:commit`, `/release-notes` — управление отключением пользователя.
- Вызываемая моделью: `security-guardian`, `tdd-node` — le model charge selon le contexte
- Les deux (défaut): многозначные навыки, вызовы deux façons.

**Регулятор быстрого выбора** :
- Переход к изоляции контекста → **Agent**
- Изучение или рабочий процесс в инкапсуляторе → **Skill**
  - Сжатый пользователь → `disable-model-invocation: true`
  - Le modèle décide → laisser le défaut (вызываемая модель)
  - Les deux → laisser le défaut sans l'option

## 4. Примеры конкретных режимов вызова

**Уникальность, вызываемая пользователем** (`disable-model-invocation: true`):
- `/tech:commit` — пользовательское управление лентой после кода
- `/release-notes` — разжатие в конце спринта для пользователя
- `/ship` — последовательность развертывания разжатого устройства

**Уникальность, вызываемая моделью** (без специального заголовка, точное описание):
- `security-guardian` — заряд, когда Claude обнаруживает аутентификацию или разумный маршрут
- `tdd-node` — временный поверенный, и Claude начинает подготовку к испытаниям
- `silence-framework-expert` — ответственный за репозитории с тишиной-ws

**Les deux** (по умолчанию, общее описание):
- `pdf-generator` — пользователь может использовать `/pdf-generator` или Claude для оплаты «создания PDF»
- `commit-craft` — разжатие `/commit-craft` или автоматическое перед фиксацией

## 5. Редакционная работа по типу содержания

### Сравнительные таблицы (3 механизма → 2)
Поднимите строку «Команда» и добавьте примечание к режимам вызова навыков.

### Примеры структуры фишеров
```
.claude/
├── skills/       # Slash commands + knowledge modules (unified since CC 2.1.3)
├── agents/
├── hooks/
└── rules/
```
Линия `commands/` — это диаграммы древовидности.

### Деревья решений
Ветви «→ Команда» devinnent «→ Навык (вызываемый пользователем)».

### Примеры фронтмена
Весь пример заголовка `command` в `.claude/commands/` отличается от примера навыка в `.claude/skills/` с `disable-model-invocation: true`, если старый пример — это чистая команда.

### Выноски sur la fusion
В официальных документах замена общей выноски «конвергенция» по фактической выноске:
> **CC 2.1.3 (январь 2026 г.)** : `.claude/commands/` представляет собой искаженное слияние с `.claude/skills/`. Чтобы создать эквивалент старой команды, поместите документ в `.claude/skills/` и добавьте `disable-model-invocation: true` во вкладку YAML.
